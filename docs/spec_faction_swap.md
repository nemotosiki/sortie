# SPEC 陣営分離 — 敵からアメリカ製兵器を排除 (2026-07-26, Fable設計)

ユーザー指示: **「敵機からアメリカ製の兵器は消して、ロシア製に置き換えていって」**。
自機＝西側（アメリカ+欧州）、敵＝ロシア製、という陣営分けを徹底する。

## 前提（この作業の直前に揃うもの）

- ロシア機第1陣: MiG-21bis / MiG-29A / Su-33 / Su-35S（enemyOnly）
- ロシア機第2陣: Su-57 / Su-47 / MiG-23 / Su-25 / Tu-95（enemyOnly）
- 敵ロスター基盤: 任意エアフレームを敵として出す機構＋ネームドエース機構
- 既存の敵専用機: bomber（B-52風）/ uav（MQ-99風）/ transport（C-17風）

## 置換方針

### 1. 敵ウェーブの機種置換（全ミッション）

西側機が敵として出ている箇所を、性格の近いロシア機に置き換える。**難度曲線（序盤=弱い / 後半=強い＋エース多め）は維持**すること。

| 現状の敵機（西側） | 置換先（ロシア） | 理由 |
|---|---|---|
| F-4（序盤の弱敵・護衛） | **MiG-21bis** | 旧世代・弱い・数で来る役割が一致 |
| F-16 / F/A-18F（中盤の標準敵） | **MiG-29A** | 第4世代の標準機 |
| F-15（中盤〜後半の強敵） | **Su-33**（艦隊戦）/ **Su-35S**（陸上） | 重戦闘機枠。艦隊CAPはSu-33が筋 |
| F-22（IRONBACK＝エース） | **Su-57**（後述） | 第5世代同士の対決に置換 |
| その他西側機が敵で出ている箇所 | 上表に準じて近い性格のロシア機へ | — |

### 2. IRONBACK の乗機（★この指示で自動的に決まる）

- IRONBACK は現在 **F-22**。アメリカ製なので**必ず置換**する → **Su-57 FELON** を推奨
  （第5世代・最強クラス・ボス格として最適。以前検討していたSu-37/Su-35S案より上）
- ポストストール機動（コブラ）の実装は**そのまま流用**できる（Su-57はコブラ機動の本家筋でむしろ自然）
- 既存のM8検証資産（発動窓380-460m等）は機体性能表が変われば要再確認だが、**性能値はSu-57の表に置き換えるだけ**で、ロジックは不変

### 3. 敵専用機のロシア化（見た目の一貫性）

| 現状 | 置換 | 備考 |
|---|---|---|
| bomber（B-52風） | **Tu-95 BEAR** へ寄せる or 併存 | 第2陣でTu-95実装済み。m01/m-interceptの爆撃機をTu-95に |
| transport（C-17風） | **Il-76 CANDID 風**に改修 | 高翼4発は共通なので、機首/尾部の造形とT字尾翼の有無で寄せる |
| uav（MQ-99風） | そのまま可 | 無国籍のドローンとして許容。余裕があればロシア系UAVの造形へ |

### 4. 触らないもの

- **自機（ハンガー14機）は一切変更しない**。MiG-31B / Su-37 が自機側に居るのはユーザー明示の例外
- 艦艇（AEGIS/CARRIER/FRIGATE）と地上目標は今回のスコープ外（無国籍として存置）
- ミッション構造・TGT指定・パータイム・解禁連鎖は変えない（**機種だけ差し替える**）

### 5. 文言の追従

- ブリーフィング/無線で敵機を機種名で呼んでいる箇所（「F-15が2機」等）を置換後の機種名に修正
- HUDの機種名表示は自動追従（実装済み）
