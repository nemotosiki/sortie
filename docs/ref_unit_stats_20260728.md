# 既存ユニットの性能値一覧（2026-07-28 実測）

**用途**: 新ユニットを追加するとき、既存と射程・HPが重複しないようにするための基準表。
外注（ChatGPT）への依頼文にそのまま載せる。

**出典**: `index.html` のコード直読み（全値が `Object.freeze` 済みリテラルで、
実行時のランダム化を受けないフィールドのみ）。デバッグフックは位置/HP/速度しか返さないため
射程・マウント情報はコード側が正本。

**単位**: HP=無次元（98 = ミサイル1発分の基準）／射程・hitRadius・hitBox=メートル／
速度=m/s／cooldown=秒／turnRate=度数

## ★空いている射程帯（新ユニットを置くべき場所）

1. **地上目標の砲射程は 390〜620 に密集していて、700以上が完全に空白。**
   高射程の地上防空が1つも無い。長射程SAMを足すならここ（第8便の狙いはこれで正しい）。
   420〜560の間も空いている。

2. **艦のSAM射程は 1100 / 1250 / 1500 / 1700 の4点。**
   1100未満、1250〜1500の間（1300台）、1700〜2100の間が空き。

3. **ヘリは中間帯（aa射程 500〜850）が薄い。**
   attackRange も 1500〜1800 に偏っており、500未満の近接特化と2000超の長射程が空き。
