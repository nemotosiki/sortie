# SPEC M5 — ミッション演出（ブリーフィング/大型バナー/ランク演出） (2026-07-25, Fable設計)

M4出荷後に着手。フローに「ブリーフィング画面」を挿入し、AC名物の大型バナーとランク演出を足す。

## 1. ブリーフィング画面（新ステート）

- フロー変更: ステージセレクトで決定 → **STATE_BRIEFING** → 機体セレクト(ready) → 出撃
  - ENTER/○: タイプ表示中なら**全文즉시表示**、表示完了後なら機体セレクトへ
  - ESC/□: ステージセレクトへ戻る
- レイアウト（menuScreen流用・opaque背景）:
  - ヘッダ: `MISSION 04` + タイトル + `[ BRIEFING ]`
  - 中央〜左: `drawTacticalMap` をズームビュー(zoom 2.2〜2.8)で使い、ミッション海域へ**起動時にゆっくりズームイン**
    （0.9秒、easeOut。毎フレーム再描画はブリーフィング表示中のみ）
  - マップ上に**目標マーカー**をミッション内容から自動生成: air波=赤の敵機シェブロン群、naval=琥珀の艦矩形群、
    groundUnits=琥珀のダイヤ群。選択ミッションのドット位置周辺に散らし、ゆっくり点滅
  - 下部: **タイプライター表示のブリーフィング本文**（無線と同じdtベース・約30ms/字、話者ビープなし・
    キャリッジ音を8字毎に小さく playTone(1180, 0.015, 0.02)）
- `MISSIONS` に `briefing` フィールド追加（日本語2〜4行、下記全文をそのまま使う）:
  - m01: 「哨戒空域レーダーに国籍不明機3。応答なし——交戦規定アルファを許可する。\n全機撃墜し、制空権を確保せよ。」
  - m02: 「敵は二正面攻勢を仕掛けてきた。第1波を叩いた直後、増援の第2波が到達する。\n補給は無い。弾を数えながら、連続迎撃せよ。」
  - m03: 「偵察衛星が敵機動部隊を捕捉。空母1、護衛のイージス艦2。\n日没の逆光を利用して接近し、対艦攻撃で殲滅せよ。\nイージスのSAMは垂直発射だ。発射煙を見たら即座に回避機動を取れ。」
  - m-glacier: 「氷河回廊の尾根に敵レーダー網が敷かれ、輸送路が塞がれている。\n谷底を低空で駆け抜ければSAMの射線は切れる。\n壁のレーダーサイトとSAMを黙らせ、上空の哨戒機も排除せよ。」
  - m-night: 「夜間強襲作戦。月明かりを背に敵前線基地へ侵入する。\n対空砲火に注意。燃料庫に火が入れば誘爆が基地を飲み込むはずだ。\n地上目標をすべて破壊し、夜間CAPも撃墜せよ。」
  - m04: 「エース『IRONBACK』率いる精鋭飛行隊が空域に侵入した。\n奴は今まで12機を墜としている。次を君にするな。\n編隊ごと撃墜せよ。」
  - m05: 「総力戦だ。敵航空戦力、IRONBACK、そして敵艦隊——すべてを叩く。\n途中、補給ラインでミサイルを再装填できる。\nこの空と海を取り戻せ。幸運を祈る。」
- ゲームパッド: ○=進む/□=戻る（既存メニュー配線の分岐追加）、D-pad/スティックは無効

## 2. 大型バナー（MISSION START / ACCOMPLISHED / FAILED）

小型の既存 `showBanner` とは別に、画面中央の**全幅帯バナー** `#bigBanner` を新設:
- 見た目: 高さ~120pxの黒帯(上下に細いHUD緑ライン)、中央に斜体大文字(clamp 40-64px, letter-spacing 0.3em)、
  下に小さくミッションタイトル。出現はワイプ(scaleY 0→1, 180ms)+文字フェード、退場はフェード
- **MISSION START**: `startMission()` 末尾で2.4秒表示（既存のWAVE 1バナーはstart時のみ0.8秒遅延させ重なり回避）
- **MISSION ACCOMPLISHED**: `completeMission(true)` を変更——即座に result へ遷移せず、
  `outcomePending` タイマー(2.8秒)を導入。その間 gameState は playing のまま(敵は全滅済み)、
  大型バナー表示+勝利スティング(playTone和音 or 既存sfx)。タイマー満了で従来どおり setState(COMPLETE)。
  途中で墜落したら従来の gameover が優先(タイマー破棄)
- **MISSION FAILED**: `completeMission(false)` 側は即遷移のまま、result画面表示と同時に赤系の大型バナーを1.8秒
- リトライ/クリーンアップで必ず非表示リセット

## 3. デブリーフのランク演出強化

- 既存 `RANK` セルを**大型ランクレター**に: 結果画面右側に120px級の文字、色分け
  (S=金+パルスグロー、A=白銀、B=青銅、C=灰)。300ms遅延でscale 1.6→1.0のスタンプイン
- スコア内訳行を追加: `TIME xx'xx"xx (PAR xx'xx")` / `DAMAGE TAKEN xx%` / `KILLS n/n`。
  既存 resultStats の下に3行、等幅フォント
- ランクS時のみ小さな追い無線: command「完璧な仕事だ。司令部が君の名を覚えたぞ。」(id "rank-s", 優先NORMAL)

## 検証
- 全7ミッションでブリーフィング表示→タイプ完走とスキップ両方→機体セレクト→出撃の全パス
- START/ACCOMPLISHED/FAILEDバナーのスクショ3枚（ACCOMPLISHEDは飛行画面の上に出ていること）
- ACCOMPLISHED表示中に墜落→gameoverが正しく優先されるエッジ
- ランクS/C両方の演出スクショ、内訳行の実測値一致（TIME=missionElapsed、PAR=parTime）
- 戻る系(ESC/□)の全遷移、ゲームパッド、fps、エラー0、リグレッション(m05アウトロ)
