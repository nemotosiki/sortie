> [設計書インデックスへ戻る](./README.md)

**版:** v0.2 / 2026-08-01  
**状態:** 新規キャンペーン設計の正本候補。コード実装前。  
**対象:** 米編20ミッション、露編20ミッション、真章1ミッション。

## 0. この設計の狙い

- エースコンバット型の「迎撃、制空、対地、艦隊戦、護衛、峡谷、エース中隊、超兵器、最終要塞」を40ミッションへ配分する。
- 米編と露編は**同じ戦争計画の別世界線**。プレイヤーが所属した側の決定的作戦を成功させるため、その側が戦争に勝つ。
- 対応する2ミッションは、必ずしも同じ場所を飛ばない。同じ戦略作戦の前段、陽動、補給、迎撃、結果回収として対応させる。
- 同じ戦場を反対側から飛ぶのは、戦争の記憶を重ねたい4組だけに絞る。
- 各地域には固定された主権国、道路、港、補給方向があり、別国のマップとして名前だけ変える使い回しをしない。
- 選択画面だけに頼らず、出撃順、撃破順、護衛対象、任意目標、救助に割く時間でプレイヤーの思想を示す。
- 姿なき悪役には名前も声も与えない。重要な場面だけ、HUDの半透明の白い照準が「最も効率的な一つの答え」を示す。
- 最初から善い選択だけを続ける話にはしない。管理が人を救った事実、解放が人を救った事実、その両方が破滅へ変わる過程をプレイヤー自身に体験させる。

### v0.2で確定した設計判断

- 旧ストーリー、旧国家、旧因果ペアを物語上の前提にはしない。現在のゲームシステムと再利用可能なユニット資産のみを参照する。
- 米編と露編は同じ戦争計画から分岐する別世界線。対応ミッションは戦略上つながるが、同一マップの裏表は4組だけに限定する。
- マップには固定主権、隣接地域、補給線、進攻方向を設定する。世界線が変わっても土地の所属を名前だけで変更しない。
- 各ミッションは「軍事目標」「味方・民間の守る対象」「プレイヤーが選べる優先順位」を最低一つずつ持つ。
- 米編の破滅は、誰も死なせないために全員の信用と移動を所有すること。露編の破滅は、解放を愛と読み替え、本人の意思と肉体を奪うこと。
- 超兵器は善悪の記号ではなく、実際に戦争を短くし人命を救う機能を持たせる。その有効性があるからこそ誘惑として成立する。
- 真章は中央を壊す話ではなく、中央が握っていた機能を十二地域へ分け、異なる制度を異なるまま守る話とする。

## 2. 世界地図と固定領土

```text
                                      北極海

                 ┌────────── エレム連邦 ──────────┐

                 ヴェル氷岸 ── ノル工業帯 ── カラン平原
                      │              │               │
                 アラド山地 ── オルム盆地 ── ケデム回廊
                                                     ╲
                                                      ナハル海峡
                                                         ╲
  西方海      ハドール諸島 ── セラ連邦 ── レン湾      ミガル環礁
                    │              │          │            │
                ハドール深海    アマル平原  ルメン稜線   シェム中枢

                 └────────── セラ連邦 ──────────┘
```

### セラ連邦領

- **レン湾:** 東海岸の大都市・航空基地・医療航空管制。米編ミッション1の戦場。
- **アマル平原:** 農地、発電網、戦略飛行場が集中する内陸部。
- **ルメン稜線:** 首都背後の山岳防衛線。セラのエース養成基地がある。
- **ハドール諸島:** 海軍基地、空母泊地、海底通信線を持つ軍事群島。
- **ハドール深海:** 空母機動部隊と潜水艦が活動する外洋。

### エレム連邦領

- **アラド山地:** 南西国境の山岳共同体、地下航空基地、古代文書庫。
- **オルム盆地:** 石油、砂漠飛行場、金融認証中継所がある乾燥地域。
- **カラン平原:** 穀倉、戦車軍、難民道路が重なる南部平原。
- **ノル工業帯:** 航空機、無人機、鉄道、弾薬工場が集中する工業都市圏。
- **ヴェル氷岸:** 長距離レーダー、防空基地、氷下貯蔵施設がある北方地域。

### ケデム共和国領

- **サルク港:** 両大国を結ぶ中立港。開戦直後の上陸戦の焦点。
- **ホワイトパス:** 東西を結ぶ唯一の大規模山岳道路。
- **ナハル海峡:** ミガル環礁へ至る海上交通の要衝。
- **ダマル海:** 悪天候が多い国際航路・救難海域。

### 国際管理地

- **ミガル環礁:** シェム本部、国際都市、病院、物流港、戦略兵器認証中枢が同居する。
- **ミガル外環:** 成層圏防衛環オファンの管制空域。
- **ミガル中枢:** シェムの中央ROOTと国際評議会が置かれた区域。

### 地理整合性の絶対ルール

1. 地域の本来の主権国は世界線が変わっても不変。
2. 世界線で変化するのは実効支配、損傷、部隊配置だけ。
3. セラ軍の基本進攻方向は西・南西から東・北東。
4. エレム軍の基本進攻方向は東・北東から西・南西。
5. 同じ地域を再訪する場合、沈没艦、破壊橋、焦げた倉庫、占領軍の仮設基地を残す。
6. 同一戦場を両編で完全共有するのは次の4か所だけ。
   - ナハル海峡（M04 / M24）
   - ミガル市街（M15 / M35）
   - ミガル外環（M19 / M39）
   - ミガル中枢（M20 / M40）

## 2.1 距離・移動・補給の基準

世界地図を雰囲気だけの図にせず、作戦間の移動が成立する距離へ固定する。ゲーム内の一つのマップは、世界地図上の地域全体ではなく、概ね20〜45km四方の戦術空域を切り出したものとする。

| 区間 | 概算距離 | 通常輸送機 | 戦闘機 | 戦略上の意味 |
|---|---:|---:|---:|---|
| レン湾―アマル平原 | 240km | 45分 | 20分 | セラ本土防衛の内線 |
| アマル平原―ハドール諸島 | 510km | 90分 | 40分 | 空母・本土間の増援路 |
| サルク港―ホワイトパス | 180km | 35分 | 15分 | ケデムを東西に貫く地上回廊 |
| ホワイトパス―オルム盆地 | 270km | 50分 | 22分 | セラ反攻・エレム侵攻の主軸 |
| オルム盆地―カラン平原 | 310km | 60分 | 25分 | エレム南部の補給動脈 |
| カラン平原―ノル工業帯 | 420km | 75分 | 32分 | 食料と軍需を結ぶ鉄道軸 |
| ナハル海峡―ミガル環礁 | 360km | 70分 | 28分 | 最終侵攻に不可欠な海空回廊 |
| ハドール深海―ミガル外環 | 620km | 110分 | 45分 | セラ空母群からミガルへの援軍路 |

### 補給と進軍の固定原則

- セラ軍がエレム領へ侵攻するには、サルク港、ホワイトパス、オルム盆地の順に補給拠点を確保する必要がある。
- エレム軍がミガルへ進むには、アラド山地からケデムへ入り、ナハル海峡かハドール外島のどちらかを確保する必要がある。
- 空母は地図上を瞬間移動しない。M04後にナハル方面へ進んだ艦隊は、M16までダマル海・ハドール深海を経由してミガルへ後退する。
- 大型爆撃機は前線基地へ常駐させず、エレム北部またはセラ西方の後方基地から給油機を介して飛来する。
- 地上軍の前線は、一つ前の幕で港、橋、鉄道、燃料施設のどれが生存したかによってのみ移動する。

### 作戦空域の高度基準

| 地域種別 | 地表・海面 | 主な戦闘高度 | 高高度上限の目安 |
|---|---:|---:|---:|
| 海岸・港湾 | 0〜180m | 30〜1,800m | 4,500m |
| 平原・砂漠 | 20〜260m | 50〜2,500m | 5,500m |
| 峡谷 | 谷底80〜350m / 稜線350〜850m | 谷底+30〜1,500m | 4,000m |
| 氷岸 | 0〜600m | 100〜3,000m | 6,000m |
| ミガル外環 | 0〜200m | 500〜7,500m | 10,000m |

この基準は演出値であり、実装時にはゲームの飛行モデルと描画距離へ合わせて圧縮してよい。ただし、同一地域を再訪した際の高度感は維持する。

## 3. 開戦前史

エレム南部十二州の武装組織が、シェム決済網を利用して戦略兵器を購入した。シェムは資金を止めるため、十二州に関係する決済、航空燃料、物流認証を凍結した。

武装組織と一般住民を完全に分離できなかったため、病院への医薬品、農家の口座、難民の身元認証まで止まった。シェムは「戦略兵器を止めなければ、さらに多くが死ぬ」と主張する。十二州は「犯罪者を止めるために、地域全体を帳簿から消した」と反発する。

エレム政府は制裁解除を要求し、交渉のための圧力としてケデム回廊へ軍を進める。セラは中立国侵攻と判断し、シェム防衛条約を発動する。

戦争は宣戦布告から始まらない。レン湾のレーダーが、低空を西へ向かう六つの大型反応を捉えた瞬間から始まる。

## 3.1 政治構造と、誰も戦争を止められない理由

### セラ連邦

- 議会制の海洋連邦。沿岸州、内陸農業州、島嶼州で利害が異なる。
- シェムを支持する理由は思想ではなく、通貨安定、海運保険、医療物流、戦略兵器管理が実際に機能しているため。
- 開戦時の政府は全面戦争を望んでいないが、中立国ケデムへの侵攻を放置すれば防衛同盟そのものが崩壊する。
- 軍は「本土と国際秩序の防衛」を掲げる。占領地拡大は当初の目的ではない。

### エレム連邦

- 大陸型の連邦国家。中央政府と南部十二州の間に長年の緊張がある。
- 中央政府は武装組織を取り締まっているが、シェムが地域全体を凍結したことで政府の正統性が崩れる。
- エメト盟約は最初から宗教軍ではない。病院、農協、地方銀行、避難所が作った相互扶助協定が、戦時に政治・軍事同盟へ変わったもの。
- エレム軍の開戦目的は、ケデム回廊を確保し、ミガルへ凍結解除を強制する限定戦争である。

### ケデム共和国

- 永世中立を掲げるが、輸送、港湾、エネルギー収入の多くをシェム決済に依存する。
- 国内にはセラ寄りの港湾都市、エレム寄りの山岳地域、厳格な中立派が存在する。
- どちらの世界線でも最初に戦場となり、住民は「どちらを支持するか」ではなく「どちらの軍が今ここを占領しているか」で生存を判断する。

### シェム

- 一般市民が直接口座を開く銀行ではなく、中央銀行、物流機関、航空当局、戦略兵器認証を接続する国際機構。
- 自前の大軍は持たず、加盟国の部隊、契約警備隊、無人防衛環オファンを運用する。
- 決定は24名の評議会による多重承認が原則。平時には濫用を防ぐが、戦時には遅い。
- ギボル権限は、評議会が停止した時だけ一人へ全承認権を一時移譲する非常条項。

### エメト盟約

- 十二州が「凍結された者も人間として数える」ために結んだ相互救済契約。
- 当初の実務は、共同通貨、医薬品交換、避難経路、農産物の相互保証。
- 戦況悪化後、盟約へ従わない者を「シェムの衣を着た者」と分類し始める。
- ヴェイルは創設聖典ではなく、戦争中盤に発見され、既存の解放思想へ危険な言葉を与える。

### 戦争を止められない五つの鎖

1. シェムが凍結を解除すると、武装組織の兵器購入も再開する可能性がある。
2. エレムが撤退すると、十二州は中央政府とシェムの双方から見捨てられたと感じ、内戦になる。
3. セラが防衛条約を放棄すると、ケデムとミガルの中立制度が崩壊する。
4. ケデムが一方へ付けば、他方にとって侵攻路または封鎖拠点になる。
5. 一度戦死者が出た後は、どの政府も「何も得ずに終わる」講和を国内へ説明できない。

## 4. 二つの世界線

### 米編世界線

ROOK 1がレン湾の爆撃機を阻止する。セラの飛行場と管制網が残り、反攻に成功する。戦線はケデムからエレム南部へ押し戻され、最後にミガルを守る戦争になる。

### 露編世界線

REEM 1が爆撃作戦の前段でセラ迎撃網を排除する。爆撃機がレン湾へ到達し、セラ航空戦力が初日に損傷する。エレムはケデムを占領し、ナハル海峡を突破し、最後にミガルを攻略する戦争になる。

両方とも公式戦史ではない。プレイヤーが操縦した側で、一人のエースが決定的な任務を成功させた世界線である。

## 4.1 戦争日程と前線推移

### 米編の幕ごとの戦線

```text
開戦前       : 国境はケデム東端
ACT I後      : セラがサルク港を奪還、エレム軍は海峡東岸へ後退
ACT II後     : セラがホワイトパスを突破、オルム盆地へ進出
ACT III後    : エレム南部戦力が後退、戦争の焦点がミガルへ移る
ACT IV終幕   : ケレン破壊、ミガル防衛成功、エレムが停戦を受諾
```

### 露編の幕ごとの戦線

```text
開戦前       : 国境はケデム東端
ACT V後      : エレムがサルク港を占領、セラの東岸航空網が損傷
ACT VI後     : エレムがナハル海峡へ進出、セラ増援路を遮断
ACT VII後    : ハドール外島に橋頭堡、ミガル市街が直接攻撃圏へ入る
ACT VIII終幕 : オファン停止、ミガル中枢陥落、セラが停戦を受諾
```

### 同一地域の世界線差分

- 米編でセラが奪還したサルク港は、露編ではエレムが防衛に成功した港として描く。
- 米編で破壊されたケレン周辺の町は、露編ではケレンが生存しシェム側施設が損傷した状態になる。
- ミガル市街の建物配置は同一だが、M15では避難灯と防空灯が主役、M35では検問所と決済塔が主役になる。
- 世界線間で瓦礫を共有しない。共有するのは地形、都市構造、道路、施設用途だけ。
