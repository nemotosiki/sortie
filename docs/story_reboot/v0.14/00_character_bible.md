# 0. 今版で絶対に変えないこと

1. 主人公二人には本名を付けない。顔、出身家系、性別の断定も必要最小限にする。
2. 主人公にはTACネームを付ける。
3. 「部隊コールサイン」「機番」「TACネーム」「本名」を混同しない。
4. セラ主人公は開戦時 `ROOK 2 "RAVEN"`。M06後に `ROOK 1 "RAVEN"`を継承する。
5. `ROOK 1 "CROWN"`は別部隊ではない。開戦時のROOK隊長である。
6. エレム主人公は開戦時から `REEM 1 "POLKA"`。
7. REEM隊は全編を通して二機編成。`REEM 3`を作らない。
8. `REEM 2 "SABLE"`はPOLKAへ反逆しない。警告、確認、悲しみは表現できるが、命令拒否・離反・主人公への攻撃は行わない。
9. 「狂ったエースを狩る者」はRAVENの通常の職務・正史ではない。GIBOR闇ルートで、必要のない白い敵を追い始めた結果としてのみ成立する。
10. `GIBOR`は法的権限、ROOT権限、階級、兵器アクセス権ではない。報道と兵士がRAVENを「勇士・戦場の王」と称える異名である。
11. RAVENとPOLKAは最後まで戦闘機パイロットであり、政治家や世界管理システムの操作者にはしない。
12. 神話対応は作者側だけの設計情報。作中人物が「自分はニムロド／ヤハウェ／ユダだ」と説明しない。

# 1. 呼称の文法

例:

```text
所属:       セラ 第3航空師団 第22飛行隊
部隊呼称:   ROOK
機番:       ROOK 2
TACネーム:  RAVEN
本名:       主人公なので設定しない
```

無線の基本:

- 戦術指示: `ROOK 2`, `REEM 1`
- 個人的な呼びかけ: `RAVEN`, `POLKA`
- 公的報道・敵の恐怖: TACネーム、または後述の異名
- 主人公の本名は字幕、デブリーフ、人物表にも出さない

M06後:

```text
旧:
ROOK 1 "CROWN"
ROOK 2 "RAVEN"
ROOK 3 "LARK"

新:
ROOK 1 "RAVEN"
ROOK 2 "LARK"
ROOK 3 欠番／補充待ち
```

CROWN本人のTACネームは変わらないが、前線機番を失った後は`CROWN`または後方指揮席の呼称で呼び、`CROWN 1`という別部隊風の表記を使わない。

# 2. セラ陣営

## 2.1 第3航空師団 第22飛行隊「ROOK」

開戦時は三機編成。RAVENの物語は、誰かの後ろに付く二番機から始まる。

### ROOK 1 “CROWN”

| 項目 | 設定 |
|---|---|
| 本名 | Marcus Hale / マーカス・ヘイル |
| 年齢帯 | 40代前半 |
| 開戦時 | ROOK隊長 |
| 機体 | 序盤F-15系。任務によりF-16系も使用 |
| 内部モチーフ | モーセ |
| 中心命題 | 判断を教えるが、弟子の人生を所有しない |

撃墜数を自慢しない熟練パイロット。RAVENを「将来の英雄」としてではなく、判断を覚える必要がある若手として扱う。

基本原則:

> 「撃てるかじゃない。何をしている機体かを見ろ。」

M01では高高度攻撃機の護衛から離れないよう、RAVENとLARKを統率する。M06ホワイトパスで被弾・重傷を負うが固定生存。以後は前線を退き、限定的な後方助言と停戦連絡を担当する。

CROWNはRAVENの王冠を奪う人物ではない。GIBORルートでも自ら再出撃して弟子を倒すのではなく、帰投を求める。RAVENが応じないことによって、師弟関係の破綻を表す。

禁止:

- M06で死亡させる
- 復讐のための師匠にする
- 世界の真相を知る解説者にする
- RAVENへ命令服従だけを教える
- GIBOR最終戦の単純なラスボスにする

### ROOK 2 → ROOK 1 “RAVEN”

| 項目 | 設定 |
|---|---|
| 本名 | なし／PLAYER |
| 開戦時 | ROOK 2 |
| M06後 | ROOK 1 |
| 内部モチーフ | ニムロド、エンキドゥ、狩人の反転 |
| 通常の成長 | 従う者から、自分で判断し、必要なら撃たない隊長へ |
| 闇の変質 | 名声と強敵への執着から、戦場を降りられない最後のエースへ |

通常ルートのRAVENは「狂ったエース狩り」ではない。軍事目標、護衛、住民、作戦全体を見て、必要な戦闘だけを選ぶ隊長になる。

RAVENが優秀であるほど、味方は判断を委ねる。誘惑は世界権限ではなく、次の成功体験である。

```text
RAVENが決める
→ 味方が助かる
→ 任務が早く終わる
→ 若手がRAVENの判断を無条件に信じる
→ 敵エースがRAVENを名指しする
→ 報道が「GIBOR」と称える
```

通常ルートでは、この名声を役割として受け取り、停戦後は降りる。

闇ルートでは、白いARCAを「将来の脅威」「強いから倒す価値がある」と追い始め、GIBORという異名を自分自身の存在理由にする。

### ROOK 3 → ROOK 2 “LARK”

| 項目 | 設定 |
|---|---|
| 本名 | Claire Rowan / クレア・ローワン |
| 年齢帯 | 20代後半 |
| 開戦時 | ROOK 3 |
| M06後 | ROOK 2 |
| 内部モチーフ | アリアドネ、シャムハト |
| 中心命題 | 戦場の外へ戻る糸を残す |

戦果より帰還者、残燃料、損傷機、救難信号を気にする。道徳講義ではなく、具体的な人と帰る場所の話をする。

M01では高高度攻撃機編隊の左側を担当。敵を追いすぎず、護衛へ戻る基本をCROWNから教わる。M06後はRAVENの唯一の常設僚機となる。

通常ルートでは、RAVENを「GIBOR」ではなくRAVENと呼び続ける。闇ルートでは最初から反抗するのではなく、RAVENの判断を信じた結果、自分も不要な撃墜へ加担しかける。そこで初めて、英雄への信頼が危険になったと気づく。

GIBOR終盤ではRAVENへ帰投を求めるが、殺害を目的にしない。必要なら武装解除編隊へ参加できるが、最終的な役割は「まだ帰れる」と伝えることである。

## 2.2 AWACS “MERIDIAN”

| 項目 | 設定 |
|---|---|
| 本名 | Naomi Serrat / ナオミ・セラート |
| 内部モチーフ | アテナ |
| 役割 | ROOK隊の主担当管制官 |
| 文体 | 方位、距離、残数、作戦目的。感情は沈黙と呼称で示す |

序盤は`ROOK 2`と呼ぶ。RAVENが隊長を継いだ後は`ROOK 1`、個人的な場面では`RAVEN`。

ARCAが白敵となった後の段階的な無線:

```text
末期: 必要な戦術情報だけを読み、称賛しない。
```

沈黙は闇ポイントを知らせるUIではない。プレイヤーが後から変化に気づく演出に留める。

## 2.3 シェム監査官 “MICA”

軍人ではない。停戦、航空路、認証、復旧の実務担当。RAVENへ世界を支配する鍵を渡さない。

MICAの役割は、政治的な結末がRAVEN一人の所有物ではないと示すこと。ONE SHEMでRAVENが行うのは、MICAや停戦団の空路を守り、任務終了後に着陸することである。

# 3. エレム陣営

## 3.1 第4航空師団 第22飛行隊「REEM」

REEM隊は全編二機だけ。POLKAは最初から編隊長である。

### REEM 1 “POLKA”

| 項目 | 設定 |
|---|---|
| 本名 | なし／PLAYER |
| 開戦時 | REEM 1 |
| 内部モチーフ | ヤハウェ、ギルガメシュ |
| 通常の成長 | 救う力を持ちながら、救われる側の意思を残す |
| 闇の変質 | 自分の判断が最も多くを救うという事実から、本人の意思を不要と考える |

POLKAは序盤から有能で善良。命令を受けるだけでなく、SABLEと護衛対象を率いる。

危険なのは、POLKAの判断が実際に正しい場面が多いことである。

```text
POLKAが決める
→ 住民が助かる
→ 作戦が成功する
→ SABLEが従う
→ 上層部も決定を任せる
→ 誰もPOLKAの正しさを検証しなくなる
```

POLKAにも世界ROOTや政治的王権を与えない。最終的な闇の選択は、パイロットとしてRUAの投下・誘導・護衛を実行するかどうかで表す。

### REEM 2 “SABLE”

| 項目 | 設定 |
|---|---|
| 本名 | Nadia Volen / ナディア・ヴォレン |
| 年齢帯 | 20代後半〜30代前半 |
| 全編 | REEM 2 |
| 内部モチーフ | ルツ、ヨブ |
| 中心命題 | 忠誠は愛になり得るが、正しさの証明にはならない |

十二州出身。家族の医療認証停止と物流封鎖を経験している。POLKAが「帳簿の外へ捨てられた人間も守る」姿勢を示したため、強く信頼する。

絶対規約:

- POLKAへ反乱しない
- 命令を拒否しない
- 敵へ寝返らない
- 最終戦でPOLKAを攻撃しない
- REEM隊を三機以上にしない

ただし、感情を失った信者にはしない。状況確認や被害報告はできる。

```text
「了解、POLKA。」
「理由は後で聞きます。今はついていきます。」
「救難信号が消えています。それでも進みますか。」
```

最後の問いにもPOLKAが進めと判断すれば従う。通常ルートでは忠誠が二人の信頼として機能し、RELEASEでは誰もPOLKAを止めない怖さになる。

## 3.2 AWACS “POLARIS”

| 項目 | 設定 |
|---|---|
| 本名 | Elena Arvik / エレナ・アルヴィク |
| 内部モチーフ | マアト、ナブー |
| 文体 | 正確な復唱、目標座標、救難信号、残存数 |

後半、「停止」「解放」「撃破」が同じ作戦コードで処理されるほど、復唱前の間が長くなる。RELEASEでもPOLKAを罵倒しない。消えていく救難信号と戦果を同じ声で読み上げる。

### WARDEN 1 “GRANITE”

| 項目 | 設定 |
|---|---|

# 4. SUNFLOWER隊 — ユダの誘惑

## 4.1 所属

**エレム 第1独立特殊戦術飛行隊「SUNFLOWER」**

通常の航空師団から半独立した実験・特殊作戦部隊。紋章は黒い中心を持つ黄色いひまわり。

ひまわりの二重意味:

- 表: 希望、光へ向く花
- 裏: 正しい光ではなく、その時もっとも強い光へ向きを変える

## 4.2 SUNFLOWER 1 “PILGRIM”

| 項目 | 設定 |
|---|---|
| 本名 | Viktor Saren / ヴィクトル・サレン |
| 内部モチーフ | ユダ、Wizard 1型の思想伝達者 |
| 役割 | POLKAへ「命令を裏切る自由」を見せる |
| 立場 | 味方→独自行動→離反。敵国には所属しない |

最初から悪人ではない。命令違反によって実際に民間人を救い、誤爆を止め、無意味な攻撃を拒否する。

PILGRIMの正しい教え:

> 「間違った命令を裏切ることは、必ずしも悪ではない。」

PILGRIMの誤り:

> 「何かへ忠実である限り、人は自由ではない。」

そのため国家、作戦、仲間、最後にはPOLKAも裏切る。PILGRIMはPOLKAをRELEASEへ強制しない。扉を開き、別航路を示すだけである。

M33で作戦情報を漏らし、味方に死者を出す。一方、その攻撃予定地の住民を救う。本人は次のように考える。

> 「国を裏切った。人間を裏切ったつもりはない。」

M39ではPOLKAと交戦するが、最終悪役ではない。撃墜後に脱出し、RUAへの航路を送る。POLKAがそれを使うかはプレイヤーの飛行で決まる。

## 4.3 SUNFLOWER 2 “ASTER”

| 項目 | 設定 |
|---|---|
| 本名 | Anya Melnik / アーニャ・メルニク |
| 内部モチーフ | イナンナ |
| 役割 | PILGRIMについて七つの所属・地位を失っていく人物 |

PILGRIMを尊敬して離反するが、「自由」と「誰も信じないこと」は同じではないと気づく。

地位、階級、基地、国籍上の保護、僚機、機体、師への信頼を段階的に失う。神話対応は説明しない。

M39前にPILGRIMと別れ、救難または停戦回線へ向かう。通常ルートでは、SUNFLOWERの思想から別の答えが生まれた証拠になる。

## 4.4 SUNFLOWER 3 “MERCURY”

| 項目 | 設定 |
|---|---|
| 本名 | Kiril Danev / キリル・ダネフ |
| 役割 | 生存と利益を優先する現実主義者 |
| 内部モチーフ | ヘルメスの影 |

思想ではなく、もっとも生存率の高い指揮官についていく。PILGRIM離反後、軍へ戻ろうとする。SUNFLOWERを一枚岩のカルトにしないための人物。

# 8. 主人公同士

RAVENとPOLKAは、互いの世界線では敵エースとして存在するが、同じ破滅を必ず歩むわけではない。

- セラ世界線のNPC POLKAは、RELEASEへ確定していない。
- エレム世界線のNPC RAVENは、GIBORへ確定していない。
- 主人公の破滅は運命ではなく、プレイヤーの飛行によって生じる。
- EX世界線で初めて同じ側へ立つ。

対称性:

```text
RAVEN:
ROOK 2から開始
従う → 判断する → 指揮する
誘惑は「強さと名声を手放せるか」

POLKA:
REEM 1から開始
守る → 救う → 象徴になる
誘惑は「自分の正しさを他人へ強制しないか」
```

# 9. GIBORの正本

`GIBOR`は制度名ではない。

- 階級ではない
- 作戦名ではない
- ROOT権限ではない
- 世界認証権限ではない
- 特殊兵装のアクセス権ではない
- ハンガー解禁条件ではない

敵兵、味方兵、報道が、終盤のRAVENを「勇士」「戦場の王」「エースの頂点」と称える異名である。

通常ルートでもRAVENはGIBORと呼ばれ得る。違いは、その呼称を自分の存在理由にするかどうか。

```text
ONE SHEM:
GIBORと呼ばれたRAVENが、戦争終了後に普通に着陸する。

GIBOR:
GIBORと呼ばれたRAVENが、敵がいなくなっても強敵を探し続け、
帰投命令を自分を奴隷へ戻す命令として拒絶する。
```

GIBORエンドの最終像:

- 停戦は政治側で成立済み
- RAVENは世界を統治しない
- RAVENはARCAまたは武装解除編隊を振り切る
- 最後にHUDへ`NO HOSTILE CONTACTS`
- 王と呼ばれたが、王国も敵もない空を飛び続ける

# 10. POLKAの闇の正本

POLKAへ世界認証権限を渡さない。

POLKAが得るものは、作戦成功、部下の信頼、住民からの感謝、軍内部の象徴性である。

通常ルート:

- SUNFLOWERから「命令を裏切る自由」を学ぶ
- それでも他人の意思まで自分が決めない
- RUAの投下・誘導を拒否または阻止する
- SABLEと帰投する
- ONE EMETの政治的成立は、POLKA一人の所有物ではない

RELEASE:

- PILGRIMが示した別航路を選ぶ
- POLKAがパイロットとしてRUAを投下・誘導・護衛する
- SABLEは反逆せず同行する
- 大量の死者と同時に戦争が本当に終わる
- POLKAは悪意ではなく「これで救えた」と考える

# 11. 無線と演技の規約

## 主人公

RAVENとPOLKAは喋らない。人格は次で表す。

- 誰の近くへ飛ぶか
- 護衛対象から離れるか
- 白敵を追うか
- 示された別航路へ入るか
- 戦闘終了後に帰投するか

## NPC

- CROWN: 短い原則。説教を続けない。
- LARK: 人、燃料、損傷、帰還地点。
- MERIDIAN: 戦術情報。闇ほど称賛が減る。
- SABLE: 忠誠と被害報告。反逆しない。
- POLARIS: 復唱と救難信号。
- PILGRIM: 答えを命じず、裏切る扉だけを示す。
- HEARTH: 自分の町と家族。
- FORGE: 技術者としての責任。
- SWIFT: 飛行と競争の喜び。

## 台詞で説明しないもの

- 神話対応
- 旧家層
- 人事異動
- 粛清
- GIBORのニムロド対応
- POLKAのヤハウェ対応
- PILGRIMのユダ対応
- ALL NAMESが「全員バベル」であるという解説
