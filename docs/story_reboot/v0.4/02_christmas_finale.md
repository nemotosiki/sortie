# 1. なぜクリスマスに戦うのか

戦争開始から11か月が経ち、両陣営は軍事的にも社会的にも限界へ近づいている。

ケデム共和国は、12月24日18:00から12月26日06:00までの36時間を、クリスマス人道休戦とする案を仲介する。

合意済みの項目:

- 有人航空機と地上部隊の前進停止
- 捕虜、負傷者、遺体、手紙の交換
- 病院、救難機、避難船への攻撃禁止
- 民間電力と水道の保護

合意できなかった項目:

- オファン無人防衛環を停止するか
- ギボルROOTを分割するか恒久化するか
- ルア搭載機を武装解除するか
- 休戦中の電子戦、認証停止、資産凍結を「攻撃」と数えるか

双方とも、相手が戦略兵器を保持したまま自軍だけ停止することを拒む。

# 2. 休戦が崩れる瞬間

12月25日05:31、二つの出来事がほぼ同時に発生する。

1. オファンの一基が、期限切れのシェム認証で進入したエレム医療輸送機を未確認機として追尾する。
2. ルア搭載機が、燃料不足を理由に待機空域からミガル方向へ移動を始める。

オファンは発砲していない。ルア搭載機も攻撃態勢を宣言していない。

しかし、セラ側には「休戦中に大量破壊兵器が前進した」と見える。エレム側には「休戦中に医療機が戦略防空へ捕捉された」と見える。

05:37、双方が防御目的として戦闘機を発進。

05:40、互いの発進を先制攻撃と判定し、最終決戦が始まる。

どちらが休戦を破ったかは断定しない。双方の記録は、自分の観測範囲では正しい。

# 3. ミガルのクリスマス景観

ミガルは戦争前から、世界各地の航空路が集まる都市だった。クリスマスは宗教儀礼だけでなく、帰省、物流、寄付、休戦の象徴として広く定着している。

最終マップには次を置く。

- 海岸沿いの低い祝祭灯
- 病院屋上の白い灯
- 港湾クレーンの赤い警戒灯
- 避難所へ続く青い誘導灯
- 軍事中枢オファンの巨大な白い環
- 破壊区画にも残る個人宅の小さな窓明かり

巨大な中央の光と、小さく分散した生活の光を同じ画面に置く。

# 4. セラ世界線 M22 — THE GUARANTOR

## 開幕

クリスマス休戦のため、通常の防空編隊は基地へ戻りかけている。ROOK 1は緊急発進し、ROOK 2、MERIDIAN、MICAとともにミガル中枢へ向かう。

### 味方

- ROOK 2
- オファン防衛ノード×12
- 市街防空隊
- CVN EPOCHの残存航空隊
- ROOT分割輸送隊または中央ROOT

### 敵

- REEM 1
- エメト攻撃隊
- ジャマー
- Tu-22M3級爆撃機
- ルア搭載機はセラ側からは正体不明の高危険目標として表示

## フェーズ

1. 医療回廊上空で敵先遣隊を迎撃する。
2. ジャマーを破壊し、オファンの識別能力を戻す。
3. 十二ノードを再接続し、市街へ向かう巡航弾を止める。
4. REEM 1と交戦しながら、ROOT分割輸送隊または中央環を守る。
5. 戦争を終わらせた後、ROOTの保持形態が確定する。

## ONE SHEM

ROOT分割が残っている場合、四評議会への移送を守る。

- オファンは共同管理へ戻る。
- 休戦は遅れて発効する。
- シェムは残るが、一人の所有物にはならない。
- クリスマス灯は区画ごとに再点灯する。

最後にROOK 1のHUDから、世界規模の認証項目が一つずつ消える。残るのは自機の高度、速度、燃料だけである。

## GIBOR

分割手段が失われている場合、ROOK 1がオファン全権限を保持する。

- 敵機、ルア、ミサイルは遠隔停止される。
- 戦争は短時間で終わる。
- 世界の航空、医療、物流、信用が一人の承認へ集約される。
- 祝祭灯は全世界で同時に点灯し、同じ色、同じ時刻、同じ周期で明滅する。

誰も爆撃されない。誰も飢えない。誰もROOK 1の外へ出られない。

# 5. エレム世界線 M44 — LAST LIGHT

## 開幕

エメト側は、オファンが医療回廊を再び閉じたと判断する。REEM 1は通常攻撃隊またはルア搭載機とともにミガルへ進入する。

### 味方

- REEM 2（生存時）
- エメト攻撃隊
- 通常攻撃爆撃機
- ルア搭載機（解禁時のみ）
- POLARIS

### 敵

- オファン防衛ノード×12
- 無人機格納庫×4
- 認証コア×3
- セラ防空隊
- ROOK 1の遠隔支援
- 防空巡洋艦

## フェーズ

1. 医療回廊を塞ぐ外周ノードを無力化する。
2. 無人機格納庫と認証コアを選んで破壊する。
3. 通常攻撃隊が軍事ROOTへ向かい、ルア搭載機は最短経路を進む。
4. プレイヤーはルア搭載機を守ることも、自ら撃墜することもできる。
5. 通常ルートでは中央環内部へ入り、部位を一つずつ破壊する。

## ONE EMET

ルアを使わず、軍事ROOTだけを通常攻撃で破壊する。

- シェムによる凍結は解除される。
- ミガルの病院、港、民間通信は残る。
- エメトは一つの盟約による新秩序を作る。
- クリスマス灯は各地区で異なる時刻に戻る。

解放は成功する。ただし盟約の外へ出る自由は、これから試される。

## RELEASE

ルア搭載機を最後まで護衛する。

- 大爆発ではなく、白い光が都市を一周する。
- オファン、送電、医療、通信、認証が順番に停止する。
- 戦争は即座に終結し、エメト側の将来の戦死者は大幅に減る。
- クリスマス灯は、都市の端から中心へ向かって全て消える。

主人公は都市を苦しみ得る未来から解放した救世主として迎えられる。

# 6. 同じ時刻・同じ場所を使う理由

M22とM44は、同じ12月25日05:40、同じミガル中枢で始まる。

- セラ世界線ではROOK 1が到着するため、オファン防衛が成立する。
- エレム世界線ではREEM 1が到着するため、外環突破が成立する。
- どちらの主人公も、自分が飛んだ世界線では本当に戦争を終わらせる。

プレイヤーだけが、勝利したのは正義の陣営ではなく、自分が操縦した陣営だと知る。

# 7. 音と演出

## 開幕前

- 戦闘音楽を流さない。
- 遠くのクリスマス曲を、ラジオや市街スピーカーの環境音として小さく入れる。
- 休戦予定時刻、患者輸送数、未交換捕虜数を表示する。

## 開戦

- 05:40に市街の一部照明が警戒モードへ変わる。
- 祝祭曲は途切れず、警報と重なる。
- 最初のミサイル発射後に初めて戦闘音楽へ移る。

## 終盤

- 通常ルートは長く、複数の部位と人間を守る必要がある。
- 裏切りルートは短く、同期し、効率的で、プレイ上も強い。
- 裏切りを暗いBGMで罰しない。勝利、感謝、帰還、平和を本当に描く。
- その映像の隅で、拒否権、個人名、異なる灯りが失われる。

# 8. クリスマスのテーマ上の役割

ゲーム内で神学的な説明はしない。内部設計上は、12月25日に次を重ねる。

- 一人の救世主へ世界を預ける誘惑
- 救済の名で他人の選択を奪う危険
- 家族、僚機、患者、敵兵を具体的に気遣う小さな愛
- 大きな中央の光と、無数の個別の灯り

真の答えは、主人公が世界の救世主になることではない。

> 自分なら正しく救える時でさえ、他人の未来を自分の所有物にしないこと。

クリスマス最終決戦は、その答えを最も誤解しやすい日に置く。
