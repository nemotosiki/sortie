# ARCAの陣営関係と非TGT敵規約 v0.10

**状態:** 歴史的な関係設計。HUD色・得点・実装順はv0.12が正本。  
**優先:** 本書の「セラ序盤は準友軍、セラ中盤以降とエレム全編は敵」という関係は継承する。ただし敵対ARCAの表示は赤ではなく白、得点とランクはv0.12へ読み替える。

# 1. 用語

ARCAは「ロックオンできない中立物」ではない。

本作では次を分けて扱う。

- **TGT:** ミッションの主目標・撃墜必須目標。HUDに`TGT`を表示し、撃破数やクリア条件へ入る。
- **非TGT敵:** 通常の敵。ロックオン、攻撃、被弾、撃墜が可能で、敵自身もプレイヤーを攻撃する。ただし撃墜はミッションクリアに不要。

敵対時のARCAは、後者の**非TGT敵**である。

```text
faction: ARCA
side: enemy
tgt: false
lockable: true
combatAI: true
canDamagePlayer: true
canBeDestroyed: true
countsForClear: false
rankNeutral: true
```

# 2. キャンペーン別の関係

| キャンペーン | 時期 | ARCAの扱い | プレイヤーへの攻撃 |
|---|---|---|---|
| セラ編（アメリカ側） | 序盤 | 準友軍・共同交戦勢力 | しない |
| セラ編（アメリカ側） | 中盤以降 | 非TGT敵 | する |
| エレム編（ロシア側） | 序盤から最終盤まで | 非TGT敵 | する |

## 2.1 セラ編序盤

ARCAは中立を名乗るが、西側起源の装備、訓練、データリンク、補給網を使うため、序盤は事実上セラ寄りに行動する。

- セラと同じ敵を攻撃する。
- セラ機を攻撃しない。
- セラの作戦空域を黙認する。
- 正式な僚機ではなく、命令もできない。
- ARCA機の生存は護衛条件、評価、後続展開へ影響しない。
- ARCA機が全滅してもミッションは通常どおり続く。

HUD上は青い友軍・準友軍色で表示し、`TGT`は付けない。

## 2.2 セラ編の転換

中盤の章境界に、ARCAがセラにも武力を向ける転換ミッションを一度だけ明確に置く。

理由は、セラとエレムの双方がARCA加盟国の領空、人道回廊、停戦命令を無視し、ARCA強硬派が主導権を握るためである。

転換後の原則:

- ARCAはセラ機を通常攻撃する。
- セラ側HUDでは白い非TGT敵表示になる。
- `TGT`にはならない。
- 撃墜しても、無視しても、本来の作戦目標と物語分岐は変わらない。

IFF変更を曖昧にしない。転換ミッションで敵対開始を明示した後は、セラ編終盤まで敵対状態を固定する。

## 2.3 エレム編

ARCAは開戦以前からエレムを主要脅威と見なしている。したがって、エレム編では最初の任務から最後まで敵である。

- エレム機をロックし、機銃とミサイルで攻撃する。
- プレイヤーは通常どおりロックオンし、撃墜できる。
- 全機が白い非TGT敵で、撃墜必須にはならない。
- 中盤以降にARCAがセラとも敵対しても、エレム側から見たゲーム上の関係は変わらない。

エレム側の人物からは、ARCAは序盤から「中立を名乗る西側補助軍」と見える。

# 3. ミッションへの影響を持たせない契約

敵対ARCAは通常の戦闘AIを持つが、キャンペーン進行を壊してはならない。

## 3.1 クリア・失敗・物語

- `mission.totalTargets`へ含めない。
- 必須撃破数へ含めない。
- ARCA撃墜をクリア条件、失敗条件、任意目標にしない。
- ARCAの生存・撃墜を後続ミッション、友好度、エンディング、世界状態へ保存しない。
- ARCAを全機無視してもクリアできる。
- ARCAを全機撃墜しても物語は変わらない。

## 3.2 スコアとランク

ARCA撃墜は、普通の非TGT敵と同じく小さなボーナス得点を与える。ただしARCAを倒さないことがランク上の不足になってはならず、倒したことでS条件が緩くなってもならない。

実装契約:

```text
撃墜時:
  bonus scoreを加算
  bonus kill表示へ加算
  rankStats.playerKillValueへは加算しない

出現時:
  rankStats.spawnedValueへ加算しない
```

これにより、ARCAを撃墜すれば表示得点は増えるが、一機も撃墜せず本来の作戦へ集中してもSランクを取れ、撃墜によってS判定を買うこともできない。

## 3.3 攻撃対象

ARCAは次を攻撃できる。

- プレイヤー
- 通常の友軍戦闘機
- ミッション成否に関係しない戦闘ユニット

ARCAは次を攻撃対象にしない。

- 護衛対象
- 病院船、輸送機、避難車列などの失敗条件ユニット
- 撃破・生存によってフェーズが変わる主目標

ARCAの行動だけで護衛失敗やTGT消失が起きないよう、AIの標的フィルターを分ける。

# 4. 所属機と登場密度

ARCAの主な所属機:

- Typhoon
- Rafale M
- Gripen E
- F-3

F-2Aはセラ編のプレイアブル機として残す。

通常のARCA編隊は2〜4機を基本とする。非TGT敵が本来の敵より多くならないようにする。

F-3はARCAの最上位研究機なので、序盤には登場させない。セラ編中盤以降およびエレム編中盤以降に、原則1機、特別な戦闘でも最大2機まで出す。F-3も通常どおりプレイヤーを攻撃するが、`TGT`にはしない。

# 5. HUDとターゲット選択

## セラ編序盤

```text
ARCA
SUPPORT
```

- 青い友軍・準友軍色
- ロックオン候補から除外
- `TGT`表示なし

## 敵対時

```text
ARCA
```

- 白い非TGT敵色
- ロックオン候補へ入る
- ミサイル、機銃で攻撃可能
- `TGT`表示だけは絶対に付けない

「ターゲットではない」とはロックオン不能という意味ではなく、**ミッション指定目標ではない**という意味である。

# 6. 実装上の固定フラグ

ミッション定義側では、同じARCA機体IDを陣営だけ切り替えて使う。

```text
セラ序盤:
  side = support
  tgt = false
  attacksPlayer = false

セラ中盤以降:
  side = enemy
  tgt = false
  rankNeutral = true
  attacksPlayer = true

エレム全編:
  side = enemy
  tgt = false
  rankNeutral = true
  attacksPlayer = true
```

機体モデルそのものへ「常に中立」「常に非攻撃」を埋め込まない。攻撃性は敵AIプロファイルとして保持し、セラ序盤だけ友軍スポーン経路を使う。
