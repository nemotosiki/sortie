# 1. 結論

F-3、F-22、Su-57は同じ最上位性能帯に置くが、同じ数値のコピーにはしない。

**F-3は三機の中で機動性に最も優れる。**

総合的な戦闘力は同格とし、強みを次のように分ける。

| 機体 | 最大の強み | 弱点・相対的な不足 |
|---|---|---|
| F-22 | 加速、速度維持、安定性、遠距離戦 | 三機中では旋回性能をやや控えめにする |
| Su-57 | 低速機動、ヨー、瞬間旋回、ポストストール | 激しい機動で速度を失いやすい |
| **F-3** | **高速域の旋回、持続旋回、ロール、ピッチ応答** | 最高速・加速・低速超機動では他二機に譲る |

# 2. F-3の機動性

F-3の特徴は、失速寸前で機首を無理に振る機体ではなく、**戦闘速度を保ったまま連続して向きを変えられる機体**とする。

優先順位:

1. 三機中最高の持続旋回率
2. 三機中最高のロール率
3. 三機中最高、または同率最高のピッチ応答
4. 高G旋回後の速度回復が早い
5. 高速域でも操縦応答が鈍りにくい
6. 低速ポストストール性能はSu-57より下
7. 最高速と直線加速はF-22より下

プレイヤーから見た印象は、

> 一度かわす敵ではなく、かわした直後にもう一度進路へ入ってくる機体

とする。

# 3. 三機の相対順位

数値は実装時に現行の機体性能表と実測して確定する。先に相対順位だけを固定する。

| 軸 | 1位 | 2位 | 3位 |
|---|---|---|---|
| 最高速 | F-22 | Su-57 | F-3 |
| 加速 | F-22 | F-3 | Su-57 |
| 持続旋回 | **F-3** | Su-57 | F-22 |
| 瞬間旋回 | Su-57 | F-3 | F-22 |
| ロール | **F-3** | F-22 | Su-57 |
| ヨー・低速機首振り | Su-57 | F-3 | F-22 |
| 安定性 | F-22 | F-3 | Su-57 |
| エネルギー保持 | F-22 | F-3 | Su-57 |
| 失速後の回復 | F-3 | F-22 | Su-57 |
| 総合戦闘力 | 同格 | 同格 | 同格 |

# 4. F-3のAI挙動

F-3はアルカの`NON-TARGET`妨害機であり、指定目標や護衛対象を攻撃しない。

機動性は次の妨害に使う。

- プレイヤーの進路正面へ短時間で回り込む
- 一度離脱してから、別角度で再び横切る
- 高速ロールで照準線から外れる
- チャフとフレアを使いながら編隊位置を組み替える
- 狭い峡谷ではなく、十分な空間のある高高度・外洋・都市外環で使う

禁止:

- プレイヤーへ実弾を撃つ
- 指定目標を守ってミッションを遅延させる
- 護衛対象を攻撃する
- Sランク成立時間を変える
- 3機以上を同時に出す

通常は1機、特別な場面でも2機までとする。

# 5. バランス契約

F-3を「F-22とSu-57の全能力を上回る機体」にはしない。

実装時は、三機の総合性能スコアが近い範囲に収まるよう調整する。

F-3へ高い機動性を与える代わりに、少なくとも次の二つを下げる。

- 最高速または加速
- HP、通常ミサイル搭載量、遠距離性能のいずれか

ただしF-3はアルカ専用かつ非武装妨害機として使うため、ミッション中の実効的な強さは主に回避性能で表現する。攻撃性能を盛って帳尻を合わせない。

# 6. 見た目と演出

F-3の機動性は数値だけでなく、次で見せる。

- 大きな主翼でも軽く見える高速ロール
- 旋回中に失速煙を長く引かず、速度を保つ
- エンジン推力偏向だけに頼らず、主翼と尾翼で滑らかに曲がる
- 交差後に大きく離れず、短い弧で再進入する
- F-22の直線的な安定感、Su-57の低速超機動と明確に違う軌跡

F-3は「最強の火力」ではなく、**最も捕まえにくい機体**として記憶させる。
