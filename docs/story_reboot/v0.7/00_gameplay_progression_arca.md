**正本:** v0.7

**優先関係:** 機体ロスター、購入許可、F-22／Su-57報酬、SR-71迎撃、アルカの扱い、ミッション密度、護衛任務の公平性については本書を最優先する。CROWN / LARKの正史搭乗機だけはv0.15/03を優先する。

# 1. ゲーム進行の基本思想

新キャンペーンでは、機体を単なる性能順の買い物にしない。

```text
前の任務で戦果を上げる
  ↓
資金が増える
  ↓
次の任務に適した専門機を買える
  ↓
同じ任務でも攻略法と危険度が変わる
```

ただし、資金だけで最上位機へ飛べないようにする。

通常機は作戦進行で購入許可が増え、そのうえで資金を払って購入する。Sランクやネームド撃墜による複雑な早期解禁は使わない。

例外は以下の二種類だけである。

- ストーリー上どうしても必要な機体は、直前任務で自動支給する。
- F-22とSu-57だけは、各キャンペーン全20ミッションSのやり込み報酬として直接支給する。

# 2. 解禁方式

## 2.1 通常機

- 指定ミッションをクリアすると購入許可が出る。
- 購入にはキャンペーン別の資金が必要。
- ランク、ネームド撃墜、任意目標による早期解禁は行わない。
- 購入許可前に資金が十分あっても買えない。
- 一度許可された機体は、その世界線のFREE MISSIONでも使える。

## 2.2 自動支給機

- 特定任務のゲーム性を成立させるための機体。
- ランクと資金に関係なく永久所有になる。
- 代表例は、SR-71高高度迎撃の直前に支給されるMiG-31。

## 2.3 全S報酬

### セラ編

```text
条件: セラ編M01〜M20の全ミッションで最高記録S
報酬: F-22を直接支給
価格: 0 CR
```

### エレム編

```text
条件: エレム編M21〜M40の全ミッションで最高記録S
報酬: Su-57を直接支給
価格: 0 CR
```

F-22とSu-57は初回本編中には購入できない。敵・宿敵としてのみ登場し、キャンペーン全クリア後のFREE MISSIONで使う最終やり込み機体とする。

# 4. 序盤の模範ゲーム性

セラM01〜M04は、新キャンペーン全体の進行設計の基準とする。

## 4.1 M01〜M03

- ただクリアするだけでもF-4を買える程度の資金が貯まる。
- 任意敵、支援機、ネームド、短時間クリアを含めて高戦果ならF-2Aを買える。
- どちらも買わずF-16のまま進むことも可能。

## 4.2 M04艦隊戦

### F-2A＋LASM

- 前3任務で多く稼いだプレイヤーの安全な攻略法。
- 艦隊防空圏の外から主力艦を攻撃できる。
- LASM弾数は有限で、空戦には通常ミサイルを使う。

### F-4＋UGB

- 通常進行で買える標準攻略法。
- SAMとCIWSを避けながら低空接近する。
- 無誘導爆弾なので対ミサイル迎撃へ依存せず艦を破壊できる。
- 危険だが高火力。

### F-16

- 無購入で挑む技能攻略。
- 防空巡洋艦、CIWS、護衛機を順番に崩す。
- ミサイルを迎撃されるため時間と接近技術が必要。
- クリア可能だが、専門機より明確に難しい。

この構造を、対地、迎撃、護衛、夜間、電子戦、高高度の各任務でも繰り返す。

# 5. エレム編の難易度

エレム編はセラ編より一段難しくする。

## セラ編

- 一つの任務で一つの新要素を教える。
- 味方支援が比較的多い。
- 初期機F-16が万能。
- 敵の進入方向を読みやすくする。

## エレム編

- セラ編で学んだ二つの要素を同時に要求する。
- 夜間、峡谷、高高度、電子戦、偽IFF、複数方向攻撃を組み合わせる。
- 味方支援を少なめにする。
- 初期機MiG-21には速度、旋回、弾数の明確な制約を持たせる。
- 専門機の選択をより重要にする。

ただし以下は禁止する。

- 敵HPの不自然な増加
- 護衛対象の至近距離スポーン
- 出現直後の即時発射
- 最低機体では時間切れになる設計
- 初見では知り得ない正解順の強要
- ランダム要素によってSランクが不可能になる設計

# 6. SR-71高高度迎撃

## 6.1 前任務

エレム中盤の前任務で、北方早期警戒基地とMiG-31格納庫を防衛する。

クリア時、成績と資金に関係なく表示する。

```text
AIRCRAFT ASSIGNED
MiG-31B FOXHOUND
```

MiG-31は永久所有となり、次の初回出撃では自動選択する。FREE MISSIONでは機体自由とする。

## 6.2 本任務

### 仮題

`THIN SKY`

### 主目標

セラのSR-71が戦略偵察データを送信し終える前に撃墜する。

### 三段構成

1. **上昇・経路確保**
   - F-15級護衛
   - EA-18G級電子戦機
   - デコイドローン
   - 空中給油機

2. **予測迎撃**
   - SR-71の後ろを単純に追わない。
   - 地上レーダーが断続的に予測交差点を送る。
   - MiG-31の速度と上昇性能で先回りする。
   - 電子戦機が残っていると予測点の更新が遅れる。

3. **送信阻止**
   - SR-71が損傷すると中立空域へ向かいながら送信を開始。
   - 護衛増援が到着。
   - SR-71を優先すればクリア、支援機まで処理すればSを狙える。

# 7. アルカ共同治安機構

## 7.1 組織の立場

アルカは中立を名乗る小国連合の航空治安維持組織である。

ただし設立、装備、データリンク、訓練、補給は西側起源で、序盤は実質的にセラ寄りである。

- セラの進入を黙認しやすい。
- エレムへ先に警告する。
- シェムの航空認証へ依存する。
- エレム側からは「中立を名乗る西側補助軍」と見られる。

戦争中盤以降、セラもエレムも中立空域と人道回廊を無視するため、アルカ強硬派が主導権を握る。

```text
中立を守るため、すべての交戦国を空から排除する。
```

という思想へ進み、セラとエレムの双方へ敵対的な飛行を行う。ただし最後まで宣戦布告せず、行動を「治安維持」「停戦執行」と呼ぶ。

## 7.2 所属機

| 機体 | 用途 |
|---|---|
| Typhoon | 高高度監視・高速割り込み |
| Rafale M | 海峡・艦隊・病院船周辺の監視 |
| Gripen E | 小国道路基地・峡谷・分散展開 |
| F-3 | アルカ最上位の三国共同研究機・強硬派の象徴 |

F-2Aはアルカへ移さず、セラのプレイアブルに残す。

# 8. F-3

## 8.1 現実モチーフとゲーム内設定

現実のモチーフは、日本、英国、イタリアが共同開発を進めるGCAP次期戦闘機である。ゲーム内では実在国名を使わず、アルカ加盟三国が共同研究した試作機を正式に`F-3`と呼ぶ。

現実の機体設計は確定前であるため、ゲームモデルは特定の公式完成形を再現したと主張しない。GCAPの公開コンセプトから、双発、低被探知性、大型デルタ／台形翼、広いセンサー統合能力を持つ独自機として造形する。

## 8.2 性能契約

F-3、F-22、Su-57の三機は、新キャンペーンの最上位性能帯として同格にする。

実装時には三機へ共通の`TOP_TIER_BASELINE`を設定し、以下を同値にする。

- 最大HP
- 巡航速度
- 最大速度
- 加速応答
- 減速応答
- ピッチ、ロール、ヨー
- 持続旋回性能
- 通常ミサイル威力
- 通常ミサイル搭載数
- 構造G
- 失速余裕

外見、排気色、所属、AI行動、無線、特殊兵装の表示は異なってよいが、総合戦闘性能をF-22やSu-57より上にはしない。

F-3は本編でプレイアブルにしない。アルカ専用のNON-TARGET機として登場する。

## 8.3 登場時期

- 序盤には出さない。
- WAR DAY 200以降、アルカ強硬化の兆候として試験飛行を見せる。
- 後半では一度に1〜2機だけ登場する。
- EX章ではアルカ残存強硬派の最上位妨害機として再登場可能。

F-3が大量配備されると研究機・象徴機としての価値が失われるため、同時出現上限は2機とする。

# 9. アルカ機のゲーム上の契約

アルカ機は一貫して次の扱いとする。

```text
HUD: ARCA / NON-TARGET
ロックオン: 可能
攻撃・撃墜: 可能
撃墜スコア: 0
ランク計算: 除外
指定目標数: 含めない
ミッション成功・失敗: 影響なし
後続ミッション: 影響なし
エンディング: 影響なし
友好度・報復: なし
```

アルカは戦術上の邪魔をするだけで、物語分岐や達成条件には関与しない。

許可する妨害:

- レーダーとターゲット切替候補へ混ざる。
- プレイヤーを警告ロックし、RWRを鳴らす。
- プレイヤーと敵の間を高速で横切る。
- チャフ、フレアを多用する。
- 編隊で進路正面へ展開する。
- 狭い峡谷や高高度航路で視覚的な圧力をかける。

禁止する妨害:

- 指定目標を撃墜する。
- 護衛対象を攻撃する。
- 敵の逃走や目的達成を直接助ける。
- プレイヤーのミサイルを意図的に迎撃する。
- ミッションタイマーを変える。
- Sランクの理論可否を変える。
- アルカ撃墜を必須または罰にする。

アルカを無視しても、全ミッションをクリアしSランクを取れることを検証する。

# 10. ミッション密度

過去の「輸送機2機だけを落として終了」のような薄い任務は禁止する。

通常任務は原則として三フェーズを持つ。

1. 状況を作る前衛戦
2. 本来の主要任務
3. 増援、逃走、ネームド、救難、帰投遮断などの変化

目安:

| 種別 | 目安 |
|---|---:|
| 通常任務 | 7〜12分 |
| 大規模任務 | 11〜16分 |
| エース決闘 | 5〜9分 |
| 通常任務の総接触 | 12〜22 |
| 大規模任務の総接触 | 22〜35 |
| 同時空中敵 | 通常6〜10、最大12〜16 |
| 地上目標 | 6〜14 |
| 大型艦 | 4〜6 |
| 小型艦 | 4〜8 |

指定目標が少ない任務でも、前衛、護衛、支援、識別、逃走などで戦闘と判断を成立させる。

# 11. 護衛任務とSランク

護衛ウェーブは距離ではなく、最初の攻撃までの時間で検証する。

```text
enemyThreatTime
  = (敵から護衛対象までの距離 - 敵射程) / 接近速度

playerInterceptTime
  = プレイヤーから迎撃点までの距離 / 到達速度

NORMALで
  enemyThreatTime - playerInterceptTime >= 4〜6秒
```

必須条件:

- 敵を護衛対象の射程内へ直接出さない。
- 出現時に発射角が完成していないこと。
- プレイヤーが敵と護衛対象の間へ入れること。
- 増援前に警告を出すこと。
- チェックポイント後も同じ猶予を持つこと。
- スポーン乱数でSランク可否が変わらないこと。
- 初期機またはその時点で必ず所有できる機体でクリア可能なこと。
- 専門機ならSが現実的で、初期機でも高技能ならSが理論上可能なこと。
