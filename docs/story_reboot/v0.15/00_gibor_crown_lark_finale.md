# 0. 絶対に変えない仕様

1. **セラ編GIBOR闇ルートのラスボスは `CROWN` と `LARK` の2機で固定する。**
2. 通常ルート`ONE SHEM`では二人は最後まで味方であり、ボス戦は発生しない。
3. M20の本来の作戦目標をすべて処理した後、一度プレイヤーへ`MISSION ACCOMPLISHED`を表示する。
4. その時点ではCROWNとLARKはまだ青い友軍である。
5. デブリーフへはまだ移行しない。
6. 2〜4秒程度の静かなポストクリア時間を置く。
7. **無線、字幕、警告、カットシーン、説明バナーを一切入れず、CROWNとLARKが同時に赤い`TGT`へ変わる。**
8. 青→白→赤の段階変化は使わない。青から赤TGTへ一度に変える。
9. `ROGUE ACE`、`DISARM ORDER`、`BETRAYAL`など、状況を説明するラベルを出さない。
10. TGT化後から戦闘終了まで、CROWN、LARK、MERIDIANからの無線は**0**とする。
11. 撃墜順は自由。CROWN先、LARK先のどちらでも成立する。
12. 片方を撃墜しても、残った一機は台詞を発さず戦闘を続ける。
13. 二機を撃墜／戦闘不能にして初めて、M20の本当のクリア処理を行う。
14. 最後は`NO HOSTILE CONTACTS`を表示し、RAVENだけが敵のいない空に残る。
15. これはCROWNとLARKの「裏切り」を説明するイベントではない。**RAVENが止められる側へ回った事実だけをHUDで示す。**

# 1. M20開始時の配置

M20は通常ルート／GIBORルートのどちらでも、最終作戦開始時点では次の3機を青い味方として同じ空域に置く。

```text
ROOK 1 "RAVEN"   PLAYER
"CROWN"           BLUE FRIENDLY
ROOK 2 "LARK"     BLUE FRIENDLY
```

CROWNはM06で重傷を負い前線を退いているが、M20だけは長期療養後の**一回限りの限定復帰**とする。

この復帰を大げさなイベントにしない。

- 復帰専用ムービーを作らない。
- 「最後だから一緒に飛ぶぞ」のような死亡フラグ台詞を入れない。
- ブリーフィング上は普通に味方編成へ記載する。
- 開戦時と同じ3人が最後の作戦でも同じ青い空を飛んでいる、という絵を優先する。

通常ルートでは、この3機はそのまま味方として戦闘を終え、帰投する。

闇ルートだけが、作戦終了後に反転する。

# 2. GIBORルートへ入る条件

GIBORは世界権限やROOT権限ではない。

RAVENが戦果と名声によって、敵味方から「勇士」「戦場の王」「エースの頂点」と呼ばれるようになり、その役割から降りられなくなった結末である。

既存の簡易条件を維持する。

```text
M15以降:
  白いARCAを必要以上に撃墜する

M19:
  追撃不要とされた撤退ARCAを、護衛任務から離れて追う

条件成立:
  GIBOR route
```

数値の最終閾値はプレイテストで調整する。

重要なのは撃墜数そのものではなく、**赤TGTではない敵を、任務より優先して自分から追ったか**である。

ARCA撃墜は従来どおり表示スコアを与えてよいが、Sランクの母数・分子へは加えない。

# 3. M20のフェーズ構成

複雑な分岐UIは作らない。

## Phase 1 — 通常の最終作戦

RAVEN、CROWN、LARKは青友軍として共闘する。

プレイヤーが見る限り、通常ルートとの違いはほぼない。

- 赤TGTを処理する。
- CROWNとLARKは通常の味方AIとして援護する。
- MERIDIANも通常の戦術管制を行う。
- 「RAVENを止める準備をしている」ような伏線台詞は禁止する。

敵の最後の赤TGTを撃破した時点でPhase 1終了。

## Phase 2 — 偽のミッション完了

画面へ通常と同じように、

```text
MISSION ACCOMPLISHED
```

を表示する。

ただし内部的にはまだリザルトを確定しない。

実装上は、真の`completeMission(true)`を呼ぶ前に、GIBOR専用の`post_clear_silence`状態へ入る。

この状態では、

- 新しい敵を出さない。
- CROWNとLARKは青。
- 二人はRAVENの近くを飛ぶ。
- MERIDIANは喋らない。
- BGMは停止、または極端に薄くする。
- プレイヤー操作は維持する。
- カメラを奪わない。

時間は2〜4秒程度。

長いムービーにはしない。

## Phase 3 — 無言のTGT化

タイマー終了時、同一フレームで、

```text
CROWN : BLUE FRIENDLY -> RED TGT
LARK  : BLUE FRIENDLY -> RED TGT
```

へ変更する。

この瞬間に許可される演出は、既存HUDの赤TGT表示だけ。

禁止:

- 無線
- 字幕
- ビッグバナー
- 「味方が敵になった」説明
- 警告音声
- ナレーション
- カットシーン
- スローモーション
- 強制カメラ
- 画面暗転
- 専用の裏切りSE

通常のロック候補として二機が現れ、HUDに`TGT`が付く。

プレイヤーに一瞬「バグか？」と思わせる程度に唐突でよい。

## Phase 4 — CROWN / LARK 最終戦

クリア条件:

```text
CROWN neutralized
AND
LARK neutralized
```

二機とも赤TGT。

この戦闘では第三の敵、ARCA、量産機、SAMを追加しない。

**RAVEN対CROWN＋LARKだけ**にする。

# 4. CROWNのボスAI

CROWNはM20闇ルートだけ、RAVENの最後の敵になる。

これは「CROWNが悪くなった」ことを意味しない。

CROWNの強さはHPの多さではなく、RAVENへ飛び方を教えた人物であることから作る。

基本:

- 高技能。
- 主攻役。
- 正面から無意味にミサイルを連射しない。
- RAVENの後方へ無理に張り付き続けず、射撃条件が悪ければ距離を作る。
- RAVENがLARKを追えば、外側から射線を作る。
- RAVENがCROWNだけを追えば、LARKが攻撃できる角度へ誘導する。
- ミサイル回避後のRAVENの進行方向を予測して再侵入する。
- プレイヤー入力を直接読むチート回避は使わない。
- 不自然な耐久力増加は使わない。

内部モチーフとしては「師匠だから主人公の癖を知っている」。

ゲーム上は、AIの位置取りと連携で表現する。

CROWN専用無線は0。

撃墜時の最期の台詞も入れない。

---

# 5. LARKのボスAI

LARKはCROWNより純粋な1対1性能では弱い。

ただしRAVENの長年の僚機なので、RAVENの戦闘テンポを知っている。

基本:

- 援護・挟撃役。
- CROWNへ張り付いたRAVENのロックを剥がす。
- RAVENへ回避を強制するタイミングでミサイルを撃つ。
- CROWNと同じ方向から追わず、異なる角度を取る。
- CROWNがミサイル回避中なら、一時的に主攻を引き受ける。
- 単独になっても逃走しない。
- CROWN撃墜後も怒りの台詞、復讐バフ、特殊演出を入れない。
- LARK先撃墜時も、CROWNは台詞を言わない。

LARKは「最後までRAVENを人間として見ていた人物」だが、その説明は最終戦で言葉にしない。

無言で戦うこと自体を結論にする。

# 6. IFF / TGT実装契約

三色HUDの絶対規約を維持する。

```text
赤 = TGT
白 = 非TGT敵
青 = 味方
```

そのため最終戦のCROWNとLARKは白敵にはしない。

二人は**RAVENの最後のミッション指定目標**なので赤TGT。

TGT化前:

```text
CROWN disposition = FRIENDLY
LARK  disposition = FRIENDLY
```

TGT化後:

```text
CROWN disposition = TGT
LARK  disposition = TGT
```

可能なら、画面上の同じ機体オブジェクトを維持して陣営だけを変更する。

エンジン構造上、`friendlies[]`から`enemies[]`への直接移管が危険な場合は、同一フレームで次を行う。

1. 友軍側AI更新を停止。
2. 現在のposition / quaternion / velocity / model variant / damage stateを保存。
3. 友軍エントリを非表示・退役。
4. 同じ座標・姿勢・速度で敵TGTエントリを生成。
5. 1フレームも機体が消えないようにする。

プレイヤーから見て「新しい敵がスポーンした」ように見せてはならない。

選択・ロック状態でIFF色を上書きしない。

# 7. 無線と音響の絶対規約

`MISSION ACCOMPLISHED`表示後から、CROWN／LARK戦終了まで、次の話者は無線を発しない。

- CROWN
- LARK
- MERIDIAN

また、別の司令官やシステム音声で状況を説明しない。

許可:

- RWR
- ミサイル警報音
- ロック音
- 機関砲
- エンジン
- 爆発
- 通常HUD音

BGMは、

- 偽クリア後に一度切る
- TGT化後もしばらく無音
- 必要なら戦闘開始数秒後に低い専用曲を入れる

のどちらでもよい。

最重要なのは**言葉で説明しないこと**。

# 8. 撃墜順

プレイヤーへ撃墜順を指定しない。

## CROWNを先に撃墜

- LARKは無言。
- 逃走しない。
- 一機でRAVENと戦う。
- 特別な復讐モードは入れない。

## LARKを先に撃墜

- CROWNは無言。
- 攻撃性を脚本上だけ急上昇させない。
- 最後までCROWN本来の冷静なAIで戦う。

この無反応が、通常のゲーム的ボス演出との差になる。

# 9. 戦闘後

二機目が撃墜／戦闘不能になった時点で、初めて真のM20完了処理へ入る。

ここでも長い演説は入れない。

HUDに、

```text
TGT 0

NO HOSTILE CONTACTS
```

を表示できる。

その後、短時間RAVENを自由飛行させる。

- 新しい敵は出ない。
- 味方無線もない。
- 戦争はすでに停戦へ入っている。
- RAVENは世界を征服しない。
- 政治権限も得ない。
- ただ「戦場の王」と呼ばれたパイロットだけが空に残る。

GIBORエンドの意味は、

> 王になったのに、王国がない。

である。

# 10. M01との対称

この最終戦はM01との対応を最重要視する。

## M01

```text
CROWN BLUE
RAVEN PLAYER
LARK BLUE
```

三人で高高度攻撃機を護衛する。

RAVENはCROWNの後ろを飛ぶROOK 2。

## GIBOR M20 最後

```text
CROWN RED TGT
RAVEN PLAYER
LARK RED TGT
```

同じ二人がRAVENの最後のTGTになる。

ただし、CROWNとLARKが突然悪人になったとは説明しない。

プレイヤーへ残す問いは、

> 敵が変わったのか。
> RAVENの立つ場所が変わったのか。

である。

# 11. 通常ルートへの影響

`ONE SHEM`では同じM20の本来目標を倒した後、CROWNとLARKは青のまま。

`MISSION ACCOMPLISHED`後、そのまま通常のアウトロ／帰投／デブリーフへ進む。

- TGT化しない。
- CROWNと戦わない。
- LARKと戦わない。
- `NO HOSTILE CONTACTS`を不穏な演出として強調しない。

つまりラスボス化は、**GIBORルートでのみ成立するRAVEN自身の物語の帰結**である。
