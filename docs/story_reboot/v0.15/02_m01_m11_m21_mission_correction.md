# 0. 絶対に変えない訂正

1. `M01 FIRST CONTACT`は**レン湾へ侵入するエレム爆撃機編隊の通常迎撃**である。
2. M01に高高度攻撃機護衛、特殊高度管理、北／南の二択を入れない。
3. M01の主役は開戦時ROOK三機 `CROWN / RAVEN / LARK` の関係と、基本的な空戦操作である。
4. セラ側の**高高度攻撃機護衛はM11**へ置く。
5. 高高度任務のエレム側は**迎撃側**として扱う。
6. `M21 CLEAR PATH`を高高度攻撃機迎撃にしない。M21はレン湾爆撃を成立させるための前段掃討である。
7. 以後、M01とM11の任務内容を入れ替えない。

# 1. M01 FIRST CONTACT — セラ

## 役割

開戦直後、レン湾へ向かうエレム爆撃機編隊をROOK隊が緊急迎撃する。

登場:

```text
ROOK 1 "CROWN"
ROOK 2 "RAVEN"   PLAYER
ROOK 3 "LARK"
AWACS "MERIDIAN"
```

敵:

- エレム爆撃機編隊
- 爆撃機護衛戦闘機

## ゲーム

一本道にする。

1. 緊急発進後、侵入編隊へ接触。
2. 護衛戦闘機と交戦。
3. 爆撃機を赤TGTとして明確化。
4. 爆撃機を必要数撃墜。
5. 残存護衛機の離脱／処理を確認して終了。

M01で覚えさせるもの:

- 飛行
- ターゲット選択
- ミサイル
- 機銃
- 赤TGTの撃破
- 味方三機の関係

M01で覚えさせないもの:

- 高高度専用戦闘
- 高度制限UI
- 護衛対象HP管理
- 分岐
- 民間／軍事施設の二択
- ARCAの複雑な関係

## 人物

CROWNはRAVENとLARKへ、護衛戦闘機を深追いして本来の爆撃機阻止を忘れないよう指示する。

これは後のRAVEN闇ルートへの小さな伏線になるが、M01時点では思想的な説明をしない。

RAVENはまだROOK 2であり、自分が作戦全体を決める人物ではない。

# 2. M11 — セラ高高度攻撃機護衛

M11がセラ側の高高度特殊任務である。

登場の基本:

```text
ROOK 1 "RAVEN"   PLAYER
ROOK 2 "LARK"
AWACS "MERIDIAN"
セラ高高度攻撃機編隊
```

CROWNはM06後に前線を離れているため、常設戦闘機として参加しない。

## ゲーム

複雑なシステムは追加しない。

1. 高高度攻撃機編隊へ合流。
2. 第一迎撃波を排除。
3. 高速迎撃機から攻撃機を守る。
4. 規定数の攻撃機が投下線／作戦線へ到達すればクリア。

高高度らしさは次だけで出す。

- 通常より高い戦闘高度
- 高速の迎撃機
- 護衛対象から離れすぎない
- 高度による景観と速度感

専用の複雑な酸素、失速、エンジン管理UIなどは作らない。

## エレム側

同じ高高度戦略事件をエレム側から遊ぶ場合は**迎撃側**となる。

- セラ高高度攻撃機を止める。
- エレム側ではMiG-31など高高度迎撃向け機体の役割を見せる。
- セラ側の護衛とエレム側の迎撃を対になる体験として扱う。

具体的なエレム側ミッション番号・タイトルを変更する場合は、他のエレム編物語配置と同時に整合させる。少なくともM21へは置かない。

# 3. M21 CLEAR PATH — エレム

M21はM01レン湾爆撃を成立させるための**前段掃討**。

登場:

```text
REEM 1 "POLKA"   PLAYER
REEM 2 "SABLE"
AWACS "POLARIS"
```

敵:

- セラ前方CAP
- セラAWACS／航空管制支援機

## ゲーム

1. 爆撃隊より先に作戦空域へ進入。
2. 前方CAPを排除。
3. AWACSまたは航空管制支援機を赤TGTとして撃墜。
4. 爆撃隊の進入路が開けば終了。

M21自体に高高度護衛／迎撃ギミックは置かない。

エレム世界線ではPOLKAがこの前段掃討を成功させるため爆撃作戦が有利に進み、セラ世界線ではRAVENたちがM01で侵入爆撃機を迎撃する。二つは同じ戦争計画から分岐する別世界線として扱う。
