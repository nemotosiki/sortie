## 2. 12月25日に起きること

シェム強硬派は、クリスマスを「世界統一認証の日」と定め、全オファンノードを中央ROOTへ再接続しようとする。

エメト統合派は、同じ日を「十二州完全盟約の日」と定め、地域鍵を一つの契約へ統合しようとする。

両者とも、戦争を終わらせたい。

- シェム強硬派は、誰も無許可で武器を使えない世界を作る。
- エメト統合派は、誰も金融封鎖で共同体から消されない世界を作る。

どちらも、一つの正しい中心を必要とする。

ROOK 1とREEM 1は、十二のブートストラップノードから個人鍵を発行し、中心そのものを不要にする作戦へ出る。

## 7. ミッション構造

### PHASE 1 — 十二窓の起動

- EX03で届けた十二鍵を再起動する。
- 送信窓は同時には開かず、四群に分かれる。
- 強硬派は自分たちに必要な窓だけを奪おうとする。

### PHASE 2 — IFF崩壊

- 中央ROOT再統合処理によって、敵味方表示が不安定になる。
- プレイヤーは挙動、進路、護衛対象から攻撃対象を判断する。
- UNKNOWNを無差別に撃つと、個人鍵配布機や救難機を失う。

### PHASE 3 — 二つの統合中枢

- シェム中央環とエメト統合鍵母機が別方向に出現。
- どちらか一方だけを先に倒すと、もう一方が急速に統合を進める。
- ROOK 1とREEM 1が分かれ、同時に両方を止める必要がある。

### PHASE 4 — 一つの照準

- 十二送信窓が中央へ吸い戻され始める。
- HUD上に巨大な白い照準が中央ROOTへ現れる。
- 中央を撃てば、すべての戦闘機と無人機を一度に停止できる。
- ただし個人鍵発行も止まり、再び誰かがROOTを所有する余地が残る。

### PHASE 5 — ALL NAMES

- 中央を撃たず、最後の個人鍵配布機を守る。
- 十二窓が地域ノードへ接続。
- 地域ノードが個人鍵の発行を開始。
- 巨大照準は破壊されず、十二へ分かれ、さらに無数の小さな円へ変わる。
