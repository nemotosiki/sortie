# 1. 解禁設計の二つのルール

## 1.1 総合性能アップは敵を一戦先に見せる

純粋に戦闘機として一段強くなる機体は、購入可能になる直前の任務で、敵側の新しい戦力階層を少数見せる。

```text
M04  敵MiG-29Aを初投入
  ↓
M04クリア
  ↓
F/A-18F購入許可

M12  敵Su-35級を初めて少数の精鋭として本格投入
  ↓
M12クリア
  ↓
F-15C購入許可

M17  後期試作機／Su-47・Su-57級を1機程度だけ先行投入
  ↓
M17クリア
  ↓
F-35C購入許可
```

「新型敵を倒したからその機体が鹵獲できる」という意味ではない。

戦争の航空戦力が一段上がったことをプレイヤーへ先に体験させ、その次の出撃から自軍側にも新しい選択肢が届く、という難度曲線である。

### 禁止

- プレイヤーがF/A-18Fを買える前からSu-35を通常雑魚として大量投入する。
- F-15C解禁前からSu-57を何機も出す。
- 高性能機を`trash / rookie`にして序盤の数合わせにする。
- 敵機のHPだけ増やして「強化」とする。

---

## 1.2 専門機は「次の任務の遊び方」を増やす直前に出す

専門機は敵の性能インフレと直接同期させない。

```text
F-4E    = 通常ミサイルだけで対地を経験した後に解禁
F-2A    = 初の本格艦隊戦の直前に解禁
F-111F  = 夜間低空侵攻の直前に解禁
A-10C   = CAS・車列識別の直前に解禁
F-14D   = 高高度護衛・長距離迎撃の直前に解禁
F-15E   = 戦争が戦略打撃段階へ入る直前に解禁
```

専門機は必ずしもF-16やF/A-18Fの上位互換ではない。

「次の任務ならこの機体を買う意味がある」と思えることが重要。

# 3. 購入許可の意味と資金設計

購入許可と「その時点で普通に買える」は分離する。

## M04開始時

既存v0.7の思想を維持する。

- 普通にM01〜M03をクリアしたプレイヤー: **F-4Eを購入可能な資金量**
- 高戦果・任意敵・短時間クリアを取ったプレイヤー: **F-2Aへ届く**
- 何も買わずF-16CでM04へ行く: 可能

つまりM04は、最初の「お金の使い方で攻略法が変わる」任務になる。

## F/A-18F以降

全解禁機をその場ですべて買える資金は配らない。

意図:

```text
F/A-18Fを早く買って万能性を取る
vs
F-2A / F-4Eを使い続け、次の専門機へ貯金する
```

が成立すること。

### 期待する資金感覚

- F/A-18F: M04直後に即買いできるのは、序盤で買い物を抑えたプレイヤー。標準ではM05〜M06頃が現実的。
- F-111F / A-10C: 両方を即買いするより、M08/M09のどちらを重視するか選ぶ価格帯。
- F-14D / F-15C: 中盤の大きな投資。前機体を全部買ったプレイヤーは少し遅れる。
- F-15E: F-15Cとは上下関係でなく、制空と打撃の分岐購入。
- F-35C: 終盤の高額機。普通の初回プレイで「これを買うために貯める」価値を持たせる。
- F-22: 資金で買わせない。

具体価格は、各ミッションの平均獲得CRとS/A/B/C報酬を決めた後に別表で確定する。

# 4. 敵航空戦力との同期

プレイヤー機解禁から逆算して、敵の格上げ時期を次のように置く。

| 戦域段階 | 敵の普通の戦闘機 | 少数の上位敵 | プレイヤー側の応答 |
|---|---|---|---|
| M01〜M03 | MiG-21中心 | M02 MiG-23少数 | F-16C、F-4E |
| **M04** | MiG-21 / MiG-23 | **MiG-29A×2初登場** | M04後 F/A-18F解禁 |
| M05〜M11 | MiG-23 / MiG-29A | MiG-31は専門迎撃だけ | F/A-18F＋各専門機 |
| **M12** | MiG-29A | **Su-35級を1〜2機の精鋭として初本格投入** | M12後 F-15C解禁 |
| M13〜M16 | MiG-29A主力 | Su-35 / Su-33用途限定 | F-15C、F-14D、F-15E |
| **M17** | MiG-29A / Su-35 | **Su-47またはSu-57級を1機の後期精鋭として先行投入** | M17後 F-35C解禁 |
| M18〜M20 | MiG-29 / Su-35が主力 | Su-47 / Su-57はネームド・重要警護だけ | F-35C、既存上位機 |

## Su-33

Su-33はM04へ出さない。

M16 `HOME FLEET`のように、空母・海軍航空隊・外洋航空戦が本当に主役になる場面を初本格登場候補とする。

「艦隊戦だからSu-33」ではなく、**どの母艦／航空基地から来た航空隊なのか**を説明できる時だけ使う。

## Su-57

Su-57はプレイヤー側では全S報酬なので、敵側でも普通の量産雑魚にしない。

- M17: 先行投入するなら1機
- M18: 超兵器防衛の特別機1機程度
- M19: REEM本人の搭乗機候補。護衛までSu-57で埋めない
- M20: 1〜2機の重要敵としては可。大量編成禁止

これにより、F-35Cを買った後でもSu-57は「まだ上がいる」と感じられ、全S F-22報酬の意味も残る。

# 5. ミッションの質から見た解禁ポイント

## 開戦章 M01〜M05

完成度の核は強い。

特にM04は「初めて機体購入が攻略へ大きく返る任務」として非常に重要。

したがってM01〜M03では新機体を乱発しない。

```text
M01: F-16だけで基本を覚える
M02: 基本A2Gまで覚えた後、F-4を開ける
M03: 低空・港湾を経験した後、対艦F-2Aを開ける
M04: 購入判断の試験
M04後: 初の本格マルチロールF/A-18F
```

### 要修正

現在のv0.16個別詳細には、この方針より前に書かれた強敵編成が残っている。

- M01: MiG-29大量 → MiG-21へ
- M02: MiG-29護衛・増援 → MiG-21主体、MiG-23少数へ
- M03: MiG-29×6 → MiG-21主体へ
- M04: Su-33×6＋増援 → MiG-29A×2＋遅延MiG-21へ
- M05: MiG-29×4 → MiG-21地方防空＋MiG-29A QRA×2へ

ミッション構造は残し、航空編成だけ新ドクトリンへ合わせる。

## ACT II M06〜M12

ここでは**性能アップより専門性を増やす**。

- 峡谷SEAD
- 悪天候救難
- 夜間低空侵攻
- CAS
- 移動列車
- 高高度護衛
- UAV / EW

が連続するので、一機の万能上位機だけで解決させない。

F-111F、A-10C、F-14Dという異なる専門機を置く価値が高い。

ACT II最後のM12で初めてSu-35級の精鋭を見せ、F-15Cを開けてACT IIIへ移る。

## ACT III M13〜M17

F-15Cを「買って強くなった」と感じさせる区間。

同時に、F-2A / F/A-18F / F-14D / F-15Eなどが任務別ではまだ勝るようにする。

- M13: F-15C / F-14D
- M14: F-2A / F/A-18F / F-15E
- M15: F-15C
- M16: F-14D / F/A-18F
- M17: F-15C中心

つまりF-15Cを解禁しても「これ一機で全部よい」にはしない。

M17を終盤航空戦の壁にし、ここを越えた報酬としてF-35Cを解禁する。

## ACT IV M18〜M20

新しい機体を次々解禁する区間ではない。

F-35Cまでで購入進行をほぼ完成させ、最後の三戦は**今まで買った機体をどう使うか**にする。

F-22は本編を楽にする救済機ではなく、20本全Sを終えた後のFREE MISSION報酬に固定する。

# 6. 現時点でのミッション品質上の重要修正

解禁表を作ることで、機体とは別に次の問題が見えた。

## M03 LOW WATER

現在の詳細版は、

```text
Ka-52を全滅
↓
輸送ヘリ出現
↓
Su-25出現
```

と順番に処理するため、元草案にあった

```text
攻撃ヘリを優先して港を守る
vs
輸送ヘリを優先して上陸を防ぐ
```

という判断が弱くなっている。

M03を代表ミッションにするなら、Ka-52と輸送ヘリの圧力が一定時間重なる構成へ戻す価値が高い。

## M04 NARROW SEA

設計の核は強い。

ただし序盤4戦目として16〜19分はかなり長いため、実装時には「内容が濃いから長い」のか「移動待ちで長い」のかを必ず実測する。

CAPをMiG-29A×2へ落としたことで、艦隊SAM・揚陸艦時間圧・後半EPOCH防衛を主役に戻す。

## M11

v0.15で高高度攻撃機護衛へ変更済みだが、ACT IIの旧本文はまだ別任務`FROZEN EYE`を記載している。

購入表ではF-14DをM10後に解禁し、M11をF-14Dの最初の明確な活躍場所とする。

正式実装前にM11詳細設計を新正本へ書き直す必要がある。

## M18〜M20

旧草案はSu-57を4機単位で置く箇所がある。

これはF-22 / Su-57を最上位特別機とするv0.7〜v0.8の思想と衝突する。

終盤の難度は、

- ジャマー
- 超兵器
- 時間圧
- 護衛
- ミサイル
- エースAI
- 多方向攻撃

の組み合わせで上げる。

Su-57の数で上げない。

# 7. 次に決めるもの

この解禁タイミングを基準に、次は二つを作る。

1. **セラ編のCR価格表**
   - 各ミッションの標準報酬
   - S/A/B/C差
   - 平均プレイヤーがいつ何機買えるか
   - 全機即購入を防ぐ価格

2. **敵航空戦力のM01〜M20完全表**
   - 各ミッションの機種
   - TGT / non-TGT
   - role / skill
   - purpose
   - 数
   - 到着時刻
   - プレイヤー解禁との同期

順序は必ず**プレイヤー機解禁 → 敵戦力**とする。
