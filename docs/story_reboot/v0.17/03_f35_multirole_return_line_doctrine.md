# 0. 絶対訂正

F-35CをF-15C / F-15Eより**数値上の上位機へ再調整しない**。

既存の機体性能値は維持する。

F-35Cの価値は、

```text
最高速度・旋回・純制空性能で勝つこと
```

ではなく、

```text
一つの長いミッションの中で
空対空 / 対地 / 対艦の要求が切り替わっても
同じ機体で高水準に対応できること
```

に置く。

F-15Cは純制空ならF-35Cより有利でよい。  
F-15Eは一つの明確な打撃目標を短時間で破壊する任務ならF-35Cより有利でよい。  
F-14Dは長距離迎撃・艦隊防空ならF-35Cより有利でよい。  
F-2Aは純対艦ならF-35Cより安価で強い選択肢として残す。

F-35Cは「全部で一番」ではなく、**任務の途中で仕事が変わった時に一番困らない機体**とする。

# 1. 解禁

既に確定した購入許可を維持する。

```text
M09クリア  -> F-15C / F-15E 購入許可 -> M10から使用可能
M14クリア  -> F-35C 購入許可         -> M15から使用可能
```

F-35C解禁後のM15〜M20では、単純な性能インフレではなく**任務構造そのものを複雑化**して購入価値を作る。

---

# 2. マルチロール機の契約

F/A-18FとF-35Cは、出撃前および再武装時に次の特殊兵装群から一つを選択できる。

```text
4AAM = 空対空・複数迎撃
4AGM = 地上目標・複数攻撃
LASM = 艦艇・長距離対艦
```

任務中に同時に三種類を積むわけではない。

一度選んだSP.Wを飛行中に瞬時変更することは禁止する。  
変更できるのは**基地・空母へ帰還して再武装した時だけ**。

これにより、マルチロール機の強さを「万能ボタン」ではなく、

```text
戦況を読んで帰る
↓
次のフェーズに必要な兵装へ換える
↓
再出撃する
```

という戦略へ結びつける。

---

# 3. RETURN LINE / 帰還ライン

一部の長時間ミッションへ、友軍基地または空母につながる**RETURN LINE**を設置する。

## 3.1 基本

HUD・レーダー・マップ上に、戦闘空域の後方へ帰還可能境界を表示する。

プレイヤーが帰還ラインを越えると、任務失敗・離脱ではなく、

```text
RETURN TO BASE
```

へ移行する。

その後、基地または空母へのアプローチへ入る。

## 3.2 着陸 / 着艦

帰還ラインを越えただけで即時全回復させない。

### 地上基地

- 滑走路へ誘導
- ギア操作の複雑なシミュレーションは作らない
- 進入方向、高度、速度をHUDで分かりやすく案内
- 滑走路へ安全に接地すればSERVICEへ移行

### 空母

- 艦尾から進入
- デッキへ着艦
- フック、LSO、細かな揚力計算は要求しない
- エースコンバット風の短いアーケード着艦にする

着陸が本編の難関になってはいけない。  
目的はフライトシム要素ではなく、**戦場から一度離れて兵装選択をやり直す時間コスト**を作ること。

## 3.3 SERVICE

着陸 / 着艦成功後、任務を終了せず簡易SERVICE画面を開く。

可能な操作:

- MSSL補充
- 現在のSP.W補充
- 対応機のみSP.W変更
- FLARE補充
- 機体ダメージ修復

修復率と補給量は基本100%でよい。  
難度は「補給を渋ること」ではなく、**帰還している間も戦況が進むこと**で作る。

## 3.4 再出撃

SERVICE完了後、同じ基地 / 空母から発進し、同一ミッションの同一戦況へ戻る。

敵ウェーブ、護衛対象、艦艇の前進、味方HP、ミッションタイマーは巻き戻さない。

つまりRETURN LINEは無料回復ではない。

```text
帰れば弾薬と兵装は整う
しかし、その間にも敵は進む
```

という交換条件にする。

---

# 4. 帰還回数

基本は**回数制限を設けない**。

代わりに次で濫用を防ぐ。

- 帰還中も主任務の時間は進む
- 護衛対象は戦い続ける
- 揚陸艦、爆撃機、地上軍は前進する
- 遅延増援の時計も進む
- 帰還の往復そのものに距離がある

何度も帰ることは可能だが、Sランクや護衛結果では不利になる。

特定ストーリー結果で基地 / 空母が損傷している場合、RETURN LINEが一時使用不能になることは許可する。

---

# 5. F-35Cを有利にするミッション設計

M15以降すべてをF-35C推奨にはしない。

重要なのは、

```text
純制空 -> F-15Cが強い
純打撃 -> F-15Eが強い
純迎撃 -> F-14Dが強い
純対艦 -> F-2Aも強い
複合・長時間 -> F-35C / F/A-18Fが強い
```

という棲み分け。

F-35Cを買わなくても全任務クリア可能、Sランクも理論上可能にする。  
ただし複合任務では専門機を選ぶとフェーズのどこかで明確に苦労する。

# 6. M15〜M20の再評価

## M15 NIGHT OF NUMBERS — 最初のF-35C推奨任務

**F-35C解禁直後に、買う意味を教える。**

### PHASE 1 — CITY INTERCEPT

- 爆撃機
- 護衛戦闘機
- 巡航ミサイル
- ジャマー航空機

4AAMが非常に有利。

F-15CならここだけはF-35Cより強くてよい。

### PHASE 2 — MISSION UPDATE / GROUND NETWORK

第一波を止めた後、敵の地上移動ジャマー / 巡航ミサイル誘導車 / データ中継車が都市外縁に確認される。

これらを残すと第二航空波のHUD妨害・巡航ミサイル精度が上がる。

ここでは4AGMが有利。

### RETURN LINE

ミガル友軍飛行場への帰還ラインを使用可能にする。

F-35C:

```text
PHASE 1  4AAM
RETURN
PHASE 2  4AGM
必要なら再度RETURNして4AAM
```

F-15C:

- PHASE 1は最強
- PHASE 2はMSSL / GUNで地上目標へ対処

F-15E:

- PHASE 2は強い
- PHASE 1で航空戦に時間が掛かる

この差をM15で初めて明確に見せる。

---

## M16 HOME FLEET — RETURN LINEの代表任務

この任務を**空母RETURN LINEの代表例**にする。

### PHASE 1 — SUBMARINE / SURFACE ATTACK

- 浮上SSGN
- 偵察艦 / ミサイル艇
- 敵海上目標

LASMが有利。

### PHASE 2 — ANTI-SHIP MISSILE DEFENSE

- 対艦ミサイル
- Tu-22M3級攻撃機
- 艦隊CAP

4AAMが有利。

### 帰還先

CVN EPOCH自身を帰還先とする。

プレイヤーはEPOCHの後方RETURN LINEへ抜け、着艦、再武装して再出撃できる。

F-35C / F/A-18Fなら、

```text
LASM -> 着艦 -> 4AAM
```

が可能。

F-14Dは航空防衛では非常に強いが、前半のSSGN処理で不利。  
F-2Aは前半の対艦で非常に強いが、後半の大規模迎撃で不利。

**一機で完璧ではなく、任務の前後半を通した総合時間でマルチロールが強い。**

---

## M17 THE LONG APPROACH — F-15Cの見せ場

ここは逆に複合任務へしすぎない。

- 大規模爆撃機迎撃
- 高高度航空戦
- ネームド護衛
- AWACS / ジャマー

空戦中心。

F-15CがF-35Cより有利でよい。

F-35Cを解禁した直後でも、古い機体が死なないことを示す。

RETURN LINEは原則なし。

---

## M18 HORN OF HEAVEN — 打撃＋航空圧力

超兵器への対地攻撃が中心。

F-15Eは直接攻撃だけならF-35Cより強くてよい。

ただし途中で、

- 防衛戦闘機
- 攻撃ヘリ
- 救援輸送機
- 超兵器部位

が混在する。

F-35Cは4AGMで始めても、MSSLによる空戦能力が十分残るため扱いやすい。

敵領深部なのでRETURN LINEは置かない。  
ここは**帰還できない複合任務**として、出撃前兵装選択の重さを出す。

---

## M19 TRUST FALL — 純制空 / 護衛寄り

- 輸送編隊護衛
- REEM 1との決闘
- ROOTドローンの判断

F-15Cを再び有力候補にする。

F-35Cは万能だが明確な最適解ではない。

RETURN LINEなし。

---

## M20 THE GUARANTOR — 最終総合任務

最終戦では、今までの全要素を混ぜる。

### 例

1. 爆撃機・戦闘機迎撃
2. 地上 / 空中のジャマーノード破壊
3. オファン外周防衛設備破壊または防衛
4. 巡航ミサイル・対艦ミサイル迎撃
5. REEM最終戦

### RETURN LINE

M15 / M16の学習を最終戦で回収する。

過去の結果に応じ、

- CVN EPOCHが健在 -> 空母RETURN LINE
- ミガル飛行場が健在 -> 地上基地RETURN LINE
- 両方損傷 -> 帰還機能制限

とする。

F-35Cは最終戦の**最も楽な汎用選択**になってよい。

ただし、

- 制空だけならF-15C
- 特定部位への打撃だけならF-15E
- 艦隊防空だけならF-14D

の方が強い時間帯を残す。

# 7. マルチロール有利任務の数

セラ編20本のうち、F-35C解禁後に明確なマルチロール有利任務を**3〜4本**置く。

推奨:

```text
M15  明確に有利 / 地上基地RETURN LINE
M16  明確に有利 / 空母RETURN LINE
M18  やや有利 / RETURNなし
M20  明確に有利 / 条件付きRETURN LINE
```

M17とM19は制空・護衛へ寄せ、F-15Cの価値を維持する。

これによりF-35Cを買った瞬間に全旧機が死ぬことを防ぐ。

---

# 8. RETURN LINEを置くミッションの原則

RETURN LINEは全任務へ付けない。

向いているのは:

- 15分以上の大規模任務
- 前半と後半で必要兵装が変わる
- 味方基地 / 空母が地理的に存在する
- 補給へ戻るか主任務を急ぐかが判断になる

向いていないのは:

- エース決闘
- 敵領深部潜入
- 5〜10分の短時間任務
- 帰還すると緊張が壊れる護衛

---

# 9. Sランクとの関係

帰還したらS不可、にはしない。

Sランクは、

- 総クリア時間
- 護衛対象生存
- 必須TGT達成
- 被害

などで評価する。

上手いプレイヤーは専門機で無補給Sを狙える。  
マルチロール機は1回のRETURNで安定してSを狙いやすい。

帰還回数そのものを減点項目にはしない。

これにより、

```text
専門機を使い切る高度な攻略
vs
F-35Cで戦況へ合わせて再武装する柔軟な攻略
```

の両方を成立させる。

# 10. 実装上の契約

新規共通機構として最低限必要:

```text
mission.returnBase
mission.returnLine
mission.serviceLoadouts
mission.serviceState
```

想定状態:

```text
combat
returning
approach
service
launch
combat
```

SERVICE時に変更できるのは**所有中の現在機体の兵装だけ**。  
ミッション途中で機体そのものをF-15CからF-35Cへ乗り換えることは禁止する。

既存の自動ミサイル補充処理が残っている場合、RETURN LINE対応ミッションでは自動補充を無効化し、補給を基地 / 空母へ統一する。

# 11. QA

1. F-35Cの既存性能値を上方修正していない。
2. M15以降でもF-15C / F-15E / F-14D / F-2Aが特定任務で最適になり得る。
3. F-35Cが有利になる理由を「性能が高いから」ではなく「任務途中の役割変更へ対応できるから」と説明できる。
4. RETURN中も敵・味方・タイマーが進む。
5. RETURN LINEを無視しても全対象ミッションをクリア可能。
6. RETURNしなくてもSが理論上可能。
7. SERVICEで機体そのものを変更できない。
8. マルチロール機だけが複数SP.W候補から再選択できる。
9. 専門機に存在しない兵装をSERVICEで追加しない。
10. M16で `LASM -> 4AAM` の再武装が実際に戦術価値を持つ。
11. M17 / M19はF-15CがF-35Cより有利な空戦中心任務として残る。
12. M20では過去の空母 / 飛行場損傷状態がRETURN可否へ返る。
