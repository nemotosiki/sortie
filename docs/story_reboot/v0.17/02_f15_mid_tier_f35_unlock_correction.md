# 1. 結論

```text
M09クリア
  -> F-15C / F-15E 購入許可
  -> M10から使用可能

M14クリア
  -> F-35C 購入許可
  -> M15から使用可能
```

F-15C / F-15E は**最上位へ向かう直前の高級機ではなく、中盤の標準的な上位戦闘機**とする。

F-35C は M15〜M20 の後半用高性能マルチロール機とする。

F-22 は従来どおり M01〜M20 全S後のFREE MISSION報酬であり、初回本編では購入できない。

# 2. セラ側の性能階層

新キャンペーンの体感階層は次を基準にする。

```text
旧式・専門低性能帯
  F-4E

初期・序盤標準帯
  F-16C
  F-2A（対艦専門）

前半マルチロール帯
  F/A-18F

中盤主力帯
  F-15C
  F-15E
  F-14D（長距離迎撃専門。総合格ではなく用途機）

後半高性能帯
  F-35C

クリア後最上位帯
  F-22
```

重要なのは、F-15C/Eを「F-35Cの一歩手前の超高性能機」にしないこと。

F-15はM10以降の戦場で普通に使う**中盤の働き馬**であり、後半でも十分使えるが、F-35Cを買った時には明確な世代更新を感じられるようにする。

# 3. F-15Cの役割

## 3.1 性格

**純制空の中盤主力。**

F/A-18Fより高速・空戦向きだが、ゲーム全体を塗り替えるほど強くしない。

長所:

- 高い巡航・最高速度
- 良好な加速とエネルギー保持
- F/A-18Fより高い純A2A能力
- 4AAMなど制空向けSP.W

短所:

- 低速安定性・狭所での扱いやすさはF/A-18Fに劣る
- 対地・対艦適応はF/A-18Fほど広くない
- F-35Cのようなステルス／高安定／万能SP.W選択は持たない
- F-22のような最高機動・最高継戦能力には遠い

### 設計上の位置

```text
F/A-18F  = 何でもできる前半機
F-15C    = 空戦へ寄せた中盤機
F-35C    = 高性能を保ったまま何でもできる後半機
F-22     = クリア後の最上位
```

F-15Cを買った瞬間に、それ以前の全機体が不要になる設計は禁止する。

# 4. F-15Eの役割

## 4.1 性格

**打撃寄りの中盤主力。**

F-15Cの完全上位互換ではなく、同じ時期に購入可能になる横並び選択とする。

長所:

- F-15Cと同系統の速度・航続力
- 対地火力と兵装量
- 長距離打撃、移動地上目標、混成任務に向く
- C型よりわずかに高い耐久・安定性を持たせてもよい

短所:

- F-15Cより旋回、ロール、純A2A効率を一段落とす
- F/A-18Fほど低速・艦上・狭所向きではない
- F-35Cの万能性・ステルス性能には届かない

### 購入上の意味

M09クリア後、プレイヤーは同時に二択を得る。

```text
F-15C = 空戦を楽にしたい
F-15E = 対地・混成任務を楽にしたい
```

両方を即購入できる資金量にはしない。

この二択自体を中盤の資金運用へ使う。

# 5. F-35Cの役割

F-35Cは**M14クリア後に購入許可、M15から使用可能**。

ここを初回本編における最後の大きな性能ジャンプにする。

F-35CはF-15C/Eより明確に高性能だが、F-22には届かない。

```text
F-15C/E -> F-35C
```

で感じる変化:

- 高い低速安定性
- 高耐久
- 高い総合機動
- 4AAM / 4AGM / LASMの任務前選択
- ステルス由来の戦術的有利
- 空対空・空対地・対艦の全てで「十分強い」

ただし各専門機の最高用途は残す。

- F-2A: 対艦コスト・LASM運用で価値を残す
- A-10C: 低速CAS・機銃対地で価値を残す
- F-14D: 長距離迎撃で価値を残す
- F-15C: 純制空の素直さで価値を残す
- F-15E: 重打撃・搭載量で価値を残す

F-35Cを買った瞬間に過去機全てが完全下位互換になる設計は避ける。

# 7. ミッション難度への反映

## M09 IRON HARVEST

M09はF-15解禁前の最後の任務。

ただしCAS・車列識別が主役なので、ここへSu-35を大量投入して難しくしない。

航空戦力を一段上げる場合は、次のどちらかとする。

- MiG-29A `line/regular` の正規隊を少数
- Su-27級 `line/regular` を1〜2機、初の中盤制空機として見せる

これにより、

> 敵の前線航空隊もMiG-21時代ではなくなった

と感じさせた直後にF-15C/Eが購入可能になる。

## M10 LAST TRAIN

F-15C/Eを初めて使える任務。

ただし列車・橋梁・低空精密打撃が主役なので、F-15Cが最適解にはならない。

- F-15C: 上空の敵を短時間で整理し、列車攻撃へ集中する
- F-15E: 空戦をこなしつつ地上攻撃も強い
- F-111F: 低空打撃では依然として非常に有効
- A-10C: 速度は遅いが列車への継続攻撃が強い

「新しく買った機体＝必ずその次の任務の唯一の正解」にはしない。

## M11

F-14Dを追加解禁し、高高度・長距離護衛で専門性を見せる。

F-15Cでも十分クリア・S取得可能。
F-14Dなら長射程迎撃が楽になる。

## M12〜M14

F-15C/Eを中盤の普通の主力として使う区間。

敵の一般航空戦力:

- MiG-29A
- Su-27級
- 用途限定MiG-31
- 海上なら用途限定Su-33

Su-35を通常雑魚にしない。

## M14 BREAKWATER

**F-35C解禁前の壁。**

ここで初めて、Su-35級を1〜2機の `elite/veteran` として本格投入する候補とする。

ただしM14は上陸阻止・対艦・対地・病院船識別が主役なので、Su-35だけをボスにしない。

M14を越えることで、M15からF-35Cが購入可能になる。

## M15〜M17

F-35Cを買ったプレイヤーが「世代が変わった」と感じる区間。

敵主力は依然としてMiG-29A / Su-27級。
Su-35は少数精鋭。
Su-33は海軍航空任務だけ。

これによりF-35Cの強さを感じられる一方、敵全員をSu-35へ置換して価値を相殺しない。

## M18〜M20

Su-47 / Su-57などの特殊・最上位敵を少数投入可能。

ここでも一般戦闘機の土台はMiG-29 / Su-27 / Su-35であり、Su-57の物量で難度を作らない。

# 9. QA

1. F-15C / F-15EはM09クリアで同時に購入許可される。
2. M10から両機を使用できる。
3. F-15C/Eを終盤最上位性能帯として扱わない。
4. F-15EはF-15Cの完全上位互換ではない。
5. M10〜M14でF-15C/Eが中盤の標準機として自然に使える。
6. F-14DはF-15より上位ではなく長距離迎撃専門として差別化する。
7. F-35CはM14クリアで購入許可され、M15から使用できる。
8. M14以前にSu-35を一般雑魚として大量投入しない。
9. M14でSu-35を出す場合は1〜2機の精鋭とする。
10. M15以降もSu-35だけで敵編成を埋めず、MiG-29 / Su-27を主力として残す。
11. F-22は初回本編へ持ち込めない。
12. F-35CとF-22の間に明確な性能差を残す。
