# 17.1 将来実装へ渡すための機能分類

## 現行資産で表現できるもの

- 空中・地上・艦船ウェーブ
- 役割とAI練度
- 護衛対象、`hunt`、任意目標、`mark`、後続ミッションの盤面変化
- 名前付きエース、恐怖無線、キルカム
- 新ユニット登録
- 新マッププリセットとワールド装飾

## 既存APIの拡張または本体機能が必要なもの

- 二つのミッションを同時解禁し、出撃順を記録する戦域選択
- 未選択作戦の部分成功／損害を自動解決する処理
- 同一地域の損傷状態を世界線内で保持するマップ差分
- 白い収束照準の選択依存表示
- 友軍・民間目標の識別遅延と誤爆記録
- 超兵器の部位破壊、長距離攻撃、専用フェーズ
- 四エンドと真章の解禁管理

## 実装単位の推奨分割

1. 地域・戦線・世界状態レジストリ
2. 新規マップ群
3. 新規ユニット群
4. M01〜M05 / M21〜M25の開戦章
5. 同時作戦と後続変化
6. 中盤20ミッション
7. 超兵器と最終章
8. エンディングと真章

新しい仕組みを一度に全40本へ実装せず、開戦10本で選択と地理整合性を完成させてから拡張する。

# 19. バランス上の目安

- 通常ミッションの同時空中敵は8〜12機を基本とする。
- 大規模戦は波を分け、最大同時空中敵16機程度。
- 地上戦は目標8〜14、非目標3〜8。
- 艦隊戦は大型艦4〜6、小型艦4〜8。
- 超兵器戦は部位12〜18だが、通常敵の同時出現を減らす。
- 選択による難易度差は、敵数±2〜4、SAM±1〜2、味方支援±1〜2を基本にする。
- 「正しい選択」を簡単にしない。人命や自由を守る選択は、軍事的には少し難しくする。
- 裏切りルートは実際に戦争を早く終わらせ、ゲームプレイも楽にする。罠として機能させるため、単なる罰ゲームにしない。

# 20. 制作時の執筆ルール

1. 一ミッションの大きな意味は一つ。
2. 無線は説明ではなく、同じ出来事を異なる立場から短く述べる。
3. 民間被害は数字だけでなく、消える灯、帰らない輸送機、止まる列車で見せる。
4. 敵側にも守る対象と帰る場所を置く。
5. プレイヤーの選択を後から「正解／不正解」と採点しない。
6. 通常エンドも正義として成立させる。
7. 裏切りエンドでは、本当に多くの人が救われる。そのうえで奪われたものを示す。
8. 真エンドを「分散技術なら自動的に善」としない。危険と責任を引き受ける結末にする。
9. 実在の国家、宗教、民族、銀行、家系の名前をゲーム本文へ出さない。
10. 神話的対応は内部制作表にのみ残し、ゲーム内では人間の選択と制度の結果として描く。

# 21. オープニング文章案

戦争は宣言から始まらなかった。

夜明け前のレン湾で、民間機の航法灯が一つずつ着陸していた。病院へ血液を運ぶ輸送機、夜勤を終えた整備員、滑走路の端で朝を待つ迎撃機。そのすべてを同じ管制塔が見ていた。

午前五時四十分、塔の画面に六つの反応が現れた。

三つは軍用滑走路へ向かい、三つは塔そのものへ向かった。

CROWN 1は敵の数を読み上げなかった。

「ROOK 1。どちらから行く」

それが、この戦争で最初に与えられなかった命令だった。

# 22. 露編オープニング文章案

レン湾空襲の九十分前、アラドの山々はまだ夜の中にあった。

REEM 1の前には爆撃機も都市もいない。レーダーに映るのは、これから爆撃機を落としに行く戦闘機、彼らを導く管制機、帰路を与える給油機だった。

WARDEN 1は言った。

「護衛は後ろへ付くことじゃない。敵が会えない空を作ることだ」

四つの目標が別方向へ分かれる。

戦闘機を落とせば、爆撃隊は生きる。管制機を落とせば、爆撃は見つからない。給油機を落とせば、遠くの敵は帰る。

REEM 1が選んだ最初の標的は、九十分後のレン湾の歴史を決める。

# 23. 確定事項と保留事項

## 今版で確定

- CROWN 1はM06で重傷を負うが生存し、後方指揮へ移る。
- M19は味方機そのものを撃墜させず、ROOT分割ドローンの護衛／破壊で分岐する。
- オファンは十二基の独立ノードと中央環から構成する。真章で十二地域へ対応させるため、一体型要塞にはしない。
- M41はまず一面の高密度真章として設計する。物語量が多すぎる場合だけ三面化を検討する。
- 新機体の多くは敵・友軍専用で導入し、キャンペーンクリア後の報酬機を2〜4機に絞る。

## 保留

- 最終的な国家・地域・人物名。現在の短いカタカナ名を仮称として継続する。
- ルアの物理的な破壊原理と、ブラウザ上で過剰な描画負荷を出さない画面表現。
- 出撃順選択UIと、未選択作戦の自動進行を本編基盤へ入れる具体方式。
- 民間目標への誤爆を即失敗、スコア減、後続変化のどれで扱うか。
- 世界線選択を最初から表示するか、米編クリア後に露編を解禁するか。
