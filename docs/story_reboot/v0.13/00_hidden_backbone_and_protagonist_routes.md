# 1. 三層の世界構造

## 1.1 表層 — 報道される戦争

表向きには、ケデムを中心としてセラとエレムが衝突する大規模な代理戦争である。

- ケデム政権と東部住民の対立
- エレムによる住民保護を掲げた侵攻
- セラによる武器、情報、顧問、契約部隊の支援
- ARCAによる治安維持と武装中立
- 港、海峡、峡谷、認証網を巡る333日間の戦争

ニュースは「世界秩序を二分する大戦」と報じる。しかし実態は、両大国が互いの首都と国民全体を破壊する全面戦争ではない。限定された地域で、代理部隊、軍事顧問、契約部隊、無人機、航空支援、金融封鎖を使って争う。

前線の死、避難、破壊、迫害はすべて本物であり、茶番だから被害が偽物という意味ではない。

## 1.2 中層 — 戦争を継続する中間支配層

戦争を実際に止められなくしている中心は、国家元首ではなく、平時への再編に従わない中間支配層である。

- 軍需企業とその系列会社
- 軍の作戦・調達部門
- 情報機関の実働局
- 契約軍事会社
- 地方財閥と資源閥
- 過激な治安部隊、民兵、国家再生派
- 戦時予算と非常権限で地位を得た官僚・司令官

彼らは会社組織で言えば部長、本部長、現地責任者に相当する。世界そのものを所有してはいないが、現場の予算、兵器、命令、報道、恐怖を握っている。

自由、主権、住民保護、民族防衛、解放、正義という本物の問題を利用し、利益、予算、地位、思想、復讐のために戦争を継続する。

## 1.3 深層 — 姿を見せない旧家層

世界の長期的な秩序は、王冠も爵位も見せない古い家々によって維持されてきた。

彼らは一つの秘密結社として毎日の戦闘を命令するのではない。信託、土地、海運、保険、信用、研究、医療物流、通信、相続、人脈を何世代も共有する階層である。

旧家層は大規模戦争を望んでいない。戦争より、安定した物流、信用、医療、相続、研究、長期取引のほうが世界にも自分たちにも有益だと理解している。

しかし彼らが作った平和は、人類が互いを愛し信頼した結果ではなく、少数者が世界を管理することで成立した平和である。

# 2. 旧家層は支配を続けたいのではない

旧家層は、自分たちの管理が最終回答ではないことを理解している。

- 管理が続くほど、人類は自分で判断しなくなる。
- 安全を中央へ預けるほど、異なる価値を持つ他人を信じなくなる。
- 世界を守る役割は、旧家自身をその役割へ拘束する。
- 管理者が善良でも、次代の管理者が善良とは限らない。
- 一つの認証、一つの通貨、一つの平和は、いつでも一つの牢獄へ変わる。

そのため、旧家層も本心では支配層をやめたがっている。

ただし、権限を突然放棄すれば、軍需企業、軍部、情報機関、過激派など、より短期的で暴力的な中間支配層が空席を奪う。旧家は人類を信用していないから支配しているのではなく、人類がまだ恐怖のたびに新しい救世主と中央を作ることを知っているため、退場できずにいる。

旧家層の退場条件は、誰か一人の理想的な後継者が現れることではない。

```text
複数の地域が、異なる価値観のまま相互承認できること
複数の通貨・信用網・身元証明が、中央所有なしで接続できること
一つの失敗を理由に、全員が一つの救世主へ権限を返さないこと
自分と他人の価値を、中央の許可なしに認められること
```

旧家層が待っているのは、新しい王ではなく、王が不要になる状態である。

# 3. 「人事異動に従わない部下の粛清」という内部解釈

世界は戦争経済から平時経済へ移行しようとしていた。

内部的な人事異動とは、次の再編を意味する。

- 軍需工場をエネルギー、輸送、宇宙防衛、災害救助へ転換する。
- 軍の一部をインフラ保全、救難、国際警備へ移す。
- 巨大な情報機関を縮小し、秘密作戦部門を解体する。
- 私兵、民兵、過激派治安部隊を武装解除する。
- 戦時調達、非常予算、秘密口座を閉じる。
- 国家単位の独占的な信用・認証を、地域と個人へ分散する。

中間支配層は、予算、地位、思想、秘密権限、武器在庫、存在理由を失うため、この異動を拒否した。

彼らは国家間戦争を始めたつもりでいるが、深層では、自分たちが平時体制へ残れるかを賭けた抵抗になっている。

本書でいう「粛清」は、一般住民や思想の異なる者を消すことではない。主に次を指す。

- 指揮権の回収
- 資産と秘密口座の凍結
- 私兵・過激派部隊の解散
- 軍需企業の分割・転換
- 司令官、役員、作戦局の更迭・逮捕
- 武装して抵抗した組織の戦場での壊滅
- 正義を掲げて中央権限を奪おうとした者の失脚

旧家層が全戦闘を台本どおりに起こしたわけではない。彼らは、権力を欲しがる者が中央ROOT、非常権限、超兵器、凍結資産へ自ら集まる構造を理解し、止めずに利用している。

したがって、戦争は「完全に仕組まれた偽物」ではなく、実在する被害と憎悪を中間支配層が拡大し、その抵抗が結果として自分たちの選別と解体へつながる構造である。

# 4. 国家元首級の人物

セラ、エレム、ケデムの大統領・首相級は、原則として物語の主悪役にしない。

彼らは権力者を演じ、強硬な演説を行い、実権を持つように見える。しかし深層では、旧家層が進める長期的な平和移行へ概ね従順な表の代表者である。

- 首都への無制限攻撃を避ける。
- 大量破壊兵器の使用線を維持する。
- 秘密回線と停戦窓口を最後まで残す。
- 軍部・企業・情報機関の暴走を完全には止められない。
- 平時移行の最終署名者にはなれるが、社会を自力で変える救世主ではない。

ケデムの国家再生政権も、大統領個人が過激思想の首魁なのではない。大統領は国家の顔を演じ、実働の過激派治安部門、軍部、軍需企業、外国顧問が自分の大義と利益で戦争を進める。

国家元首は暗殺対象、最終ボス、真相を語る人物にしない。

# 5. 主人公が歩める三つの方向

主人公は最初から旧家層の選ばれた救世主ではない。

敵を撃墜し、報酬を得て、より強い機体を買い、名声と権限を受け取ることで、中間支配層と同じ階段を上る。

プレイヤーは、その力を何のために使うかを最後に選ぶ。

## 5.1 粛清される側へ回る

主人公が世界を救った功績を理由に中央権限を保持し、平時への異動を拒むと、新しい中間支配者になる。

### `GIBOR`

主人公は保護と安定のために、ギボル権限と世界認証を返さない。

表向きには戦争を終わらせた英雄だが、内部的には、平和への再編を拒否した最後の巨大な部長となる。旧家層が退場できない原因となり、将来の整理・失脚・粛清対象へ自ら入る。

### `RELEASE`

主人公は「解放こそ愛」という大義で本人の意思と肉体を奪い、大量破壊を正当化する。

表向きには戦争を早く終え、多くを救った英雄になり得る。しかし内部的には、思想を使って中央権力を維持する新しい作戦責任者となり、同じく粛清される側へ回る。

この二つのエンドで、旧家が主人公を処刑する場面は描かない。主人公が勝利したように見える余地を残しながら、構造上は自分が倒してきた者と同じ位置へ着いたことを内部正本とする。

## 5.2 不完全な平和を選ぶ

### `ONE SHEM`

主人公は個人への非常権限を返すが、一つの認証と管理秩序は残す。

戦争は終わり、実際に多くの生活が守られる。しかし人類はまだ中央管理へ依存しており、旧家層は支配をやめられない。

### `ONE EMET`

主人公は旧い中央ROOTを壊すが、一つの盟約と一つの真理へ世界をまとめる。

凍結された人々は救われるが、異なる価値を異なるまま認める段階には届かない。旧家層の管理と別形式の中央集権が入れ替わるだけで、退場条件は満たされない。

通常エンドは失敗扱いにしない。どちらも本物の平和と救済を生むが、人類が自分で立つところまでは進まない結末である。

## 5.3 平和への道を歩く

### `ALL NAMES`

主人公は、新しい王、世界管理者、粛清の執行者になることを拒否する。

- 中央ROOTを十二地域へ分ける。
- 地域の鍵をさらに共同体と個人へ渡す。
- 複数の通貨、信用網、身元証明、価値観を併存させる。
- 一つの失敗で全権限を中央へ戻せない構造にする。
- 敵だった相手の価値と署名を、自分の中央を通さず承認する。

これが、全員が一つの巨大な塔へ入るのではなく、全員が自分の小さなバベルを持つ社会である。

旧家層を倒したから自由になるのではない。人類が、旧家層に管理されなくても互いを信じられる可能性を示すことで、旧家層自身も支配者の役割から退場できる。

# 6. 愛と分散技術

分散型通貨、地域通貨、仮想通貨、分散型身元証明、複数ROOTは、真エンドの道具であって救済そのものではない。

恐怖した人間が一人の救世主を求める限り、分散技術も再び一つへ集められる。

本作における愛は、全員を同じ価値観へ従わせることではない。

```text
自分には、中央の許可なしに価値を持つ資格がある。
他人にも、自分とは異なる価値を持つ資格がある。
相手を完全に理解できなくても、鍵と責任を預けることができる。
```

旧家層も、この愛を制度として製造できないことを知っている。

彼らができるのは、中央の椅子を用意し続けることではなく、誰かがその椅子を拒否できる日まで世界を壊さず維持することだけである。

# 7. ゲーム内で直接描写しない絶対規約

以下をゲーム本文へ出してはならない。

- 「旧家」「中世貴族」「世界の本当の所有者」という名称
- 旧家の会議、会話、人物、紋章、秘密基地
- 大統領が役者だったと告白する場面
- 「すべては人事異動だった」「戦争は粛清だった」という説明
- 旧家が全戦闘を計画したと断定する資料
- 旧家を倒す最終ボス戦
- 真相を知る一人の解説者
- 陰謀の証拠を集めて全貌を暴露するサブストーリー
- プレイヤーへ旧家の存在を推理させることだけを目的とした露骨な伏線

ゲーム内で許されるのは、表層の物語から自然に生じる結果だけである。

- 国家元首が最終ボスにならない。
- 首都壊滅ではなく、軍部、私兵、調達拠点、認証施設が戦場になる。
- 戦争を煽った司令官や企業部門が、終戦時に地位と権限を失う。
- 国家元首は戦後会談と平時移行へ残る。
- 主人公へ世界規模の権限が提示される。
- 中央が止まった地域で、人々が独自の信用と交換を始める。
- 真エンドでは、誰が裏で望んでいたかを語らず、旧い管理が不要になる結果だけを示す。

これらも「旧家の存在を匂わせる演出」として強調しない。表の制度と登場人物の選択だけで説明できる描写に留める。

# 8. ミッション・ボス・結末への実装規約

## 8.1 ミッション目標

主な敵目標は、国家元首ではなく次に置く。

- 軍司令部と作戦局
- 私兵・過激派旅団
- 軍需・調達・兵站拠点
- 秘密飛行場と契約部隊
- 超兵器の運用部門
- 中央権限を奪おうとする強硬派
- 人道回廊や停戦を妨害する現地指揮官

## 8.2 ボス

ボスは、旧家ではなく、戦争によって権限を得た中間支配層とその兵器である。

- エース中隊
- 私兵航空隊
- 軍需企業の試作機
- 強硬派司令官
- 自動防衛網
- 中央ROOT、ケレン、オファン、ルアの軍事運用形態

## 8.3 結末

エンディング本文で「主人公が粛清対象になった」「旧家が退場した」と説明しない。

- `GIBOR`と`RELEASE`は、主人公が中央の座を選んだ結果を描く。
- `ONE SHEM`と`ONE EMET`は、本物だが中央依存を残す平和を描く。
- `ALL NAMES`は、旧家や陰謀を見せず、複数の地域と個人が自分の鍵を持ち始める結果を描く。

## 8.4 QA

今後の脚本・ミッション監査では次を確認する。

- 国家元首を安易な悪役・暗殺目標にしていないか。
- 戦争継続の主体が、軍部、企業、情報機関、過激派などの中間層として見えるか。
- 本書の深層設定を説明台詞にしていないか。
- 主人公が権限を求めるほど、粛清される側と同じ位置へ近づく構造があるか。
- 真エンドが「旧家を倒す」ではなく「旧家を不要にする」結末になっているか。
- 分散技術だけを善とせず、人の愛と相互承認を成立条件にしているか。

# 9. 内部用の一文

> 表では国家間の代理戦争。中層では平時への異動を拒んだ軍需・軍部・情報機関の抵抗と整理。深層では、人類を管理し続けることに疲れた旧家が、新しい王ではなく王を必要としない人類を待っている。主人公は中央の座を奪って粛清される側へ回ることも、その座を拒んで旧家すら退場できる平和への道を開くこともできる。
