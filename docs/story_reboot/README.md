## v0.7で確定したゲーム性

- 通常機は作戦進行で購入許可が増え、そのうえで資金を払って購入する。
- ネームド撃墜や個別Sランクによる複雑な早期解禁は使わない。
- F-22はセラ編20本すべてS、Su-57はエレム編20本すべてSで直接支給する。
- F-22とSu-57は初回本編中には購入できず、全クリア後のやり込み機体とする。
- MiG-31はSR-71高高度迎撃の直前任務で、成績と資金に関係なく自動支給する。
- エレム編はセラ編より難しくするが、敵HP増加や理不尽な即時攻撃ではなく、複合状況と専門機選択で難しくする。
- セラのプレイアブルは米国系技術圏へ、エレムはロシア・旧ソ連系へ整理する。
- F-2AはF-16派生の対艦専門機としてセラへ残す。
- Typhoon、Rafale M、Gripen E、F-3は第三勢力アルカへ所属させる。
- F-3は日本・英国・イタリアの共同開発機を現実モチーフとする、アルカ最上位の三国共同研究機。
- アルカ機は`NON-TARGET`。攻撃・撃墜可能だが、スコア、ランク、ミッション成否、後続展開へ影響しない。
- 通常ミッションは原則三フェーズとし、薄い単目標任務を禁止する。
- 護衛任務は敵の最初の攻撃までの時間を測定し、Sランクが理論上可能であることを保証する。

## 中心方針

- 二つの本編キャンペーンは、同じ戦争計画から分岐する別世界線。
- 対応ミッションは戦略上つながるが、同一マップの表裏は重要な数組へ限定する。
- 各地域の主権、隣接地域、補給線、進攻方向を固定する。
- 各ミッションに、軍事目標、守る対象、プレイヤーが選べる優先順位を置く。
- 小さな選択は後続編成・景観・無線へ返し、大きな選択だけがエンディングを変える。
- セラ側の破滅は、完全な保護による自由の所有。
- エレム側の破滅は、完全な解放による本人意思と肉体の否定。
- 第一クリスマスでは、人間同士が中央命令なしでも一日撃たずにいられることを示す。
- 第二クリスマスでは、平和を一人の救世主へ所有させず、地域から個人へ鍵を返す。

## 制作上の注意

国家名・地域名・人物名は短く覚えやすい仮称。表示名を変更しても、地理ID、戦略上の役割、因果関係は維持する。

ゲーム本文では実在の国家、民族、宗教、金融機関、家系を直接名指ししない。神話的・歴史的な対応は内部制作上のモチーフとして管理し、画面には人間の選択、制度の働き、戦場の結果として表す。

333と666の意味を登場人物に解説させない。WAR DAYと日付だけを提示し、意味の発見はプレイヤーへ委ねる。
