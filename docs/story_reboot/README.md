# ARCAの確定規約

ARCAは中立を名乗る西側起源の小国連合治安機構。

| キャンペーン | 時期 | ゲーム上の関係 | 色 |
|---|---|---|---|
| セラ編 | 序盤 | 準友軍 | 青 |
| セラ編 | 中盤以降 | 攻撃可能な非TGT敵 | 白 |
| エレム編 | 全編 | 攻撃可能な非TGT敵 | 白 |

ARCAが赤TGTになることは禁止する。

敵対ARCAは普通にロック、攻撃、撃墜でき、ARCA側も機銃とミサイルで攻撃する。ただし撃墜はミッションクリアに不要。

```text
faction: "arca"
tgt: false
rankNeutral: true
```

ARCA撃墜は表示スコアと`bonusKills`を増やす。一方、ランクの母数・分子には入れないため、無視しても撃墜してもS条件自体は変わらない。

> v0.7以前の「ARCAは攻撃しない」「撃墜スコア0」、v0.10の「敵性は赤」は廃止。

# v0.7から継承するゲーム性

- 通常機は作戦進行で購入許可が増え、そのうえで資金を払って購入する。
- ネームド撃墜や個別Sランクによる複雑な早期解禁は使わない。

# 中心方針

- 二つの本編キャンペーンは、同じ戦争計画から分岐する別世界線。
- 対応ミッションは戦略上つながるが、同一マップの表裏は重要な組へ限定する。
- 各地域の主権、隣接地域、補給線、進攻方向を固定する。
- 同じ地域の再訪は、別国家への名前替えではなく、同一`regionId`の別区画・時刻・損傷として表す。
- 各ミッションに軍事目標、守る対象、プレイヤーが選べる優先順位を置く。
- 小さな選択は後続編成・景観・無線へ返し、大きな選択だけがエンディングを変える。
- セラ側の破滅は、完全な保護による自由の所有。
- エレム側の破滅は、完全な解放による本人意思と肉体の否定。
- 第一クリスマスでは、人間同士が中央命令なしでも一日撃たずにいられることを示す。
- 第二クリスマスでは、平和を一人の救世主へ所有させず、地域から個人へ鍵を返す。

# 制作上の注意

ゲーム本文では実在の国家、民族、宗教、金融機関、家系を直接名指ししない。神話的・歴史的対応は内部制作モチーフとして管理し、画面には人間の選択、制度の働き、戦場の結果として表す。

333と666の意味を登場人物に解説させない。WAR DAYと日付だけを提示し、意味の発見はプレイヤーへ委ねる。
