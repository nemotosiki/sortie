## 中心方針

- 二つのキャンペーンは同じ戦争計画から分岐する別世界線。
- 対応ミッションは戦略上つながるが、同一マップの表裏は4組だけ。
- 各地域の主権、隣接地域、補給線、進攻方向を固定する。
- 各ミッションに、軍事目標、守る対象、プレイヤーが選べる優先順位を置く。
- 小さな選択は後続編成・景観・無線へ返し、大きな選択だけがエンディングを変える。
- 米編の破滅は完全な保護による自由の所有、露編の破滅は完全な解放による本人意思と肉体の否定。
- 真章は中央を破壊するのではなく、中央機能を十二地域へ分けて異なる制度を共存させる。

## 五つの結末

- `ONE SHEM` — セラ通常
- `GIBOR` — セラ裏切り
- `ONE EMET` — エレム通常
- `RELEASE` — エレム裏切り
- `ALL NAMES` — 四エンド後の真章
