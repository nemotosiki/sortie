## v0.4で確定した変更

- 戦争期間を**333日間**へ統一する。
- 暦は平年を基準とし、**1月27日をWAR DAY 001、12月25日をWAR DAY 333**とする。
- 本編ミッション数は**44本**のまま維持する。
- セラ編を `M01〜M22`、エレム編を `M23〜M44` とする。
- セラ最終戦M22とエレム最終戦M44は、どちらの世界線でも**12月25日05:40、ミガル中枢**で始まる。
- 333日という長さを、占領統治、損傷復旧、季節変化、人物関係、休戦交渉、新兵器投入、超兵器完成へ使う。
- 44ミッションは333日間に起きた全戦闘ではなく、二人の主人公が歴史を変えた決定的な44回の出撃である。
- 12月24日夕刻から予定されていたクリスマス休戦が、中央ROOTとルアを巡る相互不信によって崩れ、最終決戦へ入る。
- 真章 `ALL NAMES` は本編44本の外側に置くEX章とし、本編番号を消費しない。

## 中心方針

- 二つのキャンペーンは同じ戦争計画から分岐する別世界線。
- 対応ミッションは戦略上つながるが、同一マップの表裏は重要な4組程度に限定する。
- 各地域の主権、隣接地域、補給線、進攻方向を固定する。
- 各ミッションに、軍事目標、守る対象、プレイヤーが選べる優先順位を置く。
- 小さな選択は後続編成・景観・無線へ返し、大きな選択だけがエンディングを変える。
- セラ側の破滅は完全な保護による自由の所有、エレム側の破滅は完全な解放による本人意思と肉体の否定。
- 真章は中央を壊すのではなく、中央機能を地域から個人へ分配し、異なる制度を異なるまま共存させる。
- クリスマスを単なる背景装飾にしない。「救世主を一人へ求める誘惑」と「名もない人同士が同じ夜を守る愛」を、同じ12月25日に重ねる。

## 制作上の注意

本書の国家名・地域名・人物名は短く覚えやすい仮称であり、表示名を変更しても地理ID・戦略上の役割・因果関係は維持する。

ゲーム本文では、実在の国家、民族、宗教、金融機関、家系を直接名指ししない。神話的・歴史的な対応は内部制作上のモチーフとして管理し、画面には人間の選択、制度の働き、戦場の結果として表す。クリスマスは世界で広く共有される民間の祝日・休戦慣行として登場させ、特定宗派の正しさを説明する場にはしない。
