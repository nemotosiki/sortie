## 中心方針

- 二つのキャンペーンは同じ戦争計画から分岐する別世界線。
- 対応ミッションは戦略上つながるが、同一マップの表裏は4組だけ。
- 各地域の主権、隣接地域、補給線、進攻方向を固定する。
- 各ミッションに、軍事目標、守る対象、プレイヤーが選べる優先順位を置く。
- 小さな選択は後続編成・景観・無線へ返し、大きな選択だけがエンディングを変える。
- 米編の破滅は完全な保護による自由の所有、露編の破滅は完全な解放による本人意思と肉体の否定。
- 真章は中央を破壊するのではなく、中央機能を十二地域へ分けて異なる制度を共存させる。

## 五つの結末

- `ONE EMET` — エレム通常

- 固定領土、地域間距離、補給線、18日間の戦線推移
- 両陣営の政治構造、軍事ドクトリン、主要人物の感情曲線
- 全40ミッションの戦域、天候、味方・敵編成、フェーズ、選択、物語本文
- 同時作戦、撃破順、任意目標、13種類の世界状態フラグ
- 17基礎マップの地域台帳と再訪差分の規則
- 新規航空機、艦艇、地上兵器、回転翼、標準戦力パッケージ
- 超兵器ケレン、オファン、広域破壊弾ルア
- 四エンド、真章M41、白い収束照準の配置
- 現行機構で可能な範囲と、本体拡張が必要な機能の切り分け

## 制作上の注意

本書の国家名・地域名・人物名は短く覚えやすい仮称であり、表示名を変更しても地理ID・戦略上の役割・因果関係は維持する。

ゲーム本文では、実在の国家、民族、宗教、金融機関、家系を直接名指ししない。神話的・歴史的な対応は内部制作上のモチーフとして管理し、画面には人間の選択、制度の働き、戦場の結果として表す。
