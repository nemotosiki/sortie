# Sortie 新キャンペーン設計書

**現行版:** v0.5 / 2026-08-02  
**状態:** 新規キャンペーン設計の正本候補。コード実装前。  
**本編:** 333日戦争・40ミッション（セラ編20本＋エレム編20本）。  
**本戦最終決戦:** WAR DAY 333、12月25日・クリスマス。  
**EX:** EX01〜EX04を含め、ゲーム全体は44ミッション。EX04はWAR DAY 666。

旧ストーリーは引き継がず、現在のゲームシステムと再利用可能なユニット資産だけを参照して、世界地図から作り直した設計パッケージである。

## v0.5で確定した構成

- 本編は**全40ミッション**。
- セラ編は `M01〜M20`、エレム編は `M21〜M40`。
- 本戦は**333日間**。1月27日をWAR DAY 001、12月25日をWAR DAY 333とする。
- M20とM40は、どちらの世界線でも12月25日05:40のクリスマス最終決戦。
- EX章は `EX01〜EX04` の4本。全体のミッション数は**44本**。
- EX04 `ALL NAMES` はWAR DAY 666に発生し、物語全体の最終ミッションとなる。
- 333日目は軍事史上の本戦最終決戦、666日目は中央権限を個人へ返す真の最終戦として呼び分ける。
- セラ世界線とエレム世界線の損傷・人物・選択フラグは共有しない。四エンド閲覧履歴だけがEX章を解禁する。

## 中心方針

- 二つのキャンペーンは同じ戦争計画から分岐する別世界線。
- 対応ミッションは戦略上つながるが、同一マップの表裏は重要な4組程度に限定する。
- 各地域の主権、隣接地域、補給線、進攻方向を固定する。
- 各ミッションに、軍事目標、守る対象、プレイヤーが選べる優先順位を置く。
- セラ側の破滅は完全な保護による自由の所有、エレム側の破滅は完全な解放による本人意思と肉体の否定。
- 姿なき収束には名前も声も与えず、最も効率的な一つの標的を示す白い照準として表す。
- EX真章の答えは分散技術そのものではなく、信じ切れない他者へ自分の大切なものを預ける行動として描く。

## 五つの結末

- `ONE SHEM` — セラ通常
- `GIBOR` — セラ裏切り
- `ONE EMET` — エレム通常
- `RELEASE` — エレム裏切り
- `ALL NAMES` — EX04で成立する真エンド

## 制作上の注意

本書の国家名・地域名・人物名は仮称であり、表示名を変更しても地理ID・戦略上の役割・因果関係は維持する。

ゲーム本文では、実在の国家、民族、宗教、金融機関、家系を直接名指ししない。神話的・歴史的な対応は内部制作上のモチーフとして管理し、画面には人間の選択、制度の働き、戦場の結果として表す。
