# 13. 同時作戦と出撃順

## 米編

### M03 / M04 — 港と海峡

- **M03先行:** 港へのヘリ上陸を抑え、M05の敵地上戦力を減らす。M04では艦隊が海峡奥へ進む。
- **M04先行:** 上陸艦を海上で減らし、M05の大型車両を減らす。M03では港湾施設の損害が増える。

### M07 / M08 — 救難と奇襲

- **M07先行:** 人員を救える。M08の敵配置情報が不足。
- **M08先行:** 夜襲が容易。M07で救難ビーコンが一つ失われる。

### M13 / M14 — 物資と海岸

- **M13先行:** 医薬品が届く。上陸部隊が増える。
- **M14先行:** 海岸を守る。輸送機が一機減る。

### M16 / M17 — 帰る場所と守る街

- **M16先行:** 空母が生存し最終戦の支援が増える。ミガル外環が損傷。
- **M17先行:** 市街への爆撃を減らす。空母が大破し、補給が減る。

## 露編

### M23 / M24 — 山道と艦隊

- **M23先行:** 港に近い着陸地点を確保。艦隊が海峡で長く待ち、損害が増える。
- **M24先行:** 艦隊を安全に通す。ヘリ部隊は危険な谷へ入る。

### M27 / M28 — 情報と基地

- **M27先行:** セラ空母を発見。ノル基地への空襲が激化。
- **M28先行:** 技術者と工場を守る。空母位置が不明確になる。

### M33 / M34 — 補給線と橋頭堡

- **M33先行:** ミガルの防空・医療補給を削る。上陸部隊が海上で待機し損害。
- **M34先行:** セラ領へ早期上陸。輸送隊がミガルへ到達する。

### M36 / M37 — 空母と認証鍵

- **M36先行:** セラ航空支援を減らす。REEM 2遠隔掌握への対処時間が短くなる。
- **M37先行:** 僚機救出が容易。空母機動部隊がM40へ残る。
