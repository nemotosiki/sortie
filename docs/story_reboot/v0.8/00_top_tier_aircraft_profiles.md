# 1. 確定評価

| 機体 | 安定性 | スピード | ミサイル搭載数 | 耐久度 | 機動性 |
|---|:---:|:---:|:---:|:---:|:---:|
| **F-22** | **S** | **A** | **S** | **A** | **A** |
| **Su-57** | **B** | **B** | **B** | **A** | **S** |
| **F-3** | **A** | **S** | **A** | **B** | **B** |

この五軸を、ハンガー表示と実際の飛行性能の両方に一致させる。

# 2. 三機の役割

## F-22 — 安定性と継戦能力

F-22は三機の中で最も安定し、最も多くの通常ミサイルを搭載する。

- 高G旋回後も姿勢が乱れにくい。
- 照準軸が安定し、遠距離戦と連続交戦に向く。
- ミサイル搭載数は三機中最多。
- 速度と機動性も高水準だが、それぞれF-3とSu-57には譲る。
- 初回本編では購入不可。セラ編20ミッション全Sで直接支給する。

プレイヤーから見た印象は、**どの局面でも崩れず、長い任務を最後まで戦い切る機体**とする。

## Su-57 — 機動性

Su-57は三機の中で最も高い機動性を持つ。

- 瞬間旋回、低速機首振り、ヨー、ポストストールを最上位にする。
- 接近戦ではF-22とF-3より強い。
- 安定性、速度、ミサイル搭載数はBとし、万能機にはしない。
- 激しい機動では速度と射撃安定性を失いやすい。
- 耐久度はF-22と同じA。
- 初回本編では購入不可。エレム編20ミッション全Sで直接支給する。

プレイヤーから見た印象は、**近距離で機首を向け続ける代わりに、長時間の任務では弾数と安定性を管理する機体**とする。

## F-3 — スピード

F-3は三機の中で最も速い。

- 最高速度を三機中1位にする。
- 高速域への到達と離脱を得意とする。
- 安定性とミサイル搭載数はA。
- 耐久度と機動性はB。
- ドッグファイトでSu-57へ勝つ機体ではなく、速度差で交戦位置を選ぶ機体とする。
- F-22より高速だが、旋回・耐久・搭載力では劣る。
- アルカ専用の `NON-TARGET` とし、プレイアブルにはしない。

プレイヤーから見た印象は、**追いつきにくく、交差後に一気に距離を取る高速妨害機**とする。

# 3. 相対順位

| 軸 | 1位 | 2位 | 3位 |
|---|---|---|---|
| 安定性 | F-22 | F-3 | Su-57 |
| スピード | F-3 | F-22 | Su-57 |
| ミサイル搭載数 | F-22 | F-3 | Su-57 |
| 耐久度 | F-22 = Su-57 | F-3 | — |
| 機動性 | Su-57 | F-22 | F-3 |

耐久度AのF-22とSu-57は同格を基本とする。機体ごとの差を付ける場合も、ハンガー表示の評価が変わらない範囲に留める。

# 4. 実装契約

## 4.1 グレードを実数へ落とすとき

- 現行の機体性能表とハンガーの正規化計算を実測してから数値を決める。
- 表示だけS/A/Bにして、実際の順位が逆になる状態を禁止する。
- SとA、AとBの差は、通常飛行で体感できる大きさにする。
- 一軸のSが、他の四軸の弱点を完全に消すほど強くならないようにする。

## 4.2 ミサイル搭載数

ここでいう「ミサイル搭載数」は通常ミサイルの総搭載数を指す。

```text
F-22 > F-3 > Su-57
```

特殊兵装の種類と弾数は別軸とし、この順位を逆転させる万能兵装を持たせない。

## 4.3 F-3のアルカ挙動

F-3は非目標妨害機なので、スピードSを次の動きへ使う。

- 戦闘空域へ高速進入する。
- プレイヤーと敵編隊の間を短時間で横切る。
- 警告ロック後、追跡される前に離脱する。
- 外洋、高高度、都市外環など広い戦域へ配置する。
- 狭い峡谷へ高速で押し込み、衝突を誘発する使い方はしない。

F-3を無視してもクリアとSランクが可能でなければならない。

# 5. 旧案の廃止

次の旧案は廃止する。

- F-3を三機中最高の持続旋回・ロール機とする。
- F-3、F-22、Su-57の主要数値をすべて同値にする。
- F-22を三機中の速度1位とする。
- Su-57をF-3より低い機動性にする。

最新の役割は次で固定する。

```text
F-22  = 安定性S・搭載数S
Su-57 = 機動性S
F-3   = スピードS
```
