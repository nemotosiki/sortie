## 内部バックボーンの要点

```text
旧家層:
管理によって平和を維持してきたが、自分たちも支配階級をやめたがっている。

国家元首級:
表の代表者。基本的には平時移行へ従順で、主要な討伐対象にはしない。

中間支配層:
軍需、軍部、情報機関、私兵、過激派など、平時への人事異動を拒否して戦争を続ける主な悪人。

主人公:
平和へ移ることも、中央管理へ戻すことも、自分が次の支配者となって粛清される側へ回ることもできる。

ALL NAMES:
主人公と旧家層の双方が世界の所有者をやめ、人類が複数の価値・信用・通貨・鍵を自ら維持する。
```
