# 2. 今回修正した計画上の矛盾

## 2.1 ARCAの色

ARCAは陣営色で表示しない。

```text
セラ序盤ARCA   = 青い準友軍
セラ中盤以降   = 白い非TGT敵
エレム全編     = 白い非TGT敵
ARCAが赤TGT    = 禁止
```

敵対ARCAはロック、攻撃、撃墜が可能で、ARCA側も攻撃する。ただし撃墜は任務完了に不要。

## 2.2 ARCAの得点

旧v0.7の「スコアへ影響しない」は廃止する。

- 表示スコアと`bonusKills`は増える。
- `rankStats.spawnedValue`は増えない。
- `rankStats.playerKillValue`も増えない。
- ARCAを無視しても、撃墜しても、S条件そのものは変わらない。

## 2.3 画面外矢印

現行mainでは独立したターゲット方向矢印が削除済みである。

したがって、v0.11第4便の「画面外矢印を三色化」は、存在しない機能を前提にした記述として廃止する。再導入する場合はHUD設計を別便で決め、`contactDisposition()`を利用する。

## 2.4 マップ制作順

旧バッチは造形上の優先度で、サルク→ホワイト→ノル→カラン→レンの順だった。

新ストーリーを先に遊べるようにするには、**物語の依存順**を優先する。

```text
完成済み: サルク港、ホワイトパス
次: レン湾、アマル平原、ナハル海峡、アラド山地、ダマル海、オルム盆地
その後: カラン平原、ノル工業帯、ヴェル氷岸、ハドール、ミガル、ルメン
```

`docs/spec_map_batch1_20260803.md`の各マップ制作規格と検証ゲートは維持し、順序だけ本書を優先する。

## 2.5 真章の番号

旧文書に残る`M41 ALL NAMES`は廃止する。

```text
本編: M01〜M40
EX章: EX01〜EX04
真の最終決戦: EX04 ALL NAMES / WAR DAY 666
```

## 2.6 マップ再訪

同じ地域を別国家の土地として使い回さない。

再訪は必ず、同一`regionId`の別セクター、時刻、天候、損傷、世界線差分として扱う。

```text
regionId       = 地理そのもの
worldKey       = 見た目のプリセット
sectorId       = 同じ地域内の戦闘区画
damageState    = 橋・港・滑走路などの損傷
controlState   = 実効支配と配備
worldline      = セラ世界線 / エレム世界線 / EX世界線
```

# 4. ブランチとマージ方針

## 4.1 本体変更

HUD、ランク、友軍AI、セーブ、ミッション進行など`index.html`へ触れる作業は、常に一つの統合ブランチだけで行う。

```text
IFF基盤       chatgpt/reboot-air-iff-foundation
ARCA本体      chatgpt/reboot-arca-runtime
機体進行      chatgpt/reboot-aircraft-progression
キャンペーン  chatgpt/reboot-campaign-core
```

前段をmainへ取り込んでから次段を最新mainから作る。

## 4.2 マップ

マップは1枚1ブランチ、1ペイロードを基本とする。

```text
chatgpt/map-ren-bay
chatgpt/map-amal-plain
chatgpt/map-nahar-strait
...
```

マップ同士は並列制作可能だが、検収とmainへのマージは一枚ずつ行う。

## 4.3 ミッション

章ごとにブランチを分ける。

```text
chatgpt/reboot-sera-act1
chatgpt/reboot-erem-act1
chatgpt/reboot-sera-act2
...
chatgpt/reboot-ex-arc
```

必要なマップ、機体、ユニットがmainへ入る前に、正式ミッションブランチを開始しない。
