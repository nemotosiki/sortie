## 1. 33日戦争へ統一する理由

この戦争は、開戦から終結まで33日間とする。

- 港湾占領、山岳回廊突破、工業帯への侵攻、空母移動、ミガル包囲を成立させるには18日では短すぎる。
- 一方で数か月戦争にすると、一人のエースの活躍が戦線を直接反転させるエースコンバット的密度が薄れる。
- 33日なら、長距離航空戦力とシェムの高速物流による短期戦でありながら、補給、損傷復旧、政治判断、超兵器準備の時間も確保できる。

両世界線は同じ日付で進む。違うのは、プレイヤーが所属した側の決定的作戦が成功し、前線の向きが反転することだけである。

## 2. 本編44本の数え方

- `M01〜M22`: セラ世界線

## 4. 作戦休止日

33日間すべてに戦闘があるわけではない。次の日程は、部隊移動、修理、政治交渉、葬儀、避難、補給に使われる。

- **5日目:** サルク港の損傷評価とケデム政府の避難
- **8日目:** 嵐による航空作戦停止
- **10日目:** カラン平原へ地上軍を集結
- **12日目:** ノル鉄道戦前の偵察
- **14日目:** 長距離レーダー戦に備えた電子戦機展開
- **16日目:** 工業帯の損害・捕虜数を確認
- **19日目:** 休戦回廊後の政治交渉が決裂
- **22日目:** ミガル外周へ艦隊と輸送隊を集結
- **24日目:** 市街戦の被害集計と空母群再配置
- **26日目:** ミガル外環への最終航空作戦準備
- **30日目:** 超兵器戦後の損害、ROOT返還／ルア認証問題
- **32日目:** 最終攻撃前の最後通告

この休止日をデブリーフ、人物会話、戦線図、短い小説場面に使う。

## 5. 同時作戦として扱う組

実際に同時発生させ、出撃順で後続が変わるのは各陣営4組に限定する。

### セラ編

- M03 / M04 — 港と海峡
- M13 / M14 — 休戦回廊と補給線
- M14 / M15 — 物資と上陸阻止の一部時間帯が重複
- M17 / M18 — 帰る空母と守るミガル

### エレム編

- M25 / M26 — 山道と艦隊
- M29 / M30 — 海上情報と基地防衛
- M35 / M36 — 休戦回廊と補給線攻撃
- M39 / M40 — 空母攻撃とミガル進入路

M07/M08のように日付が離れた任務は同時作戦と呼ばず、先行任務の結果が次の任務へ影響する連続作戦とする。

## 6. 世界線間で共有しないもの

米編と露編は別世界線なので、次は共有しない。

- 市街の停電状態
- 橋・鉄道・港の損傷
- 民間人・僚機・隊長の生死
- 任意目標の撃破記録
- 超兵器部位の損傷
- 支持率、補給量、敵数

共有するのは、プレイヤーが四つのエンディングを閲覧したというメタ進行だけである。

対応ミッションでは同じ問題を逆の立場から見せるが、片方のセーブ値をもう片方へ注入しない。
