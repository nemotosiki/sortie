# 14. 四つのエンディング

## ONE SHEM — 米編通常エンド

### 条件

- M19でROOT分割ドローンを生存させる。
- M20で四評議会への移送を守る。

### 結果

- セラ・シェム側が戦争に勝利。
- シェムの一つの帳簿は存続。
- ギボル権限は共同評議会へ返還。
- ミガル外の地域は依然としてシェム認証へ依存する。
- 完全な救いではないが、主人公は自分だけを永久の正解にしない。

### 小説的終幕

夜明け後、ROOK 1のHUDからROOT表示が一つずつ消えていく。最後に残ったのは、自機の燃料と高度だけだった。世界は急に不便になり、評議会の回線では既に意見が割れている。MERIDIANは「また遅くなる」と言い、ROOK 2は「遅くても、俺たち以外が決められる」と答える。塔は残った。鍵だけが一人の手から離れた。

---

## GIBOR — 米編裏切りエンド

### 条件

- M19でROOT分割ドローンを破壊する。
- M20で中央ROOTを恒久化する。

### 結果

- 戦争、飢餓、大量破壊兵器の再発率は大幅に低下。
- 全世界の航空認証、信用、物流、武器使用権がROOK 1へ集約。
- 拒否は形式上可能だが、拒否者は取引、医療、移動、飛行ができない。
- MICAとROOK 2は死亡しないが、世界の外へ追放される。

```text
PERMANENT ROOT: GIBOR
VALID IDENTITIES: ONE SYSTEM
WORLD CONFLICT: 0
RIGHT TO REFUSE: 0
```

### 小説的終幕

戦争が終わった日、世界中の空港で同じ緑の灯が点いた。ROOK 1が承認した便だけが飛び、承認した薬だけが届き、承認した兵器だけが沈黙した。誰も爆撃されない。誰も飢えない。誰も彼の外へ出られない。白い照準はもう現れなかった。見るものと見られるものが同じになったからだった。

---

## ONE EMET — 露編通常エンド

### 条件

- M37でREEM 2を救う、または撃墜後にM40でルア搭載機を破壊する。
- M40で軍事ROOTだけを通常攻撃で破壊する。

### 結果

- エレム・エメト側が戦争に勝利。
- シェムによる十二州の資産・航空認証凍結が解除。
- ミガル都市と民間インフラは大部分が残る。
- エメト盟約が新秩序を作り、別の信仰・契約に対して排他的になり始める。

### 小説的終幕

ミガルの中枢は止まったが、街の灯りは残った。十二州の端末には「認証回復」の文字が並び、長く閉じていた店が開く。広場では一つの盟約が読み上げられ、人々が同じ言葉を唱える。REEM 1はその輪の外を飛ぶ。金融の鎖は切れた。次に結ばれる鎖が、まだ誰にも見えていないだけだった。

---

## RELEASE — 露編裏切りエンド

### 条件

- M37でREEM 2を撃墜してルアを解禁。
- M40でルア搭載機を最後まで護衛する。

### 結果

- ルアによりミガル中枢、市街、送電、医療、通信が広域崩壊。
- シェムは即時停止し、戦争も短期間で終わる。
- エメト軍の後続戦死者は大幅に減る。
- REEM 1は「都市を苦しみ得る未来から解放した」救世主として祭り上げられる。

```text
BODIES LOST: UNCOUNTED
HOSTILITIES: TERMINATED
RELEASE: COMPLETE
```

### 小説的終幕

ルアは大きな爆発を起こさなかった。光が街を一周し、その後ですべての灯りが消えた。POLARISの画面から航空機、病院、口座、名前が順番に落ちていく。VARGAは「終わった」と言う。再生されたREEM 2の声は「解放してくれてありがとう」と繰り返す。REEM 1だけが、その声が一度も新しい言葉を話していないことに気づく。

# 15. 真章 M41 — ALL NAMES

## 世界線上の位置

M41は、四つのエンディングの後を一本につないだ続編ではない。GIBORでは自由が閉じ、RELEASEではミガルが失われるため、両方の結果から同じ未来へ進むことはできない。

四エンドを見たプレイヤーだけに開く**第五の世界線**とする。分岐点はM19／M39の直前。MICA、MERIDIAN、POLARISが敵味方双方の作戦予測に同じ収束傾向があることを突き止め、ROOK 1とREEM 1へ一度だけ非公式の共通回線を開く。

二人の主人公は他世界線の記憶を持たない。知っているのはプレイヤーだけである。したがって真章は「登場人物がループを理解して正解を選ぶ話」ではなく、**プレイヤーが四つの末路を経験したことで、二人に第五の行動をさせられる話**になる。

- **解禁条件:** ONE SHEM、GIBOR、ONE EMET、RELEASEをすべて経験。
- **戦域:** ミガル中枢から世界各地へ伸びる十二の高高度航路。
- **プレイヤー:** ROOK 1またはREEM 1を選択。選ばなかった方が僚機。
- **任務:** 中央ROOTを十二の地域ノードへ分割搬送し、異なる規格のまま全ノードを生存させる。

## 味方戦力

- ROOK 1 / REEM 1
- ROOT輸送機×12
- 各地域の小規模防空隊
- 生存したROOK 2またはREEM 2
- MICA、MERIDIAN、POLARISの共同管制

## 敵戦力

- ギボル権限の継続を求めるシェム自動防衛軍
- 一つの盟約へ統一しようとするエメト強硬派
- オファン残存ノード
- 無人戦闘機群
- 旧エース隊の生存機

## ミッション構造

1. 中央ROOTを十二機へ分割する間、ミガル中枢を防衛。
2. 十二輸送機が異なる方向へ出発。
3. プレイヤーが救援順を自由に決める。
4. 一機を中央へ戻せば他の輸送機を強化できるが、その地域は独自ROOTを失う。
5. 一機でも失えば通常クリアは可能だが、真エンドには十二機全生存が必要。
6. 最後に中央オファンが十二輸送機を一つの照準へまとめようとする。
7. 十二機を守り切ると、巨大な白い照準が十二の小さな円へ割れる。

## 真章のストーリー

中央を一つに戻せば、戦闘はすぐ終わる。十二機を守るには、燃料も弾薬も時間も足りない。ROOK 1とREEM 1は何度も反対方向へ分かれ、互いの視界から消える。それでも一方が危機に陥るたび、もう一方のレーダーに救援方向が現れる。

最終局面で、白い照準が中央ROOTへ現れる。そこを撃てば、十二の戦場を一度に停止できる。プレイヤーが撃たず、最後の輸送機を守り切ると、照準は壊れずに分裂する。一本の命令が消えるのではない。十二の異なる答えへ戻る。

```text
CENTRAL ROOT: NONE
ROOT HOLDERS: ALL
MANDATORY CURRENCY: NONE
MANDATORY FAITH: NONE
RIGHT TO REFUSE: GUARANTEED
RIGHT TO LEAVE: GUARANTEED
```

> **TRUE END: ALL NAMES**

世界は安全にはならない。詐欺も戦争も失敗も再び起こり得る。ただし、誰か一人の正しさによって、全員の未来が完成させられることもなくなる。
