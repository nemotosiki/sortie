## 2. マップ `sarkPortAsh`

### 2.1 基本原則

`sarkPortAsh`は別都市ではない。

`map_sarkPort.payload.js`と次を完全一致させる。

- plateau形状・中心 `[0,-3000]`
- 運河位置
- 3本の橋
- クレーン列
- コンテナヤード
- 市街道路
- 倉庫区
- 港口・岸壁

新規制作は、同じ地理へ戦災差分を加える。

```text
payloads/map_sarkPortAsh.payload.js
```

### 2.2 必須戦災差分

- 西岸クレーン2基が停止、うち1基は傾斜
- 倉庫2棟が焼損
- 運河中央橋が通行不能
- 南側橋に仮設補修
- コンテナヤードの一部が崩れて通路化
- 沈没輸送ヘリまたは残骸
- 西岸に沈没船1隻
- 市街に複数の煙柱
- 朝日が煙で橙色に濁る
- M03で損傷した施設を追加反映可能

煙は視界を完全に奪わず、低空進入時のランドマークとして使う。

## 5. フェーズ

### PHASE 1 — 防空回廊を開く

RAVENは西海上から低空進入。

赤SAM×2、SPAAG×3を破壊し、地上軍の航空支援圏を開く。

敵配置:

- 北倉庫区SAM
- 西クレーン地区SAM
- 中央道路SPAAG
- 南運河沿いSPAAG
- 北側橋SPAAG

赤防空目標全滅で地上軍が前進。

### PHASE 2 — 市街装甲戦

地上軍が北東から中央へ進む。

赤戦車×6、IFV×3が道路・コンテナ通路で防御。

RAVENは味方地上軍の前方だけを攻撃する。地上部隊は建物へ埋まらない固定アンカー列を使用。

敵装甲の残数が3以下になるとMISSION UPDATE。

### PHASE 3 — 指揮車脱出

敵移動指揮車が南側へ逃走開始。

```text
MISSION UPDATE
DESTROY COMMAND VEHICLE
```

指揮車経路:

```text
南倉庫 → 運河南岸 → 南側補修橋 → 東脱出線
```

同時に南東から赤Ka-52×2、白MiG-29×4。

Ka-52は指揮車を援護し、味方戦車を攻撃。

RAVENは指揮車を追うか、先にKa-52を処理するかを飛行中に判断する。選択UIは出さない。

指揮車撃破、赤Ka-52撃破、残存赤地上TGT全滅で終了。

## 6. 成功・失敗

成功:

- 赤防空目標全滅
- 赤装甲目標全滅
- 移動指揮車撃破
- ケデム地上軍が西クレーン地区へ到達

失敗:

- 味方戦車4両全滅
- 指揮車が東脱出線へ到達
- RAVEN撃墜
- 18分経過

地上軍はスポーン直後に攻撃されない。PHASE 1完了まで待機する。
