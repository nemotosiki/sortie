目的:

M03と同じ場所へ戻り、クレーン、橋、倉庫の一部が損傷していることを見せる。防空制圧、地上軍前進、市街装甲戦、指揮車追跡、航空増援を順番に重ね、ACT Iの締めにふさわしい長さを持たせる。会話は悲劇的な再訪ではなく、以前見たマップが変化したことへの短い反応と作戦無線を中心にする。

## 1. 物語上の役割

M03で見たサルク港を戦災variantで再利用し、同じ場所を別のゲーム内容で遊ばせる。

```text
ROOK 1 CROWN
ROOK 2 RAVEN
ROOK 3 LARK
AWACS MERIDIAN
```

HEARTHとWRENも生存していれば共同戦闘者として登場する。ARCAはまだ青い準友軍。

大きな思想分岐や重い戦争論は作らず、地上軍の進路を開き、敵指揮車を逃がさない王道の対地ミッションとする。

### 無線上の役割分担

- **MERIDIAN**: 正式なSEAD目標、地上軍前進許可、TGT更新、指揮車逃走、航空増援。
- **CROWN**: 煙、市街、友軍との近接、対地進入の短い助言と軽口。損害への感想や人生訓は言わない。
- **LARK**: 前回との景観差、橋、味方戦車残数、指揮車の道路位置、RAVEN背後の敵。
- **HEARTH / WREN**: 使用可能な道路、橋、敵位置などの土地勘。
- **ケデム地上軍**: 進軍、被害、交差点・橋・クレーン地区の確保。
- **ARCA CAP**: 外周戦闘機の処理だけを報告。

CROWNは地上軍へ正式命令を出さない。MERIDIANとケデム地上指揮官が作戦を進め、CROWNはRAVENへ飛び方だけを短く伝える。

## 2. マップ `sarkPortAsh`

### 2.1 基本原則

`sarkPortAsh`は別都市ではない。

`map_sarkPort.payload.js`と次を完全一致させる。

- plateau形状・中心 `[0,-3000]`
- 運河位置
- 3本の橋
- クレーン列
- コンテナヤード
- 市街道路
- 倉庫区
- 港口・岸壁

新規制作は、同じ地理へ戦災差分を加える。

```text
payloads/map_sarkPortAsh.payload.js
```

### 2.2 必須戦災差分

- 西岸クレーン2基が停止、うち1基は傾斜
- 倉庫2棟が焼損
- 運河中央橋が通行不能
- 南側橋に仮設補修
- コンテナヤードの一部が崩れて通路化
- 沈没輸送ヘリまたは残骸
- 西岸に沈没船1隻
- 市街に複数の煙柱
- 朝日が煙で橙色に濁る
- M03で損傷した施設を追加反映可能

煙は視界を完全に奪わず、低空進入時のランドマークとして使う。

## 6. フェーズ

### PHASE 1 — 防空回廊を開く

RAVENは西海上から低空進入。

赤SAM×2、SPAAG×3を破壊し、地上軍の航空支援圏を開く。

敵配置:

- 北倉庫区SAM
- 西クレーン地区SAM
- 中央道路SPAAG
- 南運河沿いSPAAG
- 北側橋SPAAG

赤防空目標全滅で地上軍が前進。

煙柱の中へTGTを隠しすぎない。RAVENが一度通過して反転した時、次の防空陣地が別のランドマークと重なるよう配置する。

### PHASE 2 — 市街装甲戦

地上軍が北東から中央へ進む。

赤戦車×6、IFV×3が道路・コンテナ通路で防御。

RAVENは味方地上軍の前方だけを攻撃する。地上部隊は建物へ埋まらない固定アンカー列を使用。

敵装甲の残数が3以下になるとMISSION UPDATE前段へ進む。味方地上軍が中央交差点へ到着するまで、残存白固定機銃は戦闘を継続してよい。

### PHASE 3 — 指揮車脱出

敵移動指揮車が南側へ逃走開始。

```text
MISSION UPDATE
DESTROY COMMAND VEHICLE
```

指揮車経路:

```text
南倉庫 → 運河南岸 → 南側補修橋 → 東脱出線
```

同時に南東から赤Ka-52×2、白MiG-29×4。

Ka-52は指揮車を援護し、味方戦車を攻撃。

RAVENは指揮車を追うか、先にKa-52を処理するかを飛行中に判断する。選択UIは出さない。

指揮車撃破、赤Ka-52撃破、残存赤地上TGT全滅で終了。

## 10. 無線脚本

### 10.1 基本規約

- MERIDIANが正式なTGTと地上軍前進を管理する。
- CROWNは頼れる先輩として、煙、市街、友軍との近接、対地進入の方法を一文で話す。
- CROWNは損失を見て格言を言わない。地上車両が失われても、必要がなければ何も言わなくてよい。
- CROWNは「街を守る意味」「残ったものを数える」といった重い総括をしない。
- LARKは前回の港との差を短く拾い、味方地上軍と指揮車を読む。
- HEARTHは使用できる橋や敵位置を伝える。
- 地上軍無線は道路・交差点・橋・残数を中心にする。
- 指揮車追跡中は、背景会話より残距離警告を優先する。
