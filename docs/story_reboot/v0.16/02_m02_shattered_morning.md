## 1. 物語上の役割

M01に続く二回目の出撃。大きなドラマを進める回ではなく、ROOK三機の仕事ぶりとRAVENが一人で一方向を任されるようになったことを見せる。

```text
ROOK 1 CROWN
ROOK 2 RAVEN
ROOK 3 LARK
AWACS MERIDIAN
```

MERIDIANが正式な作戦指示を出し、CROWNは編隊内でRAVENが戦いやすい位置を作る。RAVENはPHASE 2で初めて一つの攻撃軸を事実上任されるが、英雄扱いや成長の大演説はしない。

### 無線上の役割分担

- **MERIDIAN**: 敵侵入軸、施設状況、TGT更新、TEL経路、MISSION UPDATE。
- **CROWN**: 低空目標への入り方、離脱方向、対地攻撃中の短い補助。説教、試験官のような評価、人生訓は使わない。
- **LARK**: 地上施設、火災、RAVEN背後の敵、TELの道路位置。
- **地上偵察・発電所・飛行場管制**: 目標発見と施設の業務状況。

CROWNは「東へ行け」と正式命令を出すのではなく、MERIDIANの指示を受けて「東側は任せる」と軽く支える。

## 2. マップ `amalPlain`

### 2.1 全体形

26km四方の平坦な農業・電力地域。

```text
                           NORTH +Z

             予備飛行場 ═══════
                    ＼      鉄道
                     ＼
       発電所 ●  -----変電所-----  東部果樹林 / TEL道路
                         ＼
                          ＼ 河川
                           ＼
             ROOK START       ＼
                           SOUTH
```

必須ランドマーク:

- 北西: 予備飛行場
- 西中央: 火力・ガスタービン発電所
- 中央: 大型変電所
- 北東〜東: 果樹林、防風林、農道
- 北側: 貨物鉄道
- 北東から南西へ蛇行する河川
- 平原全体: 農地格子、用水路、送電線

地上目標の位置を視認しやすくするため、平坦さを維持する。背景山は遠景だけ。

### 2.2 制作方針

```text
payloads/map_amalPlain.payload.js
```

- 低い大型plateauで農地と施設を支える
- 農地は薄い矩形タイルと畦道で表現
- 河川はdecoratorの暗い水面帯
- 送電線は低ポリ柱＋細線
- 発電所、変電所、飛行場、TEL道路はplateau上
- 建物密度を上げすぎず、空港・発電所・農地の三領域を遠景で判別可能にする

## 6. フェーズ

### PHASE 1 — 河川沿い低空侵入

**敵方向:** 北東  
**Su-24M:** `(+9000, 450, +8500)`から南西へ  
**護衛:** 高度1500m

攻撃機は河川に沿って発電所へ向かう。

RAVENは低空目標へ降下し、速度差と地表接近を学ぶ。

赤Su-24M×2を撃墜するとPHASE 2。

### PHASE 2 — 東から予備飛行場へ

PHASE 1終了から8秒後。

**敵方向:** 東  
**Su-24M:** `(+11500, 700, +2800)`から北西へ  
**護衛:** 高度1800m

MERIDIANが東側編隊をTGT指定する。CROWNはLARKを発電所側へ残し、RAVENが東へ移動しやすいよう白護衛を引き受ける。

選択UIは出さない。次の赤TGTが東に現れ、自然にRAVENが向かう。

### MISSION UPDATE — TEL確認

全Su-24M撃墜後、東部農道にTEL×4を表示。

```text
MISSION UPDATE
DESTROY MISSILE LAUNCHERS
```

TELは東部果樹林から北の鉄道積替地点へ移動する。

**TELルート:** `(+7200,+400)` → `(+5000,+3000)` → `(+1800,+7200)`

白SPAAG×2と移動SAM×1が随伴。

### PHASE 3 — 対地攻撃

RAVENがTELへ接近すると、南から白MiG-29×4が進入。

**方向:** 南  
**高度:** 2400m  
**目的:** RAVENをTELから引き離す

白戦闘機を全滅させる必要はない。TEL4両を破壊すれば残存戦闘機は撤退する。

TELは2両ずつ少し間隔を空けて走らせる。一度の爆撃で4両全滅させない一方、通常ミサイルでも複数回の攻撃進入で十分処理可能にする。

## 7. 成功・失敗

成功:

- 赤Su-24M×4撃墜
- 赤TEL×4破壊

失敗:

- RAVEN撃墜
- 発電所と予備飛行場の両方が破壊
- TEL2両以上が脱出線へ到達
- 20分経過

発電所または飛行場の片方が損傷しても続行する。大きなストーリー分岐にはせず、デブリーフと後続味方数の小差に留める。

## 9. 無線脚本

### 9.1 基本規約

- MERIDIANが攻撃軸と目標を指定する。
- CROWNは低空進入、離脱、再攻撃のコツを短く話すだけにする。
- CROWNはRAVENを試験する教官のように振る舞わず、成績や損害を人生訓へ変えない。
- CROWNの好感は「助ける」「手柄を奪わない」「気軽に任せる」「ミスを蒸し返さない」で作る。
- LARKは地上施設、火災、TELの道路位置、RAVENの背後を読む。
- TEL発見前に「巡航ミサイル発射機がいる」と先回りして言わない。
- PHASE 3では重要なTGT移動警告を背景会話より優先する。

## 11. QA

- 初期機F-16で全TGTへ到達可能
- TELが木や建物へ埋まらない
- 地上SAMがスポーン直後にRAVENへ発射しない

- CROWNが失敗や施設損害を人生訓へ変えない
- CROWNの台詞が説教、格言、道徳評価になっていない
- 標準プレイが12〜15分に収まる
- 無線がTEL距離警告を遮らない
