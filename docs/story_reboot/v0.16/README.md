## 共通無線トーン

開戦章は大規模なシリアスドラマとして演出しない。戦況そのものは分かりやすく伝えるが、人物に戦争哲学、人生訓、感傷的な総括を長く語らせない。

- **MERIDIAN**: 正式な作戦指示、TGT、方位、距離、残数、MISSION UPDATE。
- **CROWN**: 腕がよく、気さくで、面倒見のいい先輩。短い攻略ヒント、危険警告、軽い称賛や冗談だけを話す。
- **LARK**: プレイヤー近くの敵、地形、味方、損傷を短く報告する。
- **背景部隊**: 施設・艦隊・地上軍の業務無線に留める。

CROWNはプレイヤーのミスや味方損失を責めず、同時にそれを「何を守るか」「残ったものを数える」といった格言へ変換しない。必要がなければ何も言わず、必要な場合も次の操作だけを一文で伝える。

CROWNへの好感は重い台詞ではなく、次の積み重ねで作る。

```text
手柄を奪いすぎない
白敵を引き受ける
ミスを蒸し返さない
危険な時だけ助言する
時々軽口を言う
任務後は普通に一緒に帰る
```

この軽い関係を通常ルートで維持することで、GIBOR闇ルートにおけるCROWN / LARKの無言TGT化を成立させる。

## 開戦章の難度曲線

```text
M01  空対空の基本・爆撃機迎撃
M02  空対空から対地へのMISSION UPDATE
M03  低高度ヘリ・港湾防衛
M04  艦隊戦・機体選択の意味
M05  同一地域再訪・地上軍との共同奪還
```

M01では分岐を置かない。M02〜M05も大きなルート分岐は作らず、撃破順や取り逃がしによって増援・景観・デブリーフが少し変わる程度に留める。
