# 0. 修正理由

旧草案は、序盤から非TGT護衛にMiG-29A、Su-35級、F-15級などを置く箇所があり、次の問題がある。

1. **雑魚なのに機体そのものが強い。** `role: trash` で性能を落としても、MiG-29AやSu-35を序盤の消耗品として大量配置すると機体格の意味が消える。
2. **敵戦闘機が「何のためにいるか」が弱い。** プレイヤーを攻撃するためだけの白敵は、主任務と無関係なドッグファイトを増やす。
3. **後半の格上げが見えない。** M01からMiG-29AやSu-35が普通に出ると、後で同機が出ても戦況悪化を感じない。
4. **数を増やすほど戦略が浅くなる。** 白敵を一斉に湧かせると、TGTを選ぶゲームではなく全機撃墜ゲームへ戻る。

新キャンペーンでは、敵戦闘機一機一機に**戦術上の仕事**を与える。

```text
機体 = その部隊が持つ物理的な格
role = パイロットが機体性能をどこまで引き出すか
skill = 判断の質
purpose = その編隊が戦場へ来た理由
```

既存エンジンの `ENEMY_ROLES` / `SKILL_TIERS` を使う。HPはrole/skillで増減させない。

# 1. 絶対規約

## 1.1 非TGT戦闘機は「雑魚」ではなく「障害物」

赤TGTが**任務の主語**で、白敵はその主語を成立させるための戦術的障害物とする。

白敵の仕事は次のどれか一つ以上でなければならない。

- **SCREEN**: 爆撃機・攻撃機・輸送機へ近づくプレイヤーの進路へ割り込む
- **CLOSE ESCORT**: 護衛対象から離れず、対象が攻撃された時だけ強く反応する
- **TOP COVER**: 高度差を維持し、プレイヤーが低空／対地へ集中する間だけ上から圧力を掛ける
- **CAP**: 艦隊・基地・港など一定地点を守り、遠くまで追わない
- **QRA / RESERVE**: 戦闘開始後に遅れて到着し、長期戦へ時間圧を与える
- **PINNING PAIR**: 2機でプレイヤーを一時的に空戦へ拘束し、主任務側へ時間を与える
- **RELIEF FLIGHT**: 主任務が長引いた時だけ到着する追加の弱編隊
- **INTERCEPTOR**: 高速で一度切り込み、延々と旋回戦をせず離脱して再進入する

「プレイヤーの近くに湧いて、とにかく攻撃する」だけの白敵は禁止する。

## 1.2 序盤は機体そのものを弱くする

セラ編ACT Iの一般白敵は**MiG-21bisを基本**とする。

```text
MiG-21bis  = 序盤の普通の雑魚 / 局地防空 / 近接スクリーン
MiG-23     = 序盤の上位雑魚 / 高速迎撃 / 最初の明確な格上げ
MiG-29A    = 前線正規戦闘機 / M05で初めて少数登場
Su-33      = 艦隊CAPという用途限定でM04から少数登場
Su-35S     = ACT II以降の精鋭。ACT Iでは出さない
Su-47      = 中盤以降の希少機。雑魚運用しない
Su-57      = 終盤・ネームド・戦略警護。雑魚運用を永久禁止
MiG-31     = 高高度／長距離迎撃専用。通常CAPへ混ぜない
```

MiG-29Aを`trash/rookie`にしてM01から大量投入する方法は使わない。**機体格とpilot roleの両方で段階を作る。**

## 1.3 高性能機をtrashにしない

原則:

| 機体 | 最低role | 最低skill | 備考 |
|---|---|---|---|
| MiG-21bis | trash | rookie | 最も一般的な白敵 |
| MiG-23 | trashまたはline | rookie/regular | 高速迎撃用途 |
| MiG-29A | **line** | **regular** | 前線正規戦闘機 |
| Su-33 | **line** | **regular** | 艦隊CAP限定 |
| Su-35S | **elite**（後半はline可） | veteran | 序盤禁止 |
| Su-47 | **elite** | veteran | 希少機 |
| Su-57 | **ace / elite** | expert/veteran | generic trash禁止 |
| MiG-31 | line/elite | regular/veteran | 専門迎撃のみ |

戦争後半に熟練者不足を表現するためSu-35を`line/regular`へ落とすことは可能だが、`trash/rookie`にはしない。

# 2. 戦闘圧力の予算

以下はエンジン倍率ではなく**ミッション設計用の脅威ポイント**。

| 編成 | 設計ポイント |
|---|---:|
| MiG-21 trash/rookie | 1.0 |
| MiG-23 trash/rookie | 1.4 |
| MiG-23 line/regular | 2.0 |
| MiG-29A line/regular | 3.0 |
| Su-33 line/regular | 3.0 |
| Su-35 elite/veteran | 5.0 |
| Su-47 elite/veteran | 5.0 |
| Su-57 ace/expert | 8.0 |

ACT Iでプレイヤーへ同時に掛ける**白敵空戦圧力**の上限目安:

| Mission | 最大同時圧力 | 意図 |
|---|---:|---|
| M01 | 2〜3 | チュートリアル。主任務を邪魔しすぎない |
| M02 | 4 | 二正面を読みながら初の高速迎撃を経験 |

| M05 | 6 | MiG-29A初登場で明確に一段上げる |

白敵の**総数**はこれより多くてよい。ただし `delay` と目的別ロイターで分散し、全機が同時にプレイヤーへ殺到しない。

# 3. 編隊単位の規格

## 3.1 基本は2機単位

- 弱いスクリーン: 2〜4機
- 上位迎撃／QRA: 2機
- 艦隊CAP: 2機、後半のみ4機
- エース／高性能機: 1〜2機

「9機を一度に出す」のではなく、**2機の編隊を時間と目的で重ねる**。

## 3.2 速く主任務を終えれば増援を拒否できる

既存の遅延ウェーブ仕様を利用し、QRA / RELIEFは主任務が長引いた時だけ戦場へ来る。

これにより、白敵を全部撃墜するより、赤TGTへ集中した方が結果的に戦闘が短くなる。

## 3.3 白敵全滅をS条件にしない

- 白敵を全て無視してもS取得可能にする。
- BONUS KILLは得点上の小さな利益に留める。
- 白敵狩りをした方がタイム損失でSから遠ざかる場合があってよい。
- 「敵を全部倒す」が常に最適解になるスコア設計は禁止する。

# 4. セラ編ACT I — 正式敵航空編成

# M01 FIRST CONTACT

## 主任務

通常の爆撃機迎撃。v0.15/02の一本道構成を守り、分岐を増やさない。

### 赤TGT

- Tu-95級爆撃機 **4機**

4機を一つの横一列にせず、2機×2要素で進入させる。爆撃機はレン湾の投下線へ向かい続け、プレイヤーを追わない。

### 白敵

**MiG-21bis ×4、全機 `trash / rookie`。MiG-29Aは0。**

#### SCREEN A — 2機

- 開幕から爆撃機の約800〜1200m上・後方。
- 爆撃機へ接近するプレイヤーの前へ一度だけ切り込む。
- 主任務から2km以上離れて追撃しない。
- プレイヤーが無視すれば、後方から機銃パスを試みる程度。

#### RELIEF B — 2機

- 35〜50秒遅延。
- 爆撃機が2機以上残っている時だけ戦場へ到着する想定。
- プレイヤーが素早くTGTを処理すれば実質戦わず終わる。

### 戦術上の意味

MiG-21は「倒すべき敵」ではなく、**爆撃機を深追いできる時間を奪うスクリーン**。

CROWNの序盤無線もこのゲーム性に合わせる。

```text
CROWN: 護衛に釣られるな。爆撃機が赤だ。通すな。
```

M01で覚えるのは「白を全部倒す」ではなく、**赤TGTと白敵の優先順位**。

# M02 SHATTERED MORNING

## 主任務

高高度のSu-24攻撃隊と、河川沿いの低空巡航弾を同時に処理する二正面防衛。

### 赤TGT

- Su-24級 ×4（2機×2攻撃軸）
- 低空巡航弾 ×4

### 白敵

#### CLOSE ESCORT — MiG-21bis ×4

- `trash / rookie`
- 各Su-24ペアへ2機ずつ付く。
- Su-24から遠くへ追わず、プレイヤーが攻撃隊へ入った時だけ割り込む。

#### HIGH INTERCEPT — MiG-23 ×2

- **`line / regular`**
- M02で初めて「MiG-21とは違う敵」として見せる。
- 開幕からプレイヤーへ張り付かず、片方の攻撃軸へプレイヤーがコミットした後に上空から一度高速進入。
- 旋回戦ではなく、直線速度を使って離脱→再進入する。

### 戦術上の意味

- MiG-21を掃除していると巡航弾を通す。
- 巡航弾だけを追うとMiG-23が高所から切り込む。
- 初めて「弱い多数＋少数の上位機」を経験する。

**MiG-29Aはまだ出さない。**

# M03 LOW WATER

## 主任務

サルク港へ進むヘリボーン部隊と、避難区画・港湾防空を攻撃する攻撃ヘリのどちらを優先するかをプレイヤーの飛行で決める。

### 主戦力

- 武装輸送ヘリ ×3
- Ka-52 ×4
- Su-25 ×2（Phase 3のCAS）

輸送ヘリ／Ka-52のどこまでを赤TGTとするかはM03の選択実装便で最終決定する。少なくとも白敵戦闘機はクリア条件にしない。

### 白敵戦闘機

**MiG-21bis ×4、`trash / rookie`。MiG-23 / MiG-29Aは0。**

#### TOP COVER A — 2機

- 港湾上空800〜1200m。
- 低空ヘリ戦へ降りてきたプレイヤーを上から牽制する。
- 地表近くまで深追いしない。

#### RELIEF B — 2機

- Phase 2後半に到着。
- 港上空へ入るが、輸送ヘリのLZ周辺から離れない。

### Su-25の目的

Su-25を「遅い戦闘機」として使わない。

- 生存している港湾SPAAG
- LZ周辺
- 味方AH-64

を攻撃する**CAS資産**とする。

プレイヤーがKa-52を優先して港湾防空を守った場合、Su-25はSPAAGに妨害されやすい。輸送阻止を優先しKa-52を放置した場合、港湾防空が減ってSu-25が自由になる。

つまりPhase 1の選択がPhase 3の航空圧力へ返る。

### 戦術上の意味

M03の主役はドッグファイトではない。

```text
MiG-21 = 空に居続ける小さな邪魔
Ka-52 = 港の防空・避難区画を壊す
輸送ヘリ = 敵地上軍を港へ持ち込む
Su-25 = 選択結果を増幅するCAS
```

**MiG-29Aをここへ置くと、港湾選択より空戦が強くなりすぎるため禁止。**

# M04 NARROW SEA

## 主任務

揚陸艦隊を海峡出口へ到達させない。初めて艦隊防空そのものを攻略する。

### 白敵戦闘機

#### FLEET CAP — Su-33 ×2

- `line / regular`
- **ACT Iで初めて出る明確な高性能戦闘機。**
- 防空巡洋艦／揚陸艦隊を中心にCAPし、艦隊から遠くまで追わない。
- プレイヤーが艦へ攻撃進入した時だけ迎撃角を取る。

Su-33が強い理由は「雑魚が強い」からではなく、**空母・揚陸艦隊が正規艦載CAPを持っているから**。

#### SHORE RELIEF — MiG-21bis ×2

- `trash / rookie`
- 80〜110秒遅延。
- 長期戦だけに到着する沿岸基地の増援。

### 禁止

- MiG-29Aを4〜6機同時投入しない。
- Su-33を4〜6機でプレイヤー狩りに使わない。
- CAPが艦隊を捨てて盤面端まで追撃しない。

### 戦術上の意味

Su-33を倒すと安全になるが、その間にも揚陸艦は進む。無視して艦へ入れば、プロのCAPを背負ったまま対艦攻撃を行う。

**「敵戦闘機を落とすか、TGTを急ぐか」を艦隊の前進速度で成立させる。**

# M05 PORT OF ASH

## 主任務

戦災後のサルク港を奪還する。M03結果により地上敵数・港湾防空・損傷景観を変える。

### 白敵航空戦力

#### LOCAL DEFENSE — MiG-21bis ×4

- `trash / rookie`
- 2機が開幕、2機が後半RELIEF。
- 港内の地上軍から1.5〜2km以上離れない。
- 低空の味方A-10/F-4等を追い払うのが仕事。

#### QRA — MiG-29A ×2

- **M05で初登場。`line / regular`固定。**
- 内陸基地からPhase 2に高速進入。
- 無線とレーダーで「MiG-21とは違う正規前線戦闘機が来た」と分かるようにする。
- 主目的は地上TGTを守ることではなく、プレイヤーを60〜90秒ほど空戦へ拘束し、撤退／再配置中の地上部隊へ時間を与えること。
- 港から離れすぎた場合は追わず、再び戦域へ戻る。

#### CAS — Ka-52 ×2

- 地上部隊と連動。
- プレイヤーではなく味方地上軍／攻撃機を優先する時間帯を持たせる。

### MiG-29A初登場の演出

MiG-29Aをただ混ぜない。

```text
MERIDIAN: 新規反応2、高速。MiG-29。前線航空隊だ。
LARK: やっと正規軍が出てきたか。
```

M01〜M04でMiG-21／MiG-23を見てきたからこそ、同じ2機でもMiG-29Aが**戦況の格上げ**になる。

# 7. 実装マッピング

既存システムへ次のように落とす。

| 設計上のpurpose | 既存機構の使い方 |
|---|---|
| SCREEN / CLOSE ESCORT | strike/transportの近傍を目的地とするescort loiter、`concurrent:true` |
| TOP COVER | 主任務中心の高高度loiter、低高度への深追い制限 |
| FLEET CAP | 既存fleet loiter。艦隊中心を追従 |
| QRA / RELIEF | `delay`付き有限ウェーブ |
| INTERCEPTOR | 高速進入→離脱→再進入。無限旋回を避ける |
| PINNING PAIR | 2機だけをplayer-engageへ割り当て、他編隊は主任務を守る |

既存mainはすでに「airframe × role × skill」を分離しており、escort/fleet目的ロイターと遅延ウェーブも持つため、本書の大半は新しいAI基盤を作らずデータ・ミッション定義で実現できる。

# 8. QA規約

各新ミッション実装時に最低限確認する。

1. 白敵の各編隊にpurposeが一文で説明できる。
2. 序盤雑魚がMiG-29A/Su-35などの高性能機へ安易に置換されていない。
3. M01でMiG-29Aが0機である。
4. M01〜M03の一般白敵はMiG-21中心である。
5. M05のMiG-29A初登場が2機程度で、`line/regular`以上である。
6. Su-57は`trash`になっていない。
7. 白敵を全滅させなくてもミッションクリアできる。
8. 白敵を無視する攻略でもSランクが理論上可能。
9. 同時にプレイヤーへ殺到する戦闘機数が目的に対して過剰でない。
10. 強敵を増やす時は「機数を増やす」のではなく、機体格・pilot role・skill・戦術目的のどれを上げたのか説明できる。

# 9. 目標とする体感

M01のプレイヤー:

> MiG-21が邪魔だ。でもこいつらを追っている場合じゃない。爆撃機を止める。

M02:

> またMiG-21だ。……今度の2機は速い。MiG-23か。

M04:

> 艦の上の2機だけ動きが違う。CAPを剥がすか、SAMの中へそのまま入るか。

M05:

> MiG-21ではない。MiG-29が来た。ここから敵の正規航空戦力が前へ出てきた。

この**敵機を見ただけで戦争の段階が分かること**を、新キャンペーンの敵編成の基準とする。
