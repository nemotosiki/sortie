# 2. なぜSu-33を外すか

## 2.1 M04には敵空母がいない

M04の主役は、強襲揚陸艦、防空巡洋艦、ミサイル艇からなる上陸艦隊である。

Su-33を置くと、画面上に母艦が存在しないのに高性能艦載戦闘機だけが早期登場し、戦力の由来が読みづらい。

MiG-29Aなら、エレム側の沿岸前進基地から派遣された**陸上基地航空隊の艦隊上空援護**として自然に説明できる。

## 2.2 Su-33はMiG-29Aより格上の印象を残す

ACT Iで重要なのは、敵の格上げを一段ずつ読ませること。

```text
MiG-21 -> MiG-23 -> MiG-29A
```

ここへSu-33を挟むと、M04だけ急に高性能機へ飛び、その後M05でMiG-29Aへ戻るため、敵戦力の成長線が逆転して見える。

## 2.3 M04の難しさは艦隊防空で作る

M04には既に、

- 防空巡洋艦の長射程SAM
- 艦艇CIWS
- 前進し続ける揚陸艦
- 対艦攻撃の接近リスク

がある。

白敵戦闘機まで強機体にして難しくする必要はない。MiG-29A ×2でも十分に「空を無視できない」圧力になる。

# 3. M04 正式白敵航空編成

## FLEET COVER — MiG-29A ×2

```text
aircraft: MiG-29A
role: line
skill: regular
count: 2
purpose: FLEET COVER / CAP
TGT: false
```

### 出自

エレム沿岸前進基地から派遣された正規前線航空隊。艦載機ではない。

上陸艦隊がナハル海峡を抜ける時間だけ航空援護を担当している。

### 行動

- 艦隊中心からおおむね1.2〜2.0kmのCAP圏を維持する。
- プレイヤーが艦隊へ攻撃進入した時にのみ積極迎撃する。
- 艦隊から2.5〜3km以上離れて深追いしない。
- プレイヤーが離脱すれば、追跡よりCAP復帰を優先する。
- 2機が同じ相手へ常時張り付かず、片方が接触、もう片方が艦隊側に残る時間を作る。

### 戦術目的

この2機は「倒すために置かれた雑魚」ではない。

**プレイヤーの対艦攻撃コースを崩すための航空障害物**である。

プレイヤーには三つの攻略が成立する。

1. **CAPを先に落とす**  
   対艦攻撃は安全になるが、揚陸艦が海峡出口へ近づく。

2. **CAPを無視して艦を急ぐ**  
   時間は稼げるが、MiG-29を背負ったままSAM圏へ入る。

3. **片方だけ落として圧力を半減させる**  
   完全制空を取らず、主任務との妥協点を選ぶ。

3番を成立させることが重要。敵戦闘機を「全滅か無視か」の二択にしない。

# 4. SHORE RELIEF — MiG-21bis ×2

00の基本思想を維持するが、MiG-29と同時に4機全部がプレイヤーへ殺到しないよう条件を付ける。

```text
MiG-21bis x2
role: trash
skill: rookie
purpose: RELIEF FLIGHT
TGT: false
arrival: 90秒前後、またはCAP損耗後
```

- 沿岸基地から遅れて到着する二線級部隊。
- MiG-29Aが2機とも健在な序盤には原則としてプレイヤーへ集中させない。
- MiG-29Aが1機以下になる、または戦闘が長期化した時に援護へ入る。
- 艦隊から遠くへ追わない。

これによりM04の同時空戦圧力は基本**MiG-29A 2機まで**に保つ。

# 5. M05のMiG-29Aは「初登場」ではなく「役割の変化」

M05 `PORT OF ASH` のMiG-29A ×2 QRAは維持する。

ただし演出の意味を変更する。

旧:

> MiG-21ではない。MiG-29が来た。ここから敵の正規航空戦力が前へ出てきた。

新:

> 海峡で艦隊を守っていたMiG-29が、今度は内陸基地から迎撃に上がってくる。

M04では**守備的CAP**、M05では**攻撃的QRA / PINNING PAIR**として同じ機体を使う。

### M05 QRA

- MiG-29A ×2
- `line / regular`
- 内陸基地から高速進入
- プレイヤーを一時的に地上TGTから引き離す
- 地上部隊が撤退・散開・再配置する時間を買う
- 港湾から離れすぎれば追撃を中止し戦域へ戻る

同じMiG-29Aでも、

```text
M04 = 艦隊から離れない
M05 = プレイヤーを地上目標から引き剥がす
```

という目的差で戦い方を変える。

**機体を変えるだけでなく、編隊の任務を変えることで敵航空戦力に深みを出す。**

# 6. Su-33の扱い

Su-33は高性能艦載戦闘機として温存する。

絶対規約:

- ACT I（M01〜M05）では出さない。
- generic `trash / rookie` にしない。
- 母艦または明確な海軍航空基地の存在しない任務へ理由なく置かない。
- 初登場時は「艦載航空隊が戦場へ出てきた」と分かる任務にする。

初登場候補は中盤以降の本格的な空母・外洋戦。具体的な初登場ミッション番号は、その海上任務の正式敵編成を設計する際に確定する。
