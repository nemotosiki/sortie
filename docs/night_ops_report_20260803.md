## 6b. 味方まわりの一斉点検（ご指示の r07 プロペラ ＋ 同種バグ）

ご報告の現物は直っています。**r07 の実機A/B**で、味方偵察機 PATROL 1 の
プロペラ回転量が **3秒あたり 0.000 rad（8枚とも完全停止）→ 9.408 rad** になりました。

真因は「プロペラだけ」ではありませんでした。**味方機はモデルを組んだきり、
誰も毎フレーム更新していなかった**（プロペラ・可変翼・排気炎の脈動すべて）。
自機と敵機は各自の更新関数を持っていたのに、味方だけ経路が無かった状態です。
共通ヘルパーに切り出して3経路が同じ1本を呼ぶ形にしたので、今後どちらかだけ
直し忘れることは無くなります。

「味方関連に同じようなバグがあるかも」というご指摘どおり、同種が4件出ました:

| 症状 | 影響 |
|---|---|
| **味方艦に当たり判定が無い** | 空母(330m)と揚陸艦(165m)だけ素通りできた。m03は艦首前スタートなので一番踏みやすい |
| 味方の速度フィールドの取り違え | 僚機の速度が常に0扱い（プローブ実測 0 → 315.8） |
| 着岸した味方艦がレーダーとHUDから消える | 見えているのに映らない（退場扱いの解釈違い） |
| **僚機を狙われるたび居ない輸送隊の無線が鳴る** | 輸送隊ゼロの空戦で「LIFELINEにミサイルを撃った！」（m01実測で2回） |

加えて、進路が斜めだと輸送隊の編隊が崩れる潜在バグ（現行の護路が真南北なので
偶然表面化していない）も、隣の味方艦スポーナーと同じ書き方に揃えて塞ぎました。

**バグではないと判断して触らなかったもの**: 味方残骸が `visible=false` のまま
シーンに残る件（`clearFriendlies` が破棄するのでリークなし・敵と同挙動）と、
E-2Dのロートドームが回らない件（機体payloadに回転部品を登録する口が無いのは事実だが、
現行のE-2Dはそもそも回そうとしていない＝将来の機能要望）。

### 味方コードの追加監査（Opus 5 に精読させ、6件を実測で選別）

味方関連だけを対象にもう1周精読させ、出てきた6件を**私の側で1件ずつ実測して**採否を決めました。
「もっともらしいが実際には起きない」ものを混ぜないためです。

**直したもの（1件）**
- **着岸した揚陸艦に被弾フラッシュが焼き付いたまま残る**。白い発光の減衰は「生存中」の
  分岐にあり、退場処理はその分岐ごと飛ばします。輸送機は退場と同時に消えるので表に
  出ませんでしたが、揚陸艦は「砂の上に立っている絵」が勝利条件なので残り続ける仕様で、
  被弾から0.1秒以内に着岸すると出撃が終わるまで白いままです。
  **A/B実測: 修正前は3秒後も 0.07 のまま凍結（以後永久に減らない）→ 修正後 0**。

**実測して「起きない」と分かったもの（2件・直していません）**
- **Tu-95が機首から母艦を機銃掃射して1発ごとに減点される**という指摘。コード自体は確かに
  おかしい（対プレイヤー側は尾部銃座のために機首ベクトルを反転するのに、対味方側は反転を
  忘れている＝Tu-95の仕様コメントが明記する「0.4は反転後の後方コーン」という契約に反する）。
  ただし **m-carrier で5分間、2機のBearが空母を狙い続け、最接近2.1mまで寄っても機銃命中は0**
  でした（空母を削ったのは対艦ミサイル2発だけ）。実害としては出ていません。
- **重いフレームで味方狙いミサイルが輸送機をすり抜ける**という指摘。**算数が合いません**:
  貫通は「1フレームの歩幅 > 信管の直径」で起きますが、AAMは 455m/s × dt上限0.05 = 22.75m に対し
  信管直径は44mです。**CPUを20倍スロットル（実測4fps）した m-ESCORT でも命中は正常に4回**
  発生しました。プレイヤー側で同じ修正が必要だったのは、信管が13m（直径26m）で接近速度が
  約795m/sあり、歩幅40m > 26m と本当に跨げたからです。条件が違います。

**バグではないと判断したもの（1件）**
- 撃墜された輸送機が海面に届かず空中で消える件。敵機の残骸は2.4秒で消えるのに対し味方は
  5.5秒で、**味方の方が既に長い**。演出の共通規約どおりです。

**判断をお願いしたいもの（2件・触っていません）**
- **輸送機を1機も失っていないのにSランクが剥奪されます**。S判定は「護衛対象を失っていない」
  に加えて「総HPの75%以上が残っている」を要求しますが、後者はコメント自身が空母
  （readout:"integrity"）のための条件だと書いています。護衛隊（readout:"count"）にも
  掛かっているため、3機とも生還しても合計255ダメージ（AAM3発弱）でSが消えます。
  m-ESCORT の設計規則は「1機喪失＝S剥奪」なので、**条件を readout:"integrity" のときだけに
  絞る**のが素直ですが、S獲得条件が緩くなる変更なので判断をお願いします。
  （負荷試験中に実際に **損失0のまま integrity 0.7049** まで落ちるのを観測しました）
- **僚機の機銃が、すぐ上のコメントが宣言する強さの約2.7倍**あります。コメントは
  「機体火力の40%・約10度コーン・毎秒約5ダメージ・98HPのMiG-21に20秒近く」と書いていますが、
  定数は 75% / 約14度 / 毎秒13.5ダメージ＝**7.3秒**です。どちらが正かはバランスの話なので、
  コメントを直すか定数を戻すかをご指示ください。
