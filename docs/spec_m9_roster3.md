## 追加コンテンツ

  **海なし=全面地形**。地面は砂色の起伏メッシュ（既存の島生成を平坦寄りパラメータで流用、
  水面plane非表示 or 砂色平原に差し替え）・岩山を疎らに配置
- 熱陽炎などのシェーダ演出は**やらない**（fps優先、Sortieの画作りは形とライトで出す方針）

### 2. 敵攻撃ヘリ: AH-99風 GUNSHIP（バッチ10）
- enemy専用（enemyOnly:true）。**新カテゴリ「ホバー機」**: 固定翼の速度下限を持たない
  - 実装方針: enemies[]の通常機として持つが `hover: true` フラグで運動モデルを分岐。
    speed 0〜72で自由、高度30-150を維持、横スライド回避（evadeLateralの水平版）
  - 失速判定・ブレイクターン・ポストストールの固定翼ロジックは hover機では全てスキップ
- モデル: 胴体+テールブーム+メインローター（回転アニメ、2枚ブレードの残像板でも可）+スタブ翼
- HP **98**、兵装: 機銃（damage 6、射程700、maxHit 0.15）+ 低速ロケット弾
  （直進・damage 40・自機の未来位置へリード射撃・4秒毎）。ミサイルなし・フレア反応なし
- 挙動: 地形に貼り付く低空ホバー。**低空に誘い込む脅威**として機能（プレイヤーがUGB/機銃で
  対処する際に地面が近い）。レーダー表示は地上目標と同じ琥珀系だが**動く**
- ロックオン/ミサイル: 空中目標扱い（surface:falseのまま）。QAAMが有効=設計通り

### 3. 敵列車: ARMORED TRAIN（バッチ11）
- ground派生の**移動地上目標**: 直線+緩カーブの固定経路（ウェイポイント列をミッション定義に持つ）を
  速度18で走る。機関車(HP196)+貨車×4(各HP98)の**連結5両**、車間は経路追従で維持
- 兵装: 貨車のうち2両が対空砲（既存aaGunの弾幕を流用、maxHit 0.12）
- 撃破ルール: **機関車を落とすと全体停止**（停止後の貨車は静止目標化）。全5両撃破でユニット完了
- モデル: 直方体ベース+車輪シリンダ。線路は経路に沿った2本レール+枕木（InstancedMesh）
- 狙い: 「先頭を狙う」という攻撃順序の駆け引きを地上戦に持ち込む

### 4. 敵揚陸艦: LANDING SHIP（バッチ11と同時）
- SHIP_TYPES追加: 全長140m・HP **294**(3発)・速度12・平甲板+艦首ランプの箱型
- 兵装: 軽SAM×1（イージスVLSの弱体版: cooldown 18s・フレア囮可）+ AA×2
- **ギミック: 海岸到達でヘリ2機を発進**（gunship流用、到達前に沈めれば発進なし）。
  「時間内に沈めないと脅威が増える」時間圧力型の目標
- 到達判定: 経路終点（浅瀬座標）への距離<300で発進シーケンス（30秒間隔で2機）

## 検証方針
- hover基盤: 固定翼ロジック（失速/ブレイク/地形引き起こし）がgunshipで発動しないことをプローブ
- 列車: 経路追従で脱線（ウェイポイント間の角で車間破綻）しないこと、機関車撃破→停止遷移、
  レールInstancedMeshのfps影響
- 揚陸艦: 到達前撃沈でヘリ非発進/到達でヘリ2機発進の両分岐E2E
- DESERT: 海なしプリセットでdisposeWorld/リスタート4巡のGPUメモリ不動、既存4プリセットのリグレッション
- 恒例: 新ミッションE2E+ランク記録+解禁、m01/m03/m07リグレッション、fps≥55、エラー0
