# SPEC M9 world extent — マップ拡張(端の消失対策) (2026-07-26未明, Fable設計)

ユーザー報告(7/26未明): 「全体的にマップを広げて。すぐに画面はじにいって地面が消える」。
高速機だと数十秒で海面/地形の描画範囲外に出てしまい、世界の端(海が途切れて空だけになる)が見える。

## 方針: 「海と空は無限、戦域は有界」(AC方式)

物理的に巨大な海メッシュを張るのではなく、**海面・天球をカメラ追従**にして視覚上の端を消し、
ゲームプレイ側はACの「RETURN TO THE BATTLE AREA」方式で有界にする。

### 1. 海面のカメラ追従(視覚の無限化)

- 毎フレーム海plane(および海面装飾: スペックル/サンロード)の position.x/z をカメラのx/zにスナップ
- **UVスクロールの整合**: 海テクスチャのUVオフセットに移動量を加算して「海が付いてくる」のではなく
  「海の上を移動している」見た目を維持(plane移動量 / テクスチャワールドスケールをUVに加算)。
  サンロード(太陽反射の帯)は太陽方位基準なのでそのままでよいはず(実装時に目視確認)
- 天球・雲層・遠景山(あれば)も同様にカメラ追従(既にそうなっている可能性あり。要コード確認)
- 島・艦・地上目標はワールド固定のまま(当然)
- fog far はプリセット値のまま(追従化により「fogの向こうに海の端」が見えなくなる)

### 2. 戦域境界(BATTLE AREA)の導入

- ミッションごとに戦域半径 `battleRadius`(既定 **12000**。現状の実効エリアの2倍程度を目安に、
  実装時に現状値を実測して決める)を定義、中心はミッションの主目標重心
- 半径の90%を超えたら HUD警告「RETURN TO THE BATTLE AREA」(黄文字点滅+警告音)+
  レーダー縁の方向指示
- 半径超過が**10秒**続いたら MISSION FAILED(AC同様)。境界内に戻れば警告解除
- 既存ミッションへの影響: 全ミッションの交戦域は中心付近なので、通常プレイでは警告を見ることは
  ほぼ無い(リグレッションで確認)。敵AIは戦域を意識させない(そもそも中心に居る)

### 3. 島・地形配置の拡散(任意・第2段)

- 「マップが狭い」体感の残り半分は島の密集。プリセットの島配置半径を1.5〜2倍に広げ、
  ミッション間の移動感を出す(パータイムへの影響があるため**別バッチ**で、全ミッション実走の
  上で調整)

## 実装バッチ

- **W-A**: 海/天球カメラ追従+戦域境界+警告UI+10秒FAILED(1バッチ)
- **W-B**(任意・後続): 島配置拡散+パータイム再調整

## 検証ゲート(W-A)

1. 端の消失が消えたこと: 任意方向へ全速3分直進しても海面が途切れないスクショ(前後比較)
2. UV整合: 追従化後も海面が「流れて見えない」こと(低空低速で目視+スクショ連続比較)
3. 境界: 半径90%で警告表示→復帰で解除→10秒超過でFAILED の3分岐E2E
4. リグレッション: m01/m03/m05通常クリアで警告が一度も出ないこと、fps≥55、エラー0
5. 全4プリセット(archipelago/sunset/glacier/night)で追従の見た目確認スクショ
