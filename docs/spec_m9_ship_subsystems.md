# SPEC M9 ship subsystems — 艦の武装部位ロックオン+空母ガンナー (2026-07-26未明, Fable設計)

ユーザー要望(7/26未明、AC7スクショ添付): イージス艦など軽量艦以外は**AA砲座・VLS区画を個別に
ロックオン・破壊**できるようにする(ACと同じ)。部位を潰すとその武装が沈黙。空母には防御火器を増設。

> 注: 本仕様は分類器障害中にFableがコード読解に基づき起草した。実装エージェントは着手前に
> 参照行番号と実装値を必ず実コードで再確認すること(F-2Aバッチの編集でズレている)。

## 現状の実装(読解済み・要再確認)

- `SHIP_TYPES`(L2747): aegis hp250 / carrier hp520。**両艦とも `aaMounts`(艦内Z位置の配列)+
  `aaHeight` + `aa` スペックを既に持つ**(aegis: [-48,50] range640 / carrier: [-120,130] range560)
- イージスのVLSは `vlsSide` トグルで前後セル野から交互コールドローンチ(L6571-6580)
- 艦・地上目標は enemies[] 同居方式(L2798コメント): surface:true でロック/機銃レイキャスト/
  ミサイル誘導/レーダー/キルフローが全て共通
- `cycleTarget()`(L4885)が既存 = ACの「NEXT」切替UXは既にある。`preferredCandidate`(L6809-6847)で
  ロック維持優先も実装済み

## 設計

### 1. データ構造: SHIP_TYPESに `subsystems` 配列(後方互換)

```js
subsystems: [
  { key: "aa-fore",  kind: "aa",  offset: {x: 0, y: 13, z: -48}, hp: 49, label: "AA GUN" },
  { key: "aa-aft",   kind: "aa",  offset: {x: 0, y: 13, z: 50},  hp: 49, label: "AA GUN" },
  { key: "vls-fore", kind: "vls", offset: {x: 0, y: 10, z: 38},  hp: 98, label: "VLS" },
  { key: "vls-aft",  kind: "vls", offset: {x: 0, y: 10, z: -32}, hp: 98, label: "VLS" },
]
```

- `subsystems` 未定義の艦は現行挙動のまま(後方互換。ミサイル艇=軽量艦は付けない)
- **部位HPの量子**: AA砲座=**49**(ミサイル1発で確殺+機銃で現実的に壊せる。地上のaaGunと同格)、
  VLS=**98**(ミサイル1発ちょうど)。「軽い部位は機銃掃射でも潰せる」がAC的な攻め筋になる
- offsetは既存の `aaMounts`/`vlsSide` 定数から機械的に導出できる(aaMounts z値+aaHeight、
  VLSは±38/-32のセル野)。導出したら `aaMounts` 側は subsystems からの参照に一本化してよい

### 2. エンティティ方式: enemies[] 同居の子エントリ(推奨)

- スポーン時に親艦の `enemy.subsystemIds = [...]` として enemies[] に部位エントリを追加:
  `{ surface: true, subsystem: true, parentId: <艦id>, offset, hp, ... }`
- 毎フレーム親の position+quaternion で offset を変換して追従(艦は最大3隻×部位4=12エンティティ増。
  updateEnemies の surface 分岐で早期 return する軽量パスにする。fps影響は実測ゲート)
- **親が沈没**: 部位は即座に enemies[] から除去(残存部位の爆発演出は沈没爆発に内包)
- **部位が全滅しても艦体は沈まない**(逆に艦体を直接沈めれば部位ごと沈む=速攻ルートも残る)

### 3. 武装沈黙の因果

- AA射撃ループ(L7873/L8008)を「生存している kind:"aa" 部位があるときだけ」に変更。
  tracers本数は生存AA部位数に比例(2部位→2、1部位→1、0→沈黙)
- VLS発射(L6571)は「生存している kind:"vls" 部位」からのみ。vlsSideトグルは生存部位で巡回。
  全滅でSAM完全沈黙(フレアの節約が効くようになる=2発制限と噛み合う)

### 4. ロックオンUX

- 部位は通常のロック候補(enemies[]同居なので自動)。`cycleTarget()` で艦体⇔部位を巡回=AC同等
- ロック優先度に手を入れない(最近接優先のまま)。ただし**ミサイル誘導の当たり判定**は部位の
  hitRadius を小さく(12-16)して、艦体狙いの弾が部位に吸われないようにする
- HUD: 部位のターゲット枠は艦体と同形・小さめ。ラベルは `AA GUN` / `VLS`。
  レーダーには**出さない**(艦体のみ。12個の点でレーダーが汚れるのを防ぐ)
- TGT制度(spec_m9_tgt_system.md)との関係: **部位は常に非TGT**(撃破カウント外・スコアのみ)

### 5. 空母ガンナー増設

- carrier に subsystems: AA×3(既存2マウント+艦橋前1)+**CIWS×1**(新kind:
  `{ kind: "ciws", hp: 49, label: "CIWS" }`)
- CIWS挙動: range 800・**対ミサイル迎撃**(接近中の自機ミサイルを毎秒 p=0.25 で撃墜、
  tracers 6の派手な曳光)+対機銃撃(damage 7, maxHit 0.12)。「CIWSを先に潰さないと
  ミサイルが通りにくい」= 部位攻撃の動機づけの核
- 迎撃判定は自機ミサイルの updateMissiles 内で CIWS 生存チェック1回(軽量)

### 6. スコア配分

- 部位撃破 = +150点(艦体撃破は既存値のまま)。ランクS閾値への影響は「部位を全部拾うと
  Sが緩くなりすぎないか」を実測し、必要なら S閾値ではなく部位点を調整(既存ミッションの
  スコア互換を壊さない方向で)

## 実装バッチ分割

- **S1**: subsystems基盤+イージス部位化(AA2+VLS2)+武装沈黙+m03で検証
- **S2**: 空母ガンナー(AA3+CIWS)+CIWS迎撃+m03/m05検証
- (m03へのCAP追加はTGT仕様のバッチと同時に行う)

## 検証ゲート(各バッチ)

1. 部位ロック巡回: cycleTargetで艦体→AA→VLS→…→隣の艦と巡回すること(プローブ)
2. 因果実測: AA部位2撃破→tracers 0本/30s、VLS2撃破→SAM発射0/60s、艦体撃沈→部位消滅
3. 部位HP実測: AA=機銃で撃破可能(49)、VLS=ミサイル1発ちょうど
4. ミサイル吸われ検査: 艦体ロック時の命中部位が艦体であること(hitRadius縮小の効果)
5. CIWS: 生存時のミサイル撃墜率~25%/秒接近帯の実測、撃破後は0
6. 既存リグレッション: m01/m03/m05、subsystems未定義艦(ミサイル艇等将来分)の素通り、
   fps≥55(部位12エンティティ追加時)、エラー0
