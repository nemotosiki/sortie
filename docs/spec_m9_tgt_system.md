# SPEC M9 TGT system — 指定ターゲット制度+非TGT敵の増員 (2026-07-26未明, Fable設計)

ユーザー要望(7/26未明): ACと同じく**ミッション内に指定ターゲット(TGT)**を導入する。
全敵撃破は不要、TGT全滅でACCOMPLISHED。TGT外の敵をもっと増やして戦場を賑やかにする。
あわせて「m03艦隊戦に戦闘機がいないのは不自然」を解消(CAP護衛機=非TGTで追加)。

> 注: 分類器障害中にFableが起草。実装前に参照個所を実コードで再確認すること。

## 設計

### 1. ミッション定義: ウェーブ/ユニット単位の `tgt` フラグ

- 正規化済みウェーブ記述子(1a5aebeで導入した `{types:[...]}` 形式)に `tgt: false` を追加可能に。
  **既定は tgt: true**(既存ミッションの挙動不変=後方互換)
- groundUnits にも同様に per-unit `tgt: false` を許可
- 例: `sequence: ["naval", { types: ["f15","f15"], tgt: false, label: "CAP" }]`
  → 艦隊がTGT、CAPは倒しても倒さなくてもよい

### 2. 達成判定・カウント表示

- `totalTargets` = tgtユニットのみ集計(HUDの「TGT REMAIN」表示・ブリーフィングマーカーも同じ)
- ACCOMPLISHED = tgt全滅。**非TGTが残っていても達成**(ACと同じ)
- ACCOMPLISHED後の非TGT: 交戦継続のまま勝利バナー→リザルトへ(既存のoutcomePending凍結が
  そのまま使える。追撃されて墜落した場合は既存仕様どおり記録なし=リスクも残る)
- **HUDターゲット枠(7/26ユーザー指示・AC本家準拠、AC04/5スクショ添付)**:
  **枠の左=赤色「TGT」**(TGT対象のみ。スクショの「TGT JA8-38C」式)、
  **枠の右=機種名**(全敵。例「F-4」「BOMBER」「AEGIS」。短縮名でよい)、
  **ネームド機(エース等)は機種名に個体名を付ける**(例「F-22 IRONBACK」)。
  非TGTはTGT表示なしで機種名のみ(枠は従来色のまま)。
  実装メモ: 敵エンティティに表示用shortName(機種)+name(個体名、エースのみ)を持たせる。
  既存のAIRCRAFT_TYPES/SHIP_TYPES/GROUND_TYPESのlabel/keyから導出

**★レイアウト厳密指定(7/26、初版実装がNGだったため。AC04スクショ準拠)**:
```
                 ┌──────┐
      TGT        │  □  │   JA8-38C     ← 「TGT」=枠の左横(赤・小)。機種名=枠の右横(小・1行)
                 └──────┘   188         ← 距離は機種名の下(数字のみ or 「188M」)
```
- 「TGT」と機種名は**別要素・別位置**。連結(「TGTBOMBER」)は不可
- 機種名は**枠の外・右横に1行**。折り返し禁止(「TGTF-」「4」のような分断は不可)
- フォントはHUD既存の等幅・**小さめ**(枠の高さ程度)。**グロー/影/黒背景チップ禁止**
- 距離表示は**1箇所だけ**(機種名の下)。既存の「2 · 1797M」等と二重表示にしない(既存表示は置換)
- 「TGT」は**TGT対象のみ**。非TGT(護衛F-4等)には絶対に出さない(初版はここもバグ)
- 検収は本家スクショとの並置比較で行う
- **レーダー(7/26ユーザー指示)**: **TGTの敵は〇(円)で囲む**。現在「選択中の敵」に付いている〇は
  廃止し、**選択中の敵は点滅**で示す(TGTかつ選択中なら「〇+点滅」の重なりで両方読める)

### 3. スコア/ランク

- 非TGT撃破 = 通常スコアの**半分**(乱獲でSが自動になるのを防ぐ)。ボーナス扱いでKILLS内訳に
  「BONUS KILLS」行を追加
- ランク閾値は既存のまま。**検証で「TGTのみ速攻クリア」と「全部拾い」の両方でランク帯が
  意図(速攻=時間有利/全拾い=スコア有利で拮抗)どおりか実測**し、破綻したら非TGT係数を調整

### ★難度曲線の全体方針(7/26ユーザー指示)
- **序盤(m01-m02)**: 敵は最弱のF-4主体+爆撃機。m01はAC伝統の「初任務=爆撃機迎撃」に再設計
- **中盤**: 現行どおり(f16/f15級)
- **後半(m05以降+今後の高番号ミッション)**: **敵エース(isAce ×1.2)を複数配置**するのを標準とする。
  ウェーブ記述子の ace フラグで指定(1a5aebeの自由編成で per-wave ace 指定が可能)。
  新規ミッションを設計するときは番号が進むほど ace 率を上げること

- 追加は全て既存機体タイプの流用(新モデル不要)。1ミッションあたり+1〜2機でfps安全圏
- ブリーフィング本文に非TGTの言及を1文ずつ追加(「敵CAPとの交戦は任意」等)
