# SPEC M9 SP.W discipline — 特殊兵装の発射規律+UGBロック疑義 (2026-07-26未明, Fable設計)

ユーザー指摘(7/26未明) 2件:

2. 「特殊兵装が乱射できるのもおかしい。ACと同様に通常と特殊をしっかり分けて。例えば4AAM(現8AAM)は

## 1. UGBのロック疑義(まず実測)

- コード上は `ugb` に「no lock at all - the CCIP marker is the sight」のコメントあり(L2125付近)。
  **実挙動を必ずプローブ**: UGB選択中に (a)ロック進行/ロック音が走るか (b)ターゲット枠が
  ロック状態表示になるか (c)発射がロック対象に紐づくか
- **あるべき姿(AC準拠)**: UGB選択中はロックオン一切なし。照準はCCIPマーカーのみ。
  ターゲット枠は情報表示として出てよい(距離確認用)が、ロック進行・ロック音・LOCKEDは出さない
- ロック挙動が残っていたら根治(updateLockをkind:"bomb"で完全スキップ等)。
  残っていなければ「ユーザーが見たもの」の正体を特定して報告(例: 選択枠がロックに見える等、
  見た目の紛らわしさなら表示側で解消案を提示)

## 2. SP.W発射規律(通常/特殊の分離)

現状(推定・要実測): SP.Wはトリガー連打で在庫が尽きるまで連射可能。
通常MSLは「2発装填+時限リロード」が実装済み(P3.5期)。**SP.Wにも同じ規律を入れる**。

### 装填モデル(SPW_TYPESにフィールド追加)

| SP.W | 装填数(tubes) | リロード | 備考 |
|------|--------------|---------|------|
| QAAM | 2 | 6s | MSLと同じ2発運用 |
| XLAA | 2 | 8s | 長射程は回転率で律速 |
| UGB  | 2 | 5s | 2連投下は許す(AC的) |
| LASM | 1 | 9s | 対艦の重い1発 |
| 8AAM | **1サルボ(8発消費)** | 12s | サルボ後リロード。4AAM/6AAM(将来)も同型で1サルボ制 |

- 数値は初期値。検証時の実プレイ感で±30%調整可(調整したら報告に根拠を書く)
- **リロード進行はHUD弾数パネルに表示**(MSLの既存リロード表示と同じ様式でSP.W行に)
- リロード中はトリガー無効(発射音なし・空撃ちクリック音のみ小さく)
- 補給(W3等)はリロード状態もリセット(即装填)

### 実装注意

- MSL側の既存実装(2発装填+時限リロード)を**流用**し、系を二重に作らない
- multiLock系(8AAM)はサルボ発射完了の瞬間からリロード開始。ロック維持はリロード中も可
  (ロックはできるが撃てない=ACと同じ)
- 敵AI・既存ミッションバランスへの影響: 8AAM連打前提だったm-swarm系(将来)は設計時に考慮済みの
  前提なので現時点の調整不要

## 検証ゲート

1. UGBプローブ結果(ロック進行/音/LOCKED表示の有無、修正前後)
2. 各SP.Wの連射プローブ: トリガー連打で装填数を超えないこと・リロード時間実測(表と一致)
3. 8AAM: サルボ→12sリロード→再サルボのサイクル実測、リロード中ロック維持可
4. HUDリロード表示のスクショ(MSL様式との整合)
5. 補給でリロード即完了
6. リグレッション: m01/m03/m05クリア可能(リロード制でも破綻しない)、fps≥55、エラー0
