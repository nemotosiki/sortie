# 修正残件の締め（2026-08-03）

対象はクラッシュ、進行、保存、HUD/無線/入力の不具合だけとし、地図作成・3D制作・飛行/武器バランスは含めない。

## 今回修正したもの

- 地上施設の残骸は出撃終了まで残すまま、発煙・火花・二次爆発音を破壊後18秒かつ自機から1.8km以内に限定した。破壊数に応じてパーティクル/音声プールを永久に消費しない。
- EASY の地面・地形・艦船・友軍艦への衝突が難易度軽減で生存する経路をなくし、衝突は必ず即時撃墜にした。
- チェックポイント復帰で、最初のウェーブ用無線が混ざることと、復帰直後に残存攻撃で即撃墜されることを防いだ。
- 僚機のバンク計算で `dt=0` 時に非有限値を作らないようにした。出撃開始時には狩猟型僚機の周期カウンタもリセットする。
- クリア/失敗の余韻中はRWR、ミサイル警報、ロック音を止める。キルカム中にもウェーブ/アウトロ進行を壁時計と揃え、古い大バナー/勝利スティングをメニューへ持ち越さない。
- エピローグ表示中の Retry/ゲームパッド決定は、再出撃でなくまず文章を最後まで表示する。ゲームパッドでもブリーフィングの難易度を変更できる。
- ミッション記録が配列・数値・文字列などに壊れていても空の記録として復旧する。記録削除後は機体所持、財布、選択ミッション、一覧を即座に再同期する。
- キャンペーンを跨いで未確定の購入確認を持ち越さない。デバッグ公開値の難易度設定も、無効な保存値では実際の挙動どおり NORMAL を示す。
- 地上物サブシステムのロック用ダイヤを内側に縮め、狭いターゲット枠へ接触しないようにした。ストーリー無線の CRITICAL 優先度も正本の値に一致させた。

## 意図して残した判断

- F-2A/Su-47/Su-25 の失速、STABILITY、僚機火力、護衛Sランク条件、機銃の対艦判定は飛行感・難度を変えるため保留。
- レーダー圏外表示、地表接近警報、クリア後の NEXT MISSION 導線は新しいUX仕様なので保留。
- デブリーフのランク用 TOTAL と難易度倍率後の記録/経済スコアの関係は、難易度ごとの報酬設計を決めてから一体で扱う。片側だけを変えると既存の機体価格調整を壊す。
- マップ、3Dアセット、ストーリー文面には手を入れていない。
