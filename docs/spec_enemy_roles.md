# SPEC 敵の強さモデル — 機体性能 × 役割倍率 × AIの賢さ (2026-07-26, Fable設計)

ユーザー指示: **「敵の性能は機体性能にも依存して、敵エース・雑魚などはその倍率で変える感じ。
あと、AIの賢さ」**

## 0. 三層モデル

敵1機の強さは、独立した3つの層の積で決まる。

```
実際の強さ ＝ ①機体性能（AIRCRAFT_TYPES の素の表）
            × ②役割倍率（ace / elite / line / trash）
            ＋ ③AIの賢さ（skill tier: 判断の質。数値ではなく振る舞い）
```

- **①機体性能** は自機と共有の資産。**書き換えない**。Su-57は誰が乗っても速い
- **②役割倍率** は「その機体を、どれだけ引き出して飛ばすか」。既存の `ACE_TURN_SCALE 1.2` を
  一般化したもの。**雑魚は1.0未満**（＝素の性能を出し切れない）
- **③AIの賢さ** は倍率ではなく**判断の質**。同じ機体・同じ倍率でも、賢い方が強い

これにより「MiG-21のエース」と「Su-57の雑魚」が両方作れる（＝AC的に面白い）。

## 1. 役割倍率（ENEMY_ROLES）

| 役割 | turnScale | speedScale | missileCooldown | gunAccuracy | 用途 |
|---|---|---|---|---|---|
| **ace** | **1.20** | 1.00 | ×0.85（よく撃つ） | 高 | ネームド（IRONBACK/LONGBOW/VULTURE） |
| **elite** | **1.05** | 1.00 | ×1.00 | やや高 | エース僚機、精鋭飛行隊 |
| **line** | **1.00** | 1.00 | ×1.00 | 標準 | 標準的な敵（既定値） |
| **trash** | **0.75** | 0.95 | **×1.8〜2.2（滅多に撃たない）** | 低 | 邪魔役の雑魚 |

- 倍率がかかるのは **旋回まわり（turnRate / pitch / roll / yaw）と加速レスポンス**。
  **HPには倍率をかけない**（HPは98量子の設計を維持。撃墜に必要な弾数は機体で決まる）
- `trash` は「1発で落ちる弱さ」ではなく「**素の機体性能を出し切れない下手なパイロット**」として表現する
- ウェーブ記述子で指定できるようにする: `{ types: ["mig29","mig29"], role: "trash" }`。
  未指定は `line`。`ace: "ironback"` を指定した機体は自動的に `ace` 役割

## 2. AIの賢さ（SKILL_TIERS）

倍率とは別軸。**同じ機体・同じ倍率でも賢さで強さが変わる**。

| 項目 | rookie（雑魚向け） | regular（標準） | veteran（精鋭） | expert（エース） |
|---|---|---|---|---|
| **偏差射撃（リード）** | ほぼ現在位置を狙う（当たらない） | 粗いリード | 正確なリード | 正確＋自機の旋回を読む |
| **ミサイル発射判断** | 射程外・悪角度でも撃つ／滅多に撃たない | 射程内なら撃つ | 有効包絡線でのみ撃つ | 有効包絡線＋こちらのフレア切れを狙う |
| **ミサイル回避（ブレイク）** | **しない** | たまに（遅い） | 確実に（適時） | 早期＋フレア/機動の使い分け |
| **エネルギー管理** | 水平旋回だけ、速度を失う | ときどき縦を使う | 縦横を使い分ける | 常に優位高度・速度を取りに来る |
| **編隊行動** | 団子になる | 緩く散開 | 挟撃を試みる | 役割分担（1機が釘付け、1機が刺す） |
| **深追い/離脱** | 深追いして墜ちる | 状況で離脱 | 不利なら早期離脱 | 有利になるまで距離を取る |

- 既定の対応: `trash → rookie` / `line → regular` / `elite → veteran` / `ace → expert`。
  ただし**独立して指定可能**にする（例: 「MiG-21だが腕は一流」＝ trash機体 + veteran skill）
- 実装は既存の `ENEMY_AI_PROFILES` の挙動パラメータ（evade系・engageRange・break有無）と、
  射撃判定の `aimThreshold` / リード計算の精度、ミサイル発射条件の厳しさで表現する

## 3. 実装方針

- `ENEMY_ROLES` と `SKILL_TIERS` を**データテーブル**として追加（機体表とは分離）
- `spawnEnemy` で `role` と `skill` を解決し、**その場で派生値を計算**する
  （機体表を書き換えない。派生値＝旋回上限やミサイルクールダウンの実効値）
- 既存の `ACE_TURN_SCALE 1.2` は `ENEMY_ROLES.ace.turnScale` に統合し、挙動は不変にする
- HUDには役割を出さない（プレイヤーには「なんか弱い/やたら強い」として伝わればよい）

## 4. 検証（最小限）

1. 同一機種（例: MiG-29A）で `role: trash` と `role: line` を並べ、**旋回追従とミサイル発射回数の差**を実測
2. `ace` の実効旋回が従来と同じ（×1.2）ことを確認＝既存バランスの互換
3. HPに倍率がかかっていないこと（撃墜に要するミサイル数が機体表どおり）
4. rookie がブレイクターンをしない／expert がすることのプローブ
5. fps・エラー0
