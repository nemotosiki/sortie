# SPEC キャンペーン分割・味方部隊・ストーリー (2026-07-26, Fable設計)

ユーザー指示:
- **ミッション編成をアメリカ陣営編とロシア陣営編に分ける**。今はアメリカ陣営編
- **味方の戦闘機・味方の空母などをステージによって出す**
- **簡単なストーリーを考える**

## 0. 全体構造

```
起動 → CAMPAIGN SELECT → STAGE SELECT → AIRCRAFT SELECT → BRIEFING → 出撃
        ├ AMERICAN CAMPAIGN  「OPERATION CLEAR SKY」 ← 現行10ミッション
        └ RUSSIAN CAMPAIGN   「OPERATION NORTHERN STAR」 ← 将来（枠だけ用意）
```

- `MISSIONS[]` の各エントリに `campaign: "usa" | "rus"` を追加。**既定は "usa"**（既存10本は全てusa）
- ステージセレクトの手前に**キャンペーン選択画面**を挿入（左右キー/スティックで切替、AC5のCAMPAIGN選択風）。
  ロシア陣営編は当面 **"COMING SOON"** でロック表示にしてよい（枠と導線だけ実装）
- レコード（localStorage `sortieMissionRecords`）は**ミッションキー基準のまま**＝後方互換。解禁連鎖もキャンペーン内で閉じる
- 機体選択はキャンペーンで絞る:
  - usa編 = 西側機のみ（f16/gripen/f2a/fa18/f15/f14/rafale/typhoon/f35c/f4/a10/f22）
  - rus編 = ロシア機のみ（mig31/su37 + 将来のプレイアブル化分）
  - **実装は `campaignAircraft` のような絞り込み1本**で。ハンガー本体はいじらない

## 1. ストーリー（アメリカ陣営編「OPERATION CLEAR SKY」）

> 架空の紛争として書く。実在国家の現実の戦争を描写しない（AC同様、装備は実機・戦争は架空）。

**背景**: 太平洋の群島国家連合に対し、北方の大国が突如として航空侵攻を開始した。
連合の要請を受け、西側同盟軍が展開。プレイヤーは空母打撃群に配属された混成飛行隊
**「SORTIE隊」** のパイロット、コールサイン **HAMMER 1**。
（敵はこの機を「HANGMAN」と呼ぶ。§3のオチ参照）

**主要な味方**:
| 名前 | 役割 |
|---|---|
| **SKYEYE**（AWACS） | 全ミッションの管制音声。既存の `command` 話者をこの名前に |
| **HAMMER 2**（僚機） | 既存の `wingman` 話者。軽口を叩くベテラン |
| **CV-71 INDEPENDENCE**（空母） | 母艦。海上ミッションで**実体として登場** |
| **BASE ALPHA**（前線飛行場） | m01で守る友軍飛行場（実装済み）。以後も拠点として言及 |

**敵**: 北方連邦軍。エースパイロット **IRONBACK**（Su-57）が全編を通じた宿敵。

**話の流れ（既存10ミッションに沿う）**:

| # | ミッション | 物語上の位置づけ |
|---|---|---|
| 01 | FIRST CONTACT | 開戦。Tu-95爆撃編隊がBASE ALPHAへ。初陣で基地を守る |
| 02 | TWO-PRONGED | 敵は二正面から航空戦力を投入。補給の来ない連続迎撃 |
| 03 | FLEET DESTRUCTION | 反攻の第一手。INDEPENDENCEから発艦し敵機動部隊を叩く |
| 04 | GLACIER RUN | 北方の氷河回廊。敵のレーダー網を潰して侵攻路を開く |
| 05 | NIGHT RAID | 敵前線基地を夜襲。IRONBACKの部隊が駐留していた形跡 |
| 06 | IRON COLUMN | 敵機甲部隊が上陸。海岸平野で車列を阻止 |
| 07 | UAV SWARM | 敵が投入した新型無人機。数で押す新しい戦術 |
| 08 | BOMBER STREAM | 大規模爆撃編隊。連合の中枢を狙う一撃を止める |
| 09 | IRONBACK | 宿敵との決着。1対1に近い決闘 |
| 10 | FINAL SORTIE | 総力戦。敵の残存戦力を一掃し、撤退させる |

- **各ミッションのブリーフィング冒頭に1〜2行の物語文**を足す（既存本文は活かす）
- **リザルト後に短い後日談テキスト**（3行程度）を出すと連続感が出る（任意・軽量実装で）
- 既存の無線セリフは活かしつつ、話者名を SKYEYE / HAMMER 2 に統一

## 2. 味方部隊の実装（friendlies[]）

技術方針は `docs/spec_m9_roster4.md §7` の結論に従う:
**`enemies[]` に混ぜてはいけない**（`updateMission` が `enemies.some(alive)` でウェーブ進行を判定しているため、
生存し続ける友軍がミッションを止めてしまう）。**独立した `friendlies[]` 配列**を作る。

- 友軍エンティティ: `{ type, position, quaternion, hp?, alive }`
- **ロック不可**（`updateLock` の候補に入れない）、**自機の機銃/ミサイルの当たり判定に含めない**
- **レーダーは青系**でシンボル表示。HUDマーカーも青（TGT/敵とは明確に色分け）
- 敵AIは友軍を**攻撃しない**（狙いは自機のみ）。※将来の護衛任務で「敵が友軍を狙う」を足す余地は残す

### 実装する友軍3種

1. **僚機 HAMMER 2**（味方戦闘機）
   - プレイヤーの後方斜め（オフセット約 -60m 後方 / +40m 横）を**緩く追従**するだけの簡易AI
   - 機種はプレイヤーの選択機に合わせるか、固定でF-16。撃墜されない（無敵）＝演出専用
   - 空戦中はときどき無線を返す（既存の `wingman` セリフ機構を流用）
2. **味方空母 CV-71 INDEPENDENCE**
   - 既存の `carrier` モデルを**青灰塗装＋甲板ライン**で友軍仕様に。低速で航行
   - **海上ミッション（m03, m-convoy, m05）に配置**。ミッション開始時、自機は空母の近くからスタートすると発艦感が出る
   - ロック不可・撃墜不可
3. **友軍飛行場 BASE ALPHA**（実装済みのプロップを流用）
   - m01 で守る対象。m-night / m05 でも遠景に配置してよい

## 3. ロシア陣営編（枠のみ・将来）★オチの設計

- タイトル **「OPERATION NORTHERN STAR」**。**同じ戦争・同じ時間軸を反対側から描く**
- プレイヤー機 = MiG-31B / Su-37（既にハンガーにある）＋将来のプレイアブル化分
- 敵 = F-16 / F-15 / F-22 等の西側機 → **並行実装中の「西側機を敵として使う基盤」がここで効く**
- 今回は**キャンペーン選択にロック状態で表示するところまで**でよい

### ★オチ: 「敵エースは自分」（ユーザー指示 2026-07-26）

**各キャンペーンで戦う宿敵エースは、もう一方のキャンペーンの主人公である。**

| | アメリカ陣営編 | ロシア陣営編 |
|---|---|---|
| プレイヤー | **HAMMER 1**（西側同盟軍） | **IRONBACK**（北方連邦軍） |
| 宿敵エース | **IRONBACK**（Su-57） | **HANGMAN**（＝HAMMER 1の敵側での通称。F-22等） |
| 決着ミッション | 09 IRONBACK | 09 HANGMAN |

- 敵は相手を**コールサインではなく「通称」で呼ぶ**: 北方連邦はHAMMER 1を「HANGMAN（絞首人）」と呼び、
  西側はロシア側エースを「IRONBACK」と呼ぶ。**どちらも相手が付けた名前**であることを台詞で示唆する
- **時間軸は共通**。同じ戦闘を裏表で描くので、片方の勝敗はもう片方の描写と矛盾しないよう
  「決着ミッションは相打ち/取り逃がし」の含みを持たせる（どちらの編でも「奴は墜ちなかった」と語られる）
- 演出上のフック（軽量実装でよい）:
  - 両編の09で**同じ空域・同じ時刻・同じ天候**を使う（マップとプリセットを共通に）
  - 相手の無線セリフを**対になる文言**にする（例: 米編「そんな旋回で私を捉えたつもりか！」↔
    露編で同じ台詞をプレイヤー側が言われる側/言う側で反転）
  - 最終ミッション後の後日談で、**相手が生還したこと**を匂わせて次の編へ繋ぐ

### 同一時間軸のミッション対応（露編を作るときの設計表）

| # | アメリカ陣営編 | ロシア陣営編（裏側） |
|---|---|---|
| 01 | Tu-95爆撃編隊を迎撃、基地を守る | その爆撃編隊を護衛して基地を叩く |
| 02 | 二正面の航空攻撃を凌ぐ | その二正面攻撃を仕掛ける側 |
| 03 | 敵機動部隊を撃滅 | その艦隊を守る防空戦（守り切れず撤退） |
| 04 | 氷河回廊のレーダー網を潰す | そのレーダー網の防空 |
| 05 | 敵前線基地を夜襲 | 夜襲を受けた基地から緊急発進 |
| 06 | 上陸した機甲部隊を阻止 | その上陸部隊の上空援護 |
| 07 | 無人機の群れを迎撃 | 無人機部隊を指揮・随伴 |
| 08 | 大規模爆撃編隊を迎撃 | その爆撃編隊の護衛 |
| 09 | **IRONBACKとの決着** | **HANGMANとの決着**（同じ空戦の裏側） |
| 10 | 総力戦・敵を撤退させる | 撤退戦・殿を務める |

## 4. 実装バッチ分割

- **C1**: キャンペーン基盤（`campaign` フィールド／キャンペーン選択画面／機体絞り込み／rus編ロック表示）
- **C2**: `friendlies[]` 基盤 ＋ 僚機HAMMER 2 ＋ 味方空母 ＋ ステージ別配置
- **C3**: ストーリーテキスト（ブリーフィング冒頭の物語文・話者名統一・後日談テキスト）
- ※陣営置換（敵の西側機→ロシア機）は `docs/spec_faction_swap.md` の別バッチ

## 5. 検証（最小限で可）

1. キャンペーン選択→ステージ→機体→出撃の導線が通る。ロシア編がロック表示
2. 機体絞り込み: usa編で西側機のみ、ハンガー本体は不変
3. 友軍がロックできない・撃てない・レーダーが青、m03で空母が見える状態でスタート
4. 僚機が追従して墜ちない、ミッション進行を止めない（`enemies.some(alive)` に影響しない）
5. 既存レコード互換、全ミッション起動可能、fps≥55、エラー0
