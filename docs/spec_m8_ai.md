# SPEC M8 — 敵AI深化（ミサイル回避ブレイク / IRONBACKポストストール） (2026-07-25, Fable設計)

M7組込後に着手。どちらも「機体性能表の範囲内で賢くなる」方向で、性能チートは入れない（ユーザー原則:
機体性能がベース。唯一の例外は既存のエース×1.2）。

## 1. 敵のミサイル回避ブレイクターン

- 検知: 自分を `targetId` にした自機ミサイルが**距離800未満かつ接近中**（前フレームより距離減）のとき
- 発動: `enemy.mode = "break"`（1.6秒）。既存modeマシンに追加。クールダウン**4秒/機**（連続ブレイク不可）
- 機動: 照準点 = 現在位置 + (ミサイル→自機ベクトルに垂直な水平方向) × 300 + 上下ジンク
  （sin(time×7+seed)×90）。旋回レートは既存 `pursuitTurn` のまま（**性能表内**。エースは既存×1.2が自然に効く）
- 期待効果: ミサイル旋回上限(190°/s相当)に急な照準修正を強いて近接信管(16)を外させる。
  物理は正直なままなので、回避成功は「たまに」でよい（M6のQAAM 300°/sがブレイク破りの回答になる設計）
- 無線: ブレイク発動時、たまに（機体毎クールダウン25s+確率0.5） enemy「ミサイル！ ブレイク、ブレイク！」
  (id `break-<enemyId>`)
- break終了後は従来のmode判定に復帰。地形回避が常に優先（既存の引き起こしロジックがbreak照準点を上書きできること）

## 2. IRONBACK ポストストール機動（低HP時の切り札）

- 条件: エースのみ、hp < maxHp×0.4、自機がエースの後方400m以内（エース前方ベクトルと
  エース→自機ベクトルの dot < -0.5）、クールダウン12秒
- 演出: スクリプト機動（1回1.4秒、3フェーズ）
  1. **急減速+機首跳ね上げ**(0.5s): targetSpeed=90、ピッチレート160°/s相当で機首を後方上へ振る
     （この間だけ回転上限を特例で超える=**スクリプト演出であり通常AIの性能は不変**とコメント明記）
  2. **背面反転**(0.4s): ロール180°
  3. **機首を自機へ指向**(0.5s): 自機方向へ rotateTowards（pursuitTurn×2.0）、targetSpeed復帰
- 結果: 追尾していた自機と正対（ヘッドオン）になり、既存の射撃判定で反撃が飛んでくる
- 無線: 初回発動時のみ enemy「そんな旋回で私を捉えたつもりか！」(id "ace-poststall")
- 失速表現: フェーズ1中は既存の煙パーティクルを翼端から少量（コブラの視覚的な迫力）
- 発動中は被弾判定そのまま（読み切れば撃墜チャンス=リスクとリターン）

## 検証

- ブレイク: 自機ミサイル発射→敵のmode遷移 "pursuit"→"break"→復帰をプローブ、クールダウン4s実測、
  回避成功率をON/OFF比較（debug.setBreakEnabled(false)を検証用に追加、20発ずつで命中率差>10%が出ること）
- ブレイク中も地形フロア(120)を割らない
- ポストストール: エースhp<40%+後方占位で発動、1.4s後に相対方位が反転（エース前方ベクトルと
  エース→自機のdotが -0.5未満→+0.5以上へ）、クールダウン12s、無線1回のみ
- 通常機で発動しないこと / m05アウトロ・キルカムのリグレッション / fps / エラー0
