# ChatGPTへの依頼: 新しく追加された3マップのテクスチャ品質を既存4マップと同水準に (2026-07-26)

## 背景

前回の依頼（`docs/request_chatgpt_map_texture_upgrade.md`）で作ってもらった手続きテクスチャ一式と、
その後の「海の織り目（コーデュロイ）修正」は**取り込み済み**です。ありがとうございます。
実機で before/after を比較して、海面が織物模様から自然な波に変わったことを確認しました。

取り込み経路について1点共有です。あなたが組んだ GitHub Actions の視覚回帰ゲート
（run 30190454095）は patch/visual ともに success でしたが、`PUBLISH_APPROVED: 'false'` の
ままだったのでブランチには何も出ませんでした。こちらでアーティファクトから `index.after.html` と
`apply_patch.py` を回収し、パッチを現在の main に再適用して取り込んでいます（コミット `4219c87`）。
**次回は公開スイッチをONにするか、これまで通りアーティファクト経由でも構いません**（どちらでも回収できます）。

### 具体的に見てほしい点

1. **共有ジェネレータの恩恵が新マップにも効いているか**
   ミップマップ・異方性フィルタ・多オクターブのノーマル・距離減衰は
   `makeTerrainTextureSet` / `makeOceanNormalTexture` / `makeSkyTexture` / `makeCloudTexture` 側に
   入れてもらいましたが、新しい3プリセットがそれらを正しく通っているか（パラメータが極端で
   効果が潰れていないか）を確認してください
2. **各マップ固有の質感**
   - `stormOcean`: 荒天の海。うねりの相関長を大きく、白波（クレスト）のコントラストを上げたい。
     ただし霧が濃い（near 420 / far 2150）ので、遠景に凝っても見えません。**足元の海面の
     ディテールに寄せてください**
   - `desertBasin`: 砂丘のうねりと砂の粒。**風紋（リップルマーク）**が入ると一気に砂漠になります
   - `nightCity`: 夜の地面と、街区の光。窓明かりの粒がのっぺり見えないか
3. **雲と空**は既存4マップと同じ扱いで（薄雲の密度・明度は前回下げてもらった方針を踏襲）

## ★踏んではいけない罠（実装済みの意図的な作り。壊さないでください）

- **`desertBasin` の "ocean" は水ではありません。** 内陸マップなので、地平線まで届く唯一の
  ジオメトリである海面プレーンを**砂の地面として使っています**（`metalness: 0` / `roughness: 0.98` /
  `normalScale` ほぼゼロ / `normalSpeed` が他マップの1桁下 / `bright`と`dark`が2種類の砂色）。
  ここを「海として正しく」直すとマップが壊れます。**風紋を足すのは歓迎ですが、水の質感は戻さないでください**
- **`nightCity` には街区の建物メッシュと `cityLights`（THREE.Points の光点群）があります。**
  地面テクスチャを触るときに、この2つの見え方を壊さないでください
- `surfaceHeightAt` / `surfaceTopAt` の戻り値、地上ユニットの配置、海面のカメラ追従、
  `disposeWorld` の後始末は**一切変更しないでください**（前回と同じ制約です）

## 制約（前回と同じ）

- **単一ファイル `index.html` のみ。** 外部アセット・CDN・新規依存は不可。
  テクスチャは Canvas 2D + `THREE.CanvasTexture` の手続き生成のみ
- **fps ≥ 55**（実GPU基準。あなたのCIはSwiftShaderなので相対比較で構いません）
- **`main` へは絶対に push しないでください。** 作業ブランチのみ
- **ブランチは現在の `main`（`6528f87`）から切ってください。**
  前回の `chatgpt/map-texture-upgrade` は `57125dd` で止まっており、そこから32コミット進んでいます
  （マップ3種・ミッション6本・キャンペーン選択・友軍部隊などが入りました）。
  古いブランチの上に積むと、3-wayマージで43箇所衝突する状態になります
- ブランチ名の例: `chatgpt/texture-new-maps`
