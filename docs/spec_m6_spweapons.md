# SPEC M6 — 特殊兵装 SP.W (2026-07-25, Fable設計)

M5出荷後に着手。1機体1枠、AC7の実装備準拠（裏取り済: F-15C=XLAA / F-22=8AAM / QAAM / F-4E=UGB系）。
「切替して撃ち分ける」レイヤーを足し、対地ミッション(M4)でUGBを輝かせる。

## 兵装表

| 機体 | SP.W | 弾数 | 特性 |
|------|------|------|------|
| F-16 | **QAAM** 再捕捉AAM | 4 | 旋回100°/s（通常MSLと同じ・全ミサイル共通上限）。実際に目標を追い越した最初のオーバーシュート後だけ0.35秒コーストして再捕捉し、2回目で誘導終了。寿命14秒。単発ロック |
| F-15 | **XLAA** 長距離AAM | 12 | 選択中ロック距離 2000（通常1200）、弾速640、旋回90°/sの直線番長。BVR狙撃 |
| F-4 | **UGB** 無誘導爆弾 | 18 | 重力落下・着弾爆風r60でダメージ220(減衰あり)。対地/対艦の主役。CCIP表示 |
| F-22 | **8AAM** 多目標AAM | 24 | 視界内最大8目標へ同時発射（実戦は3-6）。各弾旋回48°/s（全ミサイル共通上限100°/s以内）・ダメージ78 |

- ダメージ: QAAM/XLAA=98（通常ミサイル同等）、8AAM=78、UGB=220爆風
- SP.Wは**2連装管システムの外**（専用ランチャー扱い、リロード待ちなし）。艦隊ウェーブの補給で全回復
- 通常MSL/機銃/フレアは現行のまま

## 操作・HUD

- **切替**: キーボード `KeyX` / ゲームパッド **L3(button 10)**（未使用を確認して割当。使用済みなら報告して代替案を出せ）
- 武器状態: `selectedWeapon = "msl" | "spw"`。発射キー(ENTER/○)は選択中の武器を撃つ。機銃・フレアは独立
- **右下パネル拡張**（AC5様式維持）: MSSL行の下に SP.W行 `<兵装名> ◆.. n`。選択中の武器行に
  左端インジケータ（▶ もしくは枠強調）。切替時に小SE(playTone 1240, 0.05)
- **ハンガー**: WEAPONS AMMO に SP.W名+弾数を追加。SPECバーに **AIR-TO-GROUND** を6本目として追加
  （F-4=0.95、他=0.25。UGB実装でようやく捏造でないバーになる）
- ミッション中のHUD切替表示: バナー小 `SP.W ▶ XLAA` (0.7s)

## 発射ロジック

- **QAAM**: `turnRate`と最高速は通常MSLと同一。寿命14秒、総追尾パス数2。旋回上限に達しただけでは失探せず、接近後に目標を追い越して距離が開いた時だけ回避成立とする。最初の成立後は0.35秒だけ弾道飛行して再捕捉し、2回目で誘導終了
- **XLAA**: 選択中は `LOCK_RANGE` を2000に差し替え（updateLock参照値を関数化 or 変数化）。
  ミサイルは speed 640/turn 90°/s/寿命12s
- **4AAM／6AAM／8AAM／4AGM**: SP.W選択中、ロックコーン・射程・兵装種別に合う別々の生存目標を近い順に、それぞれ4／6／8／4目標まで同時捕捉する。各目標は独立した通常ロック時間0.85秒を**並行して**進め、最初から圏内にいる全目標は同時にロック完了する。後から入った目標は他目標の進捗を引き継がない
  発射時はロック済み全目標へ1発ずつ同一フレームで生成する。弾数・装填数不足時だけ近い順に発射可能数で打ち切り、発射後は消費したmultiロックを解除する。通常の単一ターゲットロックは維持する
- **UGB**: ロック不要。**CCIP**: 現在速度+重力(g=110/s²)の弾道を前方投影し、海面/山肌との交点を
  HUDに落下点マーカー（緑の×+円）で表示。発射で爆弾オブジェクト生成（前方+下方に初速、重力落下、
  地面/海面/目標接触で起爆）。爆風: 半径60内の enemies（surface含む）へ 220*(1-dist/60*0.5) を適用、
  大きめの爆発v2+土煙。空中の敵機には直撃(r14)のみ有効
- 敵AI・艦・地上物への command 変更なし（受け側は既存 damageEnemy）

## データ/フック

- `AIRCRAFT_TYPES` に `spw: { key, label, capacity, ... }` を追加、`applyAircraftLoadout` で反映
- `hook.loadout.spw = { key, ammo }`、`hook.weapons.spwLaunched`、`debug.forceSelectWeapon("spw")`
- リザルト内訳（M5の行）に SP.W使用数を追加してよい（任意）

## 検証

- 4機体それぞれで切替→発射→命中の実測（QAAMが通常MSLと同じ初回軌道・旋回飽和だけでは失探しない・オーバーシュート後に1回だけ再捕捉・2回目で誘導終了/XLAAの2000mロック/8AAMの3目標同時撃墜/
  UGBのCCIP精度=マーカー位置と実着弾の水平誤差<25）
- UGBで艦・地上目標（M3のバンカー等）を破壊、爆風の複数巻き込み
- 8AAM多重ロックのHUD表示スクショ、L3/KeyX切替、パネルのSP.W行と選択インジケータ
- ハンガーのA2Gバー6本目、fps、エラー0、リグレッション（通常MSLの2連装管+リロードが不変）
