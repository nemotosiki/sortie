# SPEC ウェーブ編成の多様化 (2026-07-26, Fable設計)

ユーザー指摘: **「必ず敵戦闘機は3体しか同時登場しないという縛りはないので、いろんな
バリエーションでミッションを構築して。毎回3体だけじゃん」**

## 現状の問題

1ウェーブ3機固定のハードコードは既に撤廃済み（`{types:[...]}` の自由編成が使える）。
にもかかわらず**全ミッションが `air1`/`air2` プリセット（どちらも3機）を使い続けている**ため、
プレイ体験としては毎回3機のまま。**編成そのものを組み直す**。

## 設計方針

### 1. 機数のレンジを広げる
- 序盤: **2〜3機**（弱い機体で密度も低い）
- 中盤: **4〜6機**
- 後半: **6〜9機**（エース込み、同時展開あり）
- 「機数＝難度」ではない。**MiG-21が6機 < Su-35Sが3機** になるよう、HP合計と旋回性能で釣り合わせる

### 2. 質の混成（同種3機を並べない）
- 1ウェーブに**役割の違う機種を混ぜる**: 例「MiG-29×2＋Su-25×1」（速い/硬い）、
  「MiG-21×4＋MiG-23×1」（雑魚の群れ＋中堅）、「Tu-95×2＋MiG-29×2」（爆撃機＋護衛）
- 空と地上/海上の**同時進行**（`concurrent: true`）を活用し、「空を捌きながら艦を沈める」等の
  同時処理を作る

### 3. 到着タイミングの変化
- 一度に全部出さない。**band**（ウェーブ帯）を使って**時間差で増援**を入れる
- 「削り切る前に次が来る」圧、「1機だけ先行して来る」偵察、など緩急をつける
- 逆に**間**を作るミッションもあってよい（全滅させてから次が来る = 息継ぎ）

### 4. ★TGTと雑魚の比率（7/26ユーザー指示・これが編成の基本形）

> 「ミッションの作り方はストーリー通りにして、で基本はターゲットより、
> **ターゲットではない雑魚敵が邪魔してくる感じでそこそこ配置**する感じかね」

**編成の既定形はこう**:
- **TGT（指定目標）は少数**。ミッションの主題そのもの（爆撃機2、艦5、車列7 など）
- **非TGTの雑魚を、TGTより多めにそこそこ配置**する。役割は「**邪魔**」——
  倒す必要はないが、放置すると背後を取られる・対地攻撃の進入を妨害される
- 目安の比率: **TGT : 非TGT ＝ 1 : 1.5〜2**（雑魚の方が多い）
- **★雑魚の弱さは「HP」ではなく「旋回性能」と「ミサイル頻度」で作る（7/26ユーザー訂正）**:
  - **1発で落ちる必要はない**。HPは普通でよい（2発＝196前後を基本に、機種なりの値でよい）
  - 弱さの本体は **①旋回性能が低い ②ミサイルを撃ってくる頻度が低い** の2点
  - 実装箇所: `ENEMY_AI_PROFILES`（どう飛ぶか＝旋回の使い方・追従の粘り）と
    `ENEMY_MISSILE_PROFILES` の `cooldownMin` / `cooldownSpread` を**長め**にする。
    一部は機銃のみ（ミサイルプロファイル無し＝MiG-21bisが既にこの形）でもよい
  - **性能表そのものは書き換えない**（機体の素の数値は共有資産）。
    「その機体をどう飛ばすか・どれくらい撃つか」の役割設定で弱さを表現する
  - 狙い: 雑魚は**背後に張り付くと鬱陶しいが、正面からは怖くない**。
    プレイヤーが「無視して目標へ向かう」判断を取れる強さに収める
- 雑魚は**時間差で湧き続けてよい**（band を使い、TGT処理中に断続的に入る）。
  ただし**無限湧きは禁止**（総数は有限。ミッションは必ず終わる）
- **雑魚を全部倒してもクリアにならない／TGTだけ倒せばクリア**が読み取れる配置にする
  （＝ACの「無視して目標へ向かう」判断が成立する）

### 5. ストーリーに沿った編成にする
`docs/story_bible.md` の各ミッションの物語上の役割に、編成を一致させること。例:
- 01 FIRST CONTACT: TGT=Tu-95×2、雑魚=MiG-21×3〜4（初陣なので雑魚も弱く少なめ）
- 15 CITY LIGHTS（将来）: TGT=爆撃機、雑魚=大量の護衛。「全部は守れない」を編成で語る
- 19 IRONBACK: TGT=エースのみ。雑魚は僚機として断続投入し、決闘の邪魔をする

## 制約

- **fps**: 同時8機以上のウェーブは必ずfps実測（≥50）。割るなら機数を落とす
- **パータイム**: 機数を増やしたミッションはパータイムを比例調整（クリア可能性を実走で確認）
- 難度曲線（序盤=弱い/後半=強い＋エース多め）を壊さない
- 敵は**ロシア機のみ**（陣営分離済み）
- 既存のミッションキー・解禁連鎖・レコード互換は変えない

## 検証（最小限）

1. 各ミッションのウェーブ構成をプローブで出力し、**3機固定になっていない**ことを確認（機数の分布表）
2. 全ミッションが起動し、少なくとも m01/m03/m05/m-intercept はクリア可能
3. 最大同時数のウェーブでfps実測（≥50）
4. エラー0
