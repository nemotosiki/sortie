# SPEC M9 map polish — マップの完成度向上 (2026-07-26未明, Fable設計)

ユーザー指示(7/26未明): 「裏で、マップの完成度を高めるopusを走らせて」。
既存4プリセット(archipelagoDay/sunsetOcean/glacierCanyon/nightBase)の**見栄え・密度・説得力**を上げる。

## スコープ境界(必読)

- **触ってよい**: 島の形状/配置の多様化、地形テクスチャ/色、海岸線、植生/岩/建物などの
  ランドマーク、雲のバリエーション、ライティング/フォグの味付け、天球グラデ
- **触ってはいけない**: 海planeの位置・追従ロジック(別エージェントがカメラ追従化を実装中)、
  ミッションのスポーン座標契約(艦経路・地上目標座標・surfaceHeightAtの挙動)、HUD、敵AI
- 迷ったら「見た目だけを変え、座標と物理は変えない」

## 改善候補(優先順。全部やる必要はない、効果の大きいものから)

1. **島のシルエット多様化**: 現状は同系の山型。低い砂洲/段丘/双子峰/岬など形状バリエーション
   (既存の生成パラメータ拡張で。衝突判定・surfaceHeightAtが正しく追従することが条件)
2. **海岸線の説得力**: 水際の砂色リング/浅瀬の色変化(頂点カラーで軽く)
3. **植生・ランドマーク**: 木のクラスタ(ローポリ・InstancedMesh可)、archipelagoに灯台1本、
   sunsetに小さな港集落、glacierに氷塊、nightBaseの市街光の粒を増やす
4. **雲の多様化**: 形状/高度/密度のバリエーション(既存3層の範囲で)
5. **ライティングの味**: プリセットごとの色温度・フォグ距離の微調整(視程は縮めない方向で)

## 制約

- fps≥58(全プリセット、m01/m03/m-glacier/m-night実走で計測)。パーティクル/ドローコール増は計測必須
- disposeWorldのリーク無し(4巡切替でGPUメモリ不動、M2の手法で実測)
- 全ミッションのリグレッション: 艦経路/地上目標の埋没ゼロ(m-glacier 30サンプル法)、
  スポーン契約不変(RNGストリームがズレる変更はプリセット単位で影響範囲を明記)
- 各プリセットの前後比較スクショ(同カメラ位置)を必ず撮る

## 検証ゲート

1. 4プリセット×前後比較スクショ(俯瞰+低空の2アングル)
2. fps実測表(全プリセット、変更前後)

4. m01/m03/m-glacier/m-night実走クリア+地上目標/艦の埋没ゼロ
