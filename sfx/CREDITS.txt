Files used in this project (renamed from the original pack):

  gun.ogg       <- shot_03.ogg     player machine gun
  missile.ogg   <- cannon_03.ogg   missile launch
  explosion.ogg <- bang_05.ogg     enemy destroyed
  hit.ogg       <- bang_08.ogg     player takes damage

All other sounds in the game (lock-on beeps, radio speaker chirps, stall and
missile-warning tones, the outro drone) remain procedurally synthesised with
the Web Audio API and use no external assets.
