Source 1: "25 CC0 bang / firework SFX" by rubberduck
          https://opengameart.org/content/25-cc0-bang-firework-sfx

  gun.ogg       <- shot_03.ogg     player machine gun
  missile.ogg   <- cannon_03.ogg   missile launch
  explosion.ogg <- bang_05.ogg     enemy destroyed
  hit.ogg       <- bang_08.ogg     player takes damage

Source 2: "Rocket Engine" by theMinesAreShakin
          https://opengameart.org/content/rocket-engine

  engine.ogg    <- rocket_engine.001.wav   looping engine rumble

  Modified: downmixed to mono, resampled to 44.1 kHz and encoded to Ogg
  Vorbis (q3) to cut 1.12 MB down to 19 KB. CC0 permits modification.

All other sounds in the game (lock-on beeps, radio speaker chirps, stall and
missile-warning tones, the outro drone) remain procedurally synthesised with
the Web Audio API and use no external assets.
