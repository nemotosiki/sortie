Source 1: "Plains of Luminescence" by vitalezzz
          https://opengameart.org/content/plains-of-luminescence

  menu.ogg  <- plains_of_luminescence_loop.flac   3:26   3.0 MB

  Calm synth-and-guitar bed; the author ships a purpose-made loop cut, so the
  terminal is already level-matched to the head (-19.1 dB vs -20.9 dB) and
  wraps without a seam.


Source 2: "Unsolved Investigation" by isaiah658
          https://opengameart.org/content/unsolved-investigation

  briefing.ogg  <- Unsolved-Investigation-isaiah658.wav   0:48   461 KB

  Dark cinematic pulse the author explicitly composed "to allow dialogue and
  sound effects to be heard over it", and describes as a seamless loop.
  Measured head/tail levels agree (-24.1 dB / -22.6 dB).


Source 3: "Signal Pursuit" by vitalezzz
          https://opengameart.org/content/signal-pursuit

  combat.ogg  <- signal_pursuit.wav   1:52   1.7 MB

  Driving sci-fi electronic, ~161.5 BPM.

  Modified: the original is 2:55 and ends in a fade-out to digital silence
  (-91 dB), so it cannot loop as shipped. A loop region was cut from
  39.520 s to 154.413 s -- 316 beats, exactly 79 bars on the detected beat
  grid -- and the wrap point was closed with an 8-beat (2.909 s) equal-power
  crossfade. The intro was dropped because wrapping mid-track material back
  into it scored poorly (0.32 chroma/MFCC similarity vs 0.63 for the region
  used).


Source 4: "Silver Bullet" by vitalezzz
          https://opengameart.org/content/silver-bullet

  ace.ogg  <- silver_bullet.flac   2:38   2.3 MB

  Heavy rock/metal, ~112.3 BPM. Same composer as combat.ogg, so the ace
  engagement escalates without a change of sound palette.

  Modified: the original is 3:37 and also fades out to near-silence
  (-87 dB). Loop region cut from 29.513 s to 191.634 s -- 308 beats, exactly
  77 bars -- closed with an 8-beat (4.211 s) equal-power crossfade.
  Resampled 48 kHz -> 44.1 kHz to match the rest of the set.


Source 5: "Ending Scene" by nene
          https://opengameart.org/content/ending-scene

  debrief.ogg  <- ending_scene_orchestral.wav   2:26   2.3 MB

  The orchestral-only master from a page that also offers a rock/orchestral
  mix. Kept unedited: its composed fade-out at 138-144 s is the intended
  ending, which suits a debrief screen that plays once rather than looping.


Source 6: "Game Success Fanfare" by el_boss
          https://freesound.org/people/el_boss/sounds/677859/

  victory_sting.ogg  <- 677859_9129912-hq.mp3   3.38 s   46 KB

  A quick major-chord fanfare, purpose-built for a win state and already
  inside the 3-8 s target with no trimming.

  Note on quality: Freesound gates the original 96 kHz WAV behind a login,
  so this was taken from the publicly served 128 kbps MP3 preview. The file
  is therefore a second-generation lossy encode. At 3.4 s and 46 KB the
  penalty is inaudible in context, but it is recorded here for accuracy. The
  CC0 dedication covers the preview as it does the original.


Processing applied to all six files
-----------------------------------

Encoded to Ogg Vorbis (libvorbis) at q4, except victory_sting.ogg at q5,
44.1 kHz stereo. Sources were taken as FLAC or WAV wherever the author
offered them, so each file is a single lossy generation from a lossless
master (the sting above is the one exception).

Loudness-matched to -18.0 LUFS integrated (EBU R128), true peak at or below
-4.5 dBTP. The raw sources spanned -8.3 to -21.8 LUFS, which would have made
the ace theme roughly 13 dB louder than the briefing bed. The correction was
applied as a single static gain per file rather than a dynamic normaliser,
specifically so that the loop seams in combat.ogg and ace.ogg remain
sample-exact.

Total: 10.0 MB for six tracks.

Rejected on licence grounds, despite being good fits:

  Kevin MacLeod / Incompetech (https://incompetech.com) is CC-BY 4.0, not
  CC0, and requires attribution. His CC0 releases lived on FreePD.com, which
  permanently closed in 2025 ("freepd.com is now permanently closed.
  2008-2025") and serves only a closure notice; its category pages 404, so
  nothing could be sourced there. Only four FreePD files survive, on
  Wikimedia Commons. Do not treat an Incompetech track as CC0 on the
  strength of the shared composer name.
